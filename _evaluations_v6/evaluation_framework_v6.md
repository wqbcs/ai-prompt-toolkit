## 一、评估维度定义

| 维度 | 全称 | 定义 | 满分 | 评估对象 |
|------|------|------|------|----------|
| 结构 | 结构完整性 | 场景模板是否包含5要素 | 20 | 每个场景模板 |
| 约束 | 约束条件完备性 | 约束是否覆盖技术/业务/安全/性能四维度 | 20 | 每个文档核心约束章节 |
| 角色 | 角色设定深度 | 角色定义是否含经验+领域+能力+工作方式 | 20 | 每个文档身份定义章节 |
| 输出 | 输出格式精确性 | 输出是否有明确格式+示例 | 20 | 每个文档输出规范章节 |
| 清单 | 检查清单覆盖度 | 检查项是否覆盖该领域全部关键风险点 | 20 | 每个文档检查清单章节 |
| 推理 | 推理模式适配性 | 是否适配CoT/Few-shot/自纠错等 | 20 | 每个场景模板推理模式标注 |
| 前沿 | 前沿技术适配度 | 是否适配PoT/Active-Prompt/Agent-First | 10 | 每个场景前沿技术标注 |
| 行业 | 行业垂直化覆盖度 | 行业3件套+行业专用场景覆盖 | 10 | 行业适配体系 |
| **互操作** | **互操作性** | **场景间数据传递标准化+上下文传递完整性** | **10** | **场景接口契约** |
| **生态** | **生态开放度** | **可贡献性+API可访问性+文档可发现性** | **10** | **社区生态基础设施** |

## 二、新增维度评分标准

### 2.9 互操作性评分(0-10分制)

| 分数段 | 标准 |
|--------|------|
| 0-2 | 场景间无标准化传递，依赖隐式转换 |
| 2-4 | 部分场景对有YAML接口定义，但传递不完整 |
| 4-6 | 所有关键场景对有接口契约，上下文传递基本完整 |
| 6-8 | 全场景接口契约覆盖+零损耗传递协议+断点续传 |
| 8-10 | 互操作性100%覆盖+端到端验证通过+版本化契约+自动兼容性检查 |

### 2.10 生态开放度评分(0-10分制)

| 分数段 | 标准 |
|--------|------|
| 0-2 | 封闭体系，无贡献/集成机制 |
| 2-4 | 有CONTRIBUTING.md但无评审流程 |
| 4-6 | 贡献模板+评审流程+API文档 |
| 6-8 | 贡献模板+评审+API+版本自动化+Dashboard |
| 8-10 | 完整生态：贡献+评审+API+版本+Dashboard+社区治理 |

## 三、Promptfoo CI/CD集成

### 3.1 流水线架构

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 提示词   │ ─→ │ Promptfoo│ ─→ │ 门禁    │ ─→ │ 评估    │ ─→ │ 发布    │
│ 变更触发 │    │ 全量评估 │    │ 判定    │    │ Dashboard│    │ 自动化  │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
```

### 3.2 门禁标准

| 门禁级别 | 条件 | 行为 |
|----------|------|------|
| 阻断 | 任一维度<合格阈值 | 阻止合并，返回评估报告 |
| 警告 | 均分下降>0.5 | 允许合并，标注性能退化 |
| 通过 | 均分≥18.5且标准差≤0.7 | 正常合并 |
