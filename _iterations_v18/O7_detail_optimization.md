## 2. Markdown渲染兼容性检查

### 兼容性规则

| 元素 | 规范 | 原因 |
|------|------|------|
| 表格 | 必须有表头行 | 部分渲染器不支持无表头 |
| 代码块 | 必须指定语言 | 语法高亮需要 |
| 链接 | 使用相对路径 | 离线可用 |
| 图片 | 使用alt文本 | 无障碍 |
| 列表 | 嵌套最多4层 | 渲染器限制 |
| 标题 | 不跳级(1→2→3) | 目录生成 |
| YAML代码块 | 使用```yaml | 正确高亮 |
| JSON代码块 | 使用```json | 正确高亮 |
| 数学公式 | 不使用LaTeX | 兼容性 |
| HTML | 不使用HTML标签 | 纯Markdown |
