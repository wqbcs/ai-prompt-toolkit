# 多模态Prompt设计规范 v1.0

> **版本**：v1.0
> **日期**：2026-05-29
> **适用**：支持图文混合输入的提示词场景模板(02/07/09/10)

---

## 一、多模态Prompt设计原则

| 原则ID | 原则名称 | 定义 | 示例 |
|--------|----------|------|------|
| MMP-01 | 文本优先描述 | 图像内容必须先转换为文本描述再进入Prompt | 架构图→Mermaid文本→分析指令 |
| MMP-02 | 图文关联标注 | 图像引用必须标注与文本的语义关联 | [图1-架构总览]与[章节2.1]关联 |
| MMP-03 | 跨模态推理链 | 跨文本与图像的推理步骤必须显式标注 | 文本分析→图像识别→交叉验证→综合结论 |
| MMP-04 | 降级兼容 | 无图像输入时提示词仍可正常执行 | 图像描述为可选字段 |
| MMP-05 | 格式标准化 | 图像描述必须遵循本规范定义的模板 | 架构图描述模板/流程图描述模板 |

## 五、场景模板多模态增强

### 5.1 02_架构设计 多模态增强

在场景模板中添加以下指令块：

```
## 多模态输入处理

当用户提供架构图/系统图时：
1. 识别图像类型(C4/微服务/部署/网络拓扑)
2. 转换为对应文本描述模板(参见_multimodal/multimodal_design_spec.md)
3. 在文本描述基础上执行架构评审
4. 标注[图像→文本转换]位置，确保可追溯

当用户提供代码结构截图时：
1. 提取关键类/接口/依赖关系
2. 生成UML等价文本描述
3. 基于文本描述执行架构分析
```

### 5.2 07_监控运维 多模态增强

```
## 多模态输入处理

当用户提供监控仪表盘截图时：
1. 识别图表类型(折线/柱状/热力/拓扑)
2. 提取关键指标名称、当前值、阈值线
3. 生成结构化指标数据JSON
4. 基于结构化数据执行告警规则生成

当用户提供日志截图时：
1. OCR提取日志文本
2. 识别日志格式(时间戳/级别/模块/消息)
3. 结构化解析后执行日志模式分析
```

### 5.3 09_性能优化 多模态增强

```
## 多模态输入处理

当用户提供性能火焰图时：
1. 识别热点函数调用栈
2. 提取各函数占比与耗时
3. 生成调用链文本描述
4. 基于文本描述执行瓶颈分析与优化建议

当用户提供性能对比图表时：
1. 提取优化前后指标值
2. 计算改善百分比
3. 生成对比分析报告
```

## 六、跨模态推理指令模板

```
## 跨模态推理步骤

给定：文本描述T + 图像描述I

1. [文本分析] 基于T提取：{关键实体, 关系, 约束}
2. [图像识别] 基于I识别：{视觉元素, 布局, 标注}
3. [交叉验证] 验证T与I的一致性：
   - T中实体是否在I中出现
   - I中元素是否在T中描述
   - 不一致项标注[跨模态冲突]
4. [综合推理] 基于T∪I的一致部分执行推理
5. [不确定性标注] 对仅来源单一模态的结论标注[待验证]
```
