## 2. 日文文化适配

### 2.1 敬语体系适配
- **尊敬语(そんけいご)**：用于客户/上级相关描述
- **谦让语(けんじょうご)**：用于自身操作描述
- **丁寧语(ていねいご)**：通用正式文体(desu/masu体)

### 2.2 表达习惯适配
| 中文表达 | 日文表达 | 说明 |
|----------|----------|------|
| 必须 | しなければなりません | 丁寧语+义务 |
| 禁止 | してはいけません | 丁寧语+禁止 |
| 建议 | することをお勧めします | 委婉建议 |
| 注意 | ご注意ください | 礼貌提醒 |
| 严格执行 | 厳格に実行してください | 正式请求 |

### 2.3 文档格式适配
- 全角字符使用
- 段落缩进：1全角空格
- 标点：句号「。」、逗号「、」
- 术语：片假名标注外来语

### 2.4 行业术语映射(日文)
| 中文 | 日文 | 备注 |
|------|------|------|
| 提示词 | プロンプト | 片假名 |
| 代码审查 | コードレビュー | |
| 安全审计 | セキュリティ監査 | |
| CI/CD | CI/CD | 不译 |
| 监控 | モニタリング | |

## 3. 韩文文化适配

### 3.1 敬语体系适配
- **합쇼체**：最高敬语(正式文档)
- **해요체**：礼貌语(一般说明)
- **해체**：平语(代码注释)

### 3.2 表达习惯适配
| 中文表达 | 韩文表达 | 说明 |
|----------|----------|------|
| 必须 | 반드시 ~해야 합니다 | 正式义务 |
| 禁止 | ~해서는 안 됩니다 | 正式禁止 |
| 建议 | ~하는 것을 권장합니다 | 委婉建议 |
| 注意 | 주의하시기 바랍니다 | 礼貌提醒 |

### 3.3 行业术语映射(韩文)
| 中文 | 韩文 | 备注 |
|------|------|------|
| 提示词 | 프롬프트 | |
| 代码审查 | 코드 리뷰 | |
| 安全审计 | 보안 감사 | |
| CI/CD | CI/CD | 不译 |
| 监控 | 모니터링 | |
