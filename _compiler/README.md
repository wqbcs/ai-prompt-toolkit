# _compiler — 提示词编译引擎

## 引擎简介

`_compiler` 是提示词基础设施的核心编译引擎，负责将结构化提示词模板编译为可执行的提示词实例。主要功能包括：

- **模板解析**：解析模板语法，提取变量、条件分支和继承链
- **条件编译**：根据运行时上下文动态激活/忽略条件分支
- **嵌套展开**：递归展开嵌套模板，支持最大嵌套深度限制
- **缓存机制**：基于模板 ID 和上下文哈希的编译结果缓存

## 使用指南

### 目录结构

```
_compiler/
├── README.md          # 本文件
├── config.yaml        # 引擎配置
└── (引擎核心代码)
```

### 编译流程

1. 加载模板定义
2. 解析继承链并合并
3. 评估条件分支
4. 展开嵌套模板
5. 应用操作符转换
6. 输出编译结果与报告

### 配置说明

参见 `config.yaml`，关键配置项：

- `max_nesting_depth`：最大嵌套深度
- `cache_ttl_seconds`：缓存过期时间
- `fallback_strategy`：编译失败回退策略

### 编译报告

编译输出遵循 `_schemas/compile_report.schema.json` 定义的格式。
