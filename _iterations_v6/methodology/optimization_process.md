## 五、收敛判定流程(v3.0)

```
1. 执行全量十维度评估(55场景×10维度)
2. 计算均分与标准差
3. 执行全量回归测试(78用例)
4. 执行注入防御测试(Promptfoo Red Team)
5. 执行互操作性端到端验证(5用例)
6. 判定收敛：
   - 均分≥18.5 ✅
   - 标准差≤0.7 ✅
   - 回归通过率≥90% ✅
   - 注入防御率≥99% ✅
   - 互操作性覆盖=100% ✅
7. 通过→发布v6.0.0
8. 未通过→定位低分维度→针对性迭代→重新评估
```

## 六、Promptfoo CI/CD集成流程

```
1. 提示词变更触发(文件修改/Push/PR)
2. Promptfoo自动执行全量评估
3. 评估结果与基线对比
4. 门禁判定：
   - 阻断：均分下降>1.0或任一维度<合格阈值
   - 警告：均分下降0.5-1.0
   - 通过：均分无下降或上升
5. 结果发布至Dashboard
6. PR评论自动附加评估摘要
```
