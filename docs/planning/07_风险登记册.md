## 5. 低价值打磨陷阱（01 §6 的可执行检查版）

> 01 §6 是"是什么"，本节是"执行 agent 怎么检查自己是否踩了"。
> **触发机制**：执行 agent 开始一个任务前，自问本节 5 问；任一答"是"→ 停手登记 02 总板"暂停项"区。

**5 问自检**：
1. 这个任务在 02 总板里有编号吗？没有→先登记（防自主发散）
2. 这个任务服务 01 §2 的哪个价值主张？说不清→大概率是 T1 凑数量
3. 这个任务需要引入新依赖吗？需要→查 03 §F 是否已否决+查依赖面
4. 这个任务改内核结构吗？改→查 04 §6 演进顺序是否在发布窗口冻结期
5. 这个任务的验收标准是"跑通"还是"数字改善/护栏建立"？只"跑通"→警惕 T3/T9

**陷阱速查**（01 §6 的 T1-T10 编号引用）：
- 想加规则/维度/Provider → **T1**
- 想全量行:列重构 → **T2**
- 想做 A/B 测试/模板市场/评分 → **T3**
- 想批量模板塞声明 → **T4**
- 想抬基线/mypy 数字 → **T5**
- 想发布前大重构/重命名 → **T6**
- 想建"未来可能用"的抽象 → **T7**
- 想追新框架/新依赖 → **T8**
- 想在规则/门禁里加 LLM 可选增强 → **T9**
- 想无验收标准大重构 → **T10**
