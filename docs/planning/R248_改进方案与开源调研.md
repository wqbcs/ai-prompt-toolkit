## §1 定位与反思（鬼才 PM 自检，开工前）

**项目定位**：确定性的 LLM 提示词静态门禁——prompt 的 ESLint。
**楔子**（产品核心价值）：每次裁决逐字节一致 + 零 LLM 成本 + <100ms/文件 + 离线可跑。

**可信度是产品**。门禁只在"被相信"时才有价值；而"被相信"最直接的素材不是
一句 slogan，是**收紧史**——误报率 8.38%→0.9%、漏检率恒 0，这条曲线本身
就是"这个工具在变诚实、没在放水"的证据。P2-04 板行原文："误报率收紧史是
可信度核心素材……生成 sparkline 图入 README"。

   README 里一张图**——与 R247 P5-01 同形态（数据在、展示断链的最后一公里）。

## §2 开源/外部调研

  文件序=时间序——sparkline 按文件序读，不重排（确定性+append 语义天然）。

**外部共识（sparkline 形态，已知实践）**：

  普遍用"提交静态 SVG/数字，CI 定期重生成"模式——与 ci-streak 同形态，
  无需运行时。**采用**：纯 stdlib 确定性生成 + 静态提交 + release_gate 重生成。

**内部实证（本轮新数据，入 08 调研表）**：

## §3 落地内容

### 3.1 确定性 sparkline 生成器（P2-04 收口）

- `scripts/gen_baseline_sparkline.py`（纯 stdlib，零新依赖）：
  - 读 `docs/baseline_history.jsonl`（append-only 文件序=时间序）。
  - 提取 fp_rate 序列（非 null）为主折线；miss_rate 作为恒 0 底线（若有非 0
    点则一并画）。
  - 输出 `badges/baseline-trend.svg`：**确定性纯函数**（同 jsonl→同 SVG 字节，
    坐标固定小数位、无时间戳/随机、无运行时时钟）；固定 viewBox（600×160）。
  - **n/a 态**：有效点 <2 → 渲染 n/a 占位 SVG（灰化，同 ci-streak n/a 纪律），
    不画假曲线。
  - 头部注释留数据源路径+点数（可审计），不含生成时刻（确定性）。
- 接线：`release_gate` 新步（生成+断言 SVG 存在且非空，与 sync_badges 相邻）；
  CI `prompt-ci.yml` 同命令；README 可信度节（"为什么该信这个工具"附近）引用
  `![Baseline Trend](badges/baseline-trend.svg)`+一行图注（FP 8.4%→0.9% 收紧史）。
- 提交 `badges/baseline-trend.svg`（静态资产，git 版本化=曲线历史可 diff）。
