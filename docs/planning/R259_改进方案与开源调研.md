## §0 定位与核心价值（第一性原理——任何改进方案先过这两问）

**定位（01 §1，未漂移）**：LLM 应用提示词的 ESLint——**每次裁决逐字节一致**的确定性
静态门禁。零 LLM、可复现、<100ms/文件、SARIF/CI 原生、离线可跑。

**核心价值（01 §2 moat，按强度排序）**：
| 楔子 | 强度 | R259 时点状态 |
|---|---|---|
| 确定性/可复现（逐字节） | ★★★★★ | 已机器护栏（SARIF 确定性 R246 + e2e 逐字节 + 复现性锁）——**内化饱和** |
| 零 LLM 成本 | ★★★★★ | 结构保证，无待办 |
| <100ms/文件 | ★★★★ | P2-16 性能断言已锁（P99 14.87ms，6.3× 余量）——饱和 |
| 零 key/离线/air-gap | ★★★★ | 结构保证；**采用侧未兑现**（air-gap ICP-② 无交付包） |
| 可审计裁决 | ★★★★ | explain 页 267 + 规则源 + 探针——**本轮审计对象（§3 S1）** |

**推论（宪法）**：一切资源向"加深确定性楔子"**且"让楔子被外部看见/验证"**倾斜；
"加数量"（规则/维度/Provider）只做防守性维护。北极星=**每周在多少条 CI 流水线里
产生"阻止一次不安全 prompt 合入"的可复现裁决**——不是下载量、不是 star、不是内部指标。

**需用户调整的一件事（本轮唯一对外请求，见 §4 顶部）**：授权 P0-03 + P0-04

## §2 R259 决策记录 + 开源/外部调研小结

### 2.1 P3-03 变异测试（已判：不抢跑，留痕 01 §7 + 02 板行）
R259 用原型实证了"探针集强度度量"这条路的当前不可行动性：
- **原型**：10 规则（P001/P103/P134/P161-165/P258/P260）× 4 算子（case/量词减半/
  词边界剥离/负向前瞻剥离）× 235 探针 = 148 mutants。
- **结果**：kill 3%，144/148 equivalent。
- **方法论缺陷（不是探针弱，是度量设计有问题）**：
  1. **kill 判据 = hitset 全等**——宽 OR 规则（如 P001 在基线上 218 命中）里
     单 pattern 变异几乎都被其余 pattern 兜住，"命中集合不变"是常态，不是探针缺口。
  2. **算子太弱**——量词减半/词边界剥离对宽匹配 OR 规则是 0 扰动，produces
     "equivalent" 假信号。真正有判别力的算子应是 **alternation 分支删除 / 断言翻转 /
     常量替换**（能真改命中集合的）。
  3. **元指标性质**——杀死率是"探针集质量"的间接代理，无客户可见、周间结构稳定，
     给它建周频 CI + 基线棘轮 = 打磨的打磨（T1/T7 邻变体）。
- **重启三条件**（齐备才立）：① 09 §5 触发器满足（M3 达成）② 强算子集
  （alternation 删除/断言翻转/常量替换）③ kill 判据改 per-probe expected 单元语义
  （不是 hitset 全等）。**本轮：登记不实施。**

### 2.2 外部信号复用（不重搜，引用项目已积累调研）
外部信号**复用 08（痛点）+ 13（开源）+ 12** 的既有证据链（本 session 新做的 2 次
web 检索 1 次被 Exa 限流、1 次确认既有结论，无新 S 级信号）。对本轮决策有效的
三条既有外部信号（08 发现 1/2/4）：
- **发现 1**：误报率是检测器第一信任问题，"单阈值比较"是行业盲区 → 我们双基线
  0.82% 可复现正是弹药（R258 已做成 operating point 公开页）。
- **发现 2**：行业共识"PR gate 必须确定性，否则 CI 信任崩塌"，且分层与我们的
  "确定性快层 + 统计慢层"双轨完全同构 → 定位被外部验证，README 应改"互补+边界"
  （P1-07，user-gate）。
- **发现 4**：MCP 管道是新兴注入面，**轻量检测器在 JSON 结构面快速漏报**（S2
  信号）→ P2-18 预研的立足点（本轮 #4 推进）。
- 开源侧（03/13）：aiproof 迁 Rust 收缩了 Python 生态 ICP（反面教训，我方不迁）；
  mutmut 可定向变异规则 regex（已原型，§2.1）；prompt-guard "read this honestly"
  = 如实公开差数字的叙事先例（我方 operating point 页同叙事）。

### 4.2 本轮（#4）实推进的 slice
**A1 = P2-18 MCP JSON 结构面检测预研**（1 页检测面白皮书 + go/no-go 提案）。

  （守 <100ms 楔子），不抢 P4 结构变更窗口。
