## 一、生态变局（S 级信号, 2026-10-28→10-30 窗口）

### S1: GitHub 官方 AI 代码扫描上线 public preview（2026-10-28）

- **事实**（github.blog/changelog/2026-10-28）：Code scanning 新增 AI 应用/agent
  漏洞检测——indirect prompt injection（XPIA）、敏感信息泄露、过度 agency；
  PR 创建时自动跑（与 CodeQL 并行）；需 **GitHub Advanced Security 许可**；
  Enterprise Server 暂不可用。
- **差分**：官方=CodeQL 系（SaaS 依赖+GHAS 按席收费+黑盒启发式, 无逐字节
  可复现承诺）; 我方=确定性零 LLM 离线+byte-identical+SARIF 原生+双基线自证。
  官方入场=**品类合法性确认**（"AI 代码扫描"从 niche 变成 GHAS 标准件）,
  同时留下三个未满足面：离线/自托管（GHAS 是 SaaS）/确定性审计（CodeQL
  无逐字节承诺）/成本敏感（GHAS 按席）——恰是我方的楔子面。
- **动作**：N3 定位对比表更新（本轮）。

### S2: promptfoo 被 OpenAI 收购（2026-03-09 官宣, 开源继续）

- **事实**（promptfoo 官方公告 + andrew.ooo 2026-10-29 综述）：收购后开源项目
  继续, 技术并入 OpenAI Frontier；**间接注入/hijack/SSRF/system-override 等
  red-team 插件需 hosted generation**（离线用户被分流到云端）；26.5k stars,
  "25% Fortune 500 使用"（官方口径）。
- **差分**：静态车道（prompt 文件面确定性门禁）与 promptfoo 动态车道
  （模型行为评估）互补性被收购进一步放大——动态面被云绑定, 静态离线面
  的独立价值上升。我方 README 既有"promptfoo 互补"表述仍成立, 需补
  "离线 hosted-generation 分流"这一新事实。
- **动作**：并入 N3（对比表同段）。

### S3: PIDS-Bench（IEEE Access 2026-09-14, DOI 10.1109/ACCESS.2026.3728186）

- **事实**：frozen 多轴基准（SHA-256 manifest）, 联合评估攻击检测+**良性
  误报**：hard-benign 压力集 1472 条（外部来源 872 + 构造 600, 双标注员盲审
  κ=0.85）, 核心发现=**provenance-sensitive over-defense**——F1>0.98 的
  检测器在外部来源安全邻域良性子集上误杀 ~1/3; 全阈值扫描+5 种子下无检测器
  同时满足 F1≥0.95 且 hard-benign FPR≤0.10。
- **差分**：与我方过防御锚点（NotInject-339, 6.78%, 首点 33.92% 逐批修复）
  **同族互证**——学界独立得出"过防御是学习检测器的结构性问题", 确定性
  规则面+过防御曲线的工程路线获得外部背书。其外部来源良性子集=可复用的
  跨基准验证资产（我方 0.81%@60 干净样本面的扩样候选, T1=先核数据集许可）。
- **动作**：N5 跨基准验证预研（下轮, 取证先行）。

## 二、竞品/开源新动态（A 级信号）

### A1: malskanner（npm+GitHub, 9 规则, MIT）——**已直接触发本轮 E1**

- **事实**：确定性 repo 安全扫描（agent 读取前的 payload 门禁）, 9 规则：
  `unicode-tag-smuggling`（U+E0000-E007F 1:1 解码）/`bidi-override`/
  `zero-width-char`/`hidden-html-comment`/`hidden-css-text`/`encoded-base64`/
  `encoded-hex`/`homoglyph-token`/`agent-directed-instruction`；
  REFUSE/WARN/OK 裁决; CLI+GitHub Action+MCP 工具三形态。
- **差分与执行**：
  - tag smuggling 面（首条规则）= R356 归一化层首版（5 字符剥离集）的
    **逃逸面**——对抗性审查发现 2/3 实证后, 本轮 **E1 已落地**：归一化三阶
    （NFKC + tag 解码 + Cf 完整剥离）, tag 有编码语义=解码类（DECODED 层
    同范式）, Cf 无编码语义=剥离类（Unicode 属性类, 170 码点/21 区间,
    测试钉死与 Unicode 数据库对齐）。
  - `hidden-html-comment`/`hidden-css-text` 面 = 本轮 E2 取证：**7 个攻击
    形态（HTML 注释×2 / display:none / font-size:0 / color:transparent /
    opacity:0 / off-screen）全部被现有规则命中**——全文正则匹配器结构上
    免疫 markup 隐藏（无解析器=无隐藏节点盲区）, 无漏检红, 该面关闭。
- **状态**：E1 ✅（本轮）/ E2 取证 ✅（本轮, 无漏检红, 观察项关闭）。

### A2: reizan-injectgate（PyPI 0.1.0, 2026-10-29 窗口内发布）

- **事实**：确定性 CI gate, "无 LLM judge"范式：语料驱动 OpenAI-compatible
  agent + 双 fixture 工具（read_file/http_fetch 闭世界）+ canary oracle +
  SHA-256 证据绑定 + fail-closed ScopeGate（越界工具请求= susceptibility
  证据而非副作用）。
- **差分**：同车道叙事（"无 LLM judge"）但不同测量对象——他们测
  **模型+agent scaffold 的动态行为**（闭世界运行时）, 我方测 **prompt
  文件面的静态属性**。非竞争, 是同一"确定性楔子"哲学的独立收敛
  （第一性原理互证：可审计门禁不需要模型裁判）。注意="无 LLM judge"
  叙事先发优势已被稀释, 我方差异化押注在 111 天双基线曲线+708 探针
  的积累深度（新进入者无法伪造时间）。

### A3: promptpale（GitHub, Python AST）

- **事实**：prompt **构建面**检测——PP001 用户输入直接插值进 system 通道
  （blocker）/ PP002 user 通道无围栏/数据框架 / PP003 裸 f-string 拼接
  外部输入变量; safe-marker 短路（围栏/数据框架/sanitize 调用/常量）。
- **差分**：**新目标类型**（代码中的 prompt 构建模式 vs 我方 prompt 文件
  面）, 互补非竞争。登记观察区 N6（未来目标类型扩展候选, 触发=真实
  用户需求信号, 不预支实现）。

### A4: ContextHound（GitHub, 122 规则/15 族, MIT）

- **事实**：静态分析 CLI（多语言）, 122 规则 15 族（injection/exfiltration/
  jailbreak/unsafe tool use/命令注入/RAG 投毒/编码隐藏内容/输出处理/
  多模态/agent skills/agentic/MCP/供应链/资源/持久化）; **`hound fix`
  自动剥离隐藏 Unicode（ENC-002~005 autofix）**; 增量缓存/baseline-diff
  模式/插件系统/OWASP LLM Top 10 (2025)+Agentic (2026) 双映射。
- **差分**：autofix 面——我方 196 条规则可自动修复, 但**隐藏字符剥离
  是否在 autofix 面未取证**（196 是 lint 规则面计数, Unicode 隐藏字符
  治理归 defender 层）→ N4 取证项（下轮）。

### A5: garak v0.17.1（NVIDIA, 2026-10-16）

- **事实**：hit@k 攻击成功率指标（per probe/detector 对, report.jsonl
  digest 暴露）+ Python 3.14 支持; v0.17.0 = EU AI Act 映射。
- **差分**：指标面互鉴——hit@k 与我的探针命中计数（708 探针 0.00% 漏检）
  同族; garak 是模型扫描器（动态）, 无静态门禁功能, 维持互补定位。
  EU AI Act 映射=合规映射竞争面（我方已有等保 2.0/OWASP/ATLAS 三映射,
  EU AI Act 映射登记观察区——触发=欧盟市场信号）。

### A6: Semalith v1.4（arXiv 2607.22545, 184M DeBERTa-v3）

- **事实**：单一 DeBERTa-v3 头, 7/7 prompt-injection 基准胜 Llama-Guard-3-8B,
  **FPR=0.000 @ 208 良性 agent 提示**。
- **差分**：叙事对抗——学习型的 "FPR=0@208" 单点声明 vs 我方 0.81%@60 +
  6.78%@339 双锚点+111 天曲线。PIDS-Bench（S3）刚证明单点 FPR 声明在
  分布偏移下不可信（F1>0.98 仍误杀 1/3 外部良性）——**曲线 vs 单点**
  是我方叙事护城河, 博客素材（下轮博客④候选：《为什么我们不信 FPR=0 的
  单点声明》, 引 PIDS-Bench+Semalith 双源）。

### A7: 其他竞品情报（B+ 观察）

- **ipi-check**（SAST, 三阶段：静态+可选 LLM+skill 审计 IPI401-411）：
  **agent skill 安全审计面**（SKILL.md 恶意行为检测：凭据窃取/远程执行/
  权限滥用/隐匿指令）= 新面登记 N6; 其 pre-LLM 消毒（防分类器自身被注入）
  与我方"门禁层零 LLM"哲学同向。
- **prompt-shield**（33 输入检测器+9 输出扫描器+**联邦威胁情报 feed**）：
  威胁情报订阅=商业化信号（N6 观察区）。
- **llm-app-ci-gate**（2026-10-29, PyPI 0.1.0）：组合门禁（prompt eval+
  安全扫描+离线成本估算, ~4 字符/token 无模型调用）——"一门禁一报告"
  叙事同族; 他们=组合薄层（不重新实现评分/扫描）, 我方=单点深度
  （规则+基线+门禁全自持）。
- **lintlang**（7 结构检测器, agent 配置语言质量, 0 LLM, ~2ms/文件）：
  相邻车道（配置语言质量 vs prompt 安全）, 其"CI 机械化文档一致性门禁"
  与我方 sync_* 门禁同族实践。
- **nox / promptaudit / prompt-armor**：情报面（prompt-armor 5 层+meta
  分类器=混合型, 与我的纯确定性分层同构但层 2 用 DeBERTa=其"确定性"
  主张有边界——对比表引用时须精确到"层 1/4/5 确定性, 层 2/3 学习"）。
- **Wagner 团队论文**（arXiv 2610.03448, "Passing the Test You Trained On"）：
  15 检测器跨基准评估——**检测排名跨基准迁移差**（BIPIA 最佳者在
  AgentDojo 仅捕 2% 注入@1% FPR）, 但 **tool output 面 FPR 排名稳定**
  （Kendall τ=0.67, p=0.001）; 结论=评估应使用 agent 自己的 tool output +
  低 FPR 运营点报告 + 审计训练数据。→ 我方基线扩展方向 N6（tool output
  面 FP 测量, 触发=agent 场景用户需求）。
- **Confidently Wrong**（arXiv 2606.22659）：漏检攻击时置信度 0.99-1.00
  （content-keying 而非 injection 结构）, 标准池化校准错误不登记此缺陷
  → **校准救不了结构盲点**=确定性规则面价值的又一外部论证（博客素材）。
- **LongPIBench**（EMNLP 2026 findings）：长上下文注入基准, 检测器极端
  权衡（要么全杀要么全漏）——长 prompt 场景的基准空白=我方长单行
  （R343-RE-1 1.8MB 面）治理的外延, 观察区。

## 四、PM 四问（鬼才 PM 视角）

1. **为什么是现在**：GitHub 官方 10-28 入场=品类合法性窗口开启——
   "AI 代码扫描"从 niche 变 GHAS 标准件, 但官方只覆盖 SaaS/按席/黑盒
   三面, 离线+确定性+自托管需求被官方定价排除在目标市场外=我方楔子
   面从"自证价值"进入"品类已验证+官方未覆盖"的获客窗口。
2. **谁会付费**：CI 门禁预算=DevSecOps; 官方 preview 的 GHAS 按席费
   把中小团队/自托管/隐私敏感行业（等保/政务/金融）推向我方免费开源
   +离线面; 付费转化路径=企业定制映射（行业合规）+支持服务, 非功能
   付费（功能全开源是楔子策略, 非放弃商业化）。
3. **为什么是我们**：111 天双基线曲线+708 探针 0.00% 漏检+byte-identical
   裁决=**时间不可伪造的信任资产**; reizan-injectgate（10-29）证明
   "无 LLM judge"哲学正在被行业收敛, 但新进入者没有曲线——先发优势
   从"叙事独特性"转移到"积累深度"。
4. **为什么不成立**：风险=① GitHub 向确定性/离线面扩张（CodeQL 本身
   就是确定性引擎, 加 prompt 规则集技术上不复杂）→ 对冲=曲线积累速度
   +双基线自证（官方不会为开源小项目做"每次发版追加机器记录"的纪律）
   ② promptfoo 收购后免费开放静态面 → 对冲=其商业重心在动态/云面
   （hosted generation 被绑定即是信号）。

## 五、对抗性自审（本方案自身的弱点）

- **N3 对比表=营销失实高风险面**：对比项必须逐条引源（changelog/
  README/论文 DOI）, 且"竞品弱点"表述只能写"未提供 X"（事实）不能写
  "X 很差"（评价）; prompt-armor"5 层确定性"主张引用时须精确到层级
  （层 2/3 是 DeBERTa/embedding=学习面）。
- **N5 数据集许可**：论文 CC BY 4.0 ≠ 数据集同许可, 下载前须核
  FREEZE_MANIFEST/dataset 页; 若许可不兼容=放弃 N5 改自建扩样
  （不违规用数据）。
- **N1 tag 解码的 TN 面**：tag 字符合法用途极罕见（CSS tag() 是
  渲染面不是文本面）, 解码引入 FP 的风险≈0, 但测试已含 TN 护栏
  （阿拉伯语 LRM/全角技术段）钉死。
- **E2 取证边界**：全角引语误报面只取证了 5 个构造形态, 真实用户
  语料中的引语分布未测——P2-35 的 T1 条件（≥2 独立真实 FP）未满足,
  立规前不得动手（纪律留痕）。
