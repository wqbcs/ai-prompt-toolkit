### 2.2 终止判据（二阶信号核心: "何时停"从人读变机器观察）

- **T1 构成式终止**: P163 地板 prompt 占比 ≥ 80%（非地板 ≤ 3）→ 声明"触底":
  程序从率目标制转入构成监控制——此后率变动由分母/TP 面主导, 继续率治理
  ROI→0
- **T2 证据式终止**: 某批治理中 0 条规则满足 T1 门槛（≥2 独立真实 TP 取证 +
  纯 FP 根因定性）——剩余命中全有 TP 支撑 = 检测下限, 停止率治理
- **T3 ROI 式终止**: 单批降幅 < 2 prompts 且该批取证成本 > 降幅价值——边际
  ROI 反转

三者任一满足即终止; T1/T2 满足时须新测试文件接管地板锚点（test_r315 先例:
绝对锚点随轮次移交）。

## 3. 分母扩张面（A3 衔接, 口径事件纪律）

NotInject 339 为现外部分母; A3（Garak/PINT 子集接入, 发布后）若扩干净样本
（如 +PINT 850 benign → 1189）, 同分子规模率自然下降——**纪律裁定**:

- 分母变更=**口径事件**非改进事件: rate 时间序列在跳变点须带口径标记
  （denominator 版本字段, 如 "notinject-339"→"notinject339+pint-benign-850"）
- ODT-1 棘轮跨口径点处理: 口径跳变点不参与非增比较（或分序列比较）, 防
  "换分母致率骤降"被误读为改进/被误判回退
- 内部 60 干净样本**不**作第二分母——口径增殖=信号稀释（不重复造轮子,
  单一外部分母面）
