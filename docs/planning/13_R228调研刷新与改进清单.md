  触发条件早已登记：07 R5（"OWASP 更新=固定触发器：重跑 gap-report+补探针+规则映射校"）

## 4. PM 四问反思（第一性原理 / 奥卡姆 / 对抗性 / 鬼才产品）

**Q1 定位是啥？** 确定性 Prompt 静态门禁——prompt 的 ESLint，CI 裁决层。
（不变。本轮竞品密度上升不改变定位：5 家都在做"prompt lint"，但只有我们
卖"逐字节可复现裁决 + 公开 precision 时间序列 + 零 LLM 成本"的组合。）

**Q2 核心价值是啥？** 每次裁决逐字节一致 + 零 LLM 成本 + <100ms + 离线 air-gap +
**模型厂商无关**（promptfoo 进 OpenAI 后新增第四句）。
（不变，新增佐证 §1.2/§1.4。规则数 261 仍是防守项不是楔子。）

**Q3 目前推进方向有啥问题？**
1. **（高，本轮修）标准过期**：OWASP 2026 已发布而我们映射停 2025——对我们卖
   "标准映射"的定位是正面伤害，且是已登记的固定触发器拖延。→ F1 本轮收口。
2. **（高，维持 12 轮结论）发布缺位**：5 家竞品已可 `pip/cargo/npx install`，
   我方 PyPI 不存在。所有采用物料（Action/pre-commit/扩展/文档站）的入口都是
   `pip install`。→ P0-03/P0-04 仍是唯一真阻塞；等待用户授权期间继续备料
   （F1/C1/C2 都是发布前内容件）。
3. **（中）叙事占位加剧**："ESLint for prompts" 从 2 家（12 轮）涨到 ≥5 家。
   → 主叙事必须完成向"可验证性"的切换（P5-11 误报曲线公开页是唯一竞品做不出的
   差异化资产，优先级维持上调 P2）。
4. **（中）检测面真实缺口被对标暴露**：内嵌代码 prompt 抽取（F2）、可移植性规则
   （F3）是 aiproof 验证过的真实需求。→ 下一轮做，不是凑数（有对标实证）。
5. **（低，陷阱确认）**：MCP 赛道看起来热闹（mcp-audit/mcpscan 功能多），但
   跟进其功能面（advisory feed/Semgrep SAST/live server 连接）= 依赖面扩张 +
   偏离静态确定性楔子。**不跟**，只做静态 config/description 面（已做 P2-20）+
   诚实边界声明（C2）。

**Q4 低价值打磨陷阱（本轮新增确认）**：
- 本轮差点踩的坑：**给 101 条 ReDoS 脆弱 pattern 全量重构**（R227 实测 2000 字符
  包络内全部 <100ms 后，重构=零收益+双基线漂移风险）——已正确判定为陷阱并批准
  不重构（R227 留痕）。
- 维持硬清单（01 §6 T1-T10），本轮无新增陷阱项。
