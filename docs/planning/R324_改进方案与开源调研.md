## 3. 定位反问（本轮鬼才 PM 四问）

**问 1：项目定位是啥？**
答：不变——LLM 应用提示词的确定性静态门禁（prompt 的 ESLint）。01 §1 定位 300+ 轮未漂移。
但 2026-10 赛道真貌刷新了**叙事的锚点**：从"我们有 271 规则+确定性"转向"字节级可复现的
双基线可信度 + 多语言 + agentic 面"。定位本身没变，变的是对外表述的重点。

**问 2：核心价值是啥？**
答：核心楔子=确定性/可复现/零 LLM/毫秒/离线（01 §2）。但本轮调研实证：这条楔子已成赛道
必备，不再是"竞品补不上"。真正竞品补不上的=**双基线棘轮时间序列（可被引用的可信度证明）
+ 多语言分基线**。→ 资源继续向"加深可信度自证 + agentic 面 + 采用摩擦"倾斜，而非"加规则
数量"（T1）。

**问 3：目前推进方向有啥问题？**
三个真问题：
1. **最大杠杆卡在用户侧**：P0-03（仓库公开）+ P0-04（PyPI 发布）⬜ 待用户，而整个 P1 采用面
   （Action/pre-commit/Docker/npm/VS Code/英文 README）都依赖它。产品私有+装不上=楔子对全世界
   不可证。→ 这是 #1 项（需用户，我无法代劳）；我能做的最高杠杆自主前置=**把首发体验做到
   零摩擦**（本轮配置环收敛即此）。
2. **"顶配/每端最优技术栈"字面解读=低价值陷阱 T7**：本项目是确定性离线静态门禁，核心楔子
   恰要求"单一代码库+零 LLM"；"铺多端最优栈"与楔子正面冲突。正确解读（01 §9 已裁定）=
   **架构分层解耦让任意端未来可接入（P4-06 占位已登记）+ 端按 ICP 信号逐个上（npm 优先
   P1-04）**，而非现在铺端。本轮拒绝按字面铺端。
3. **首发现验有真实断点**：`init` 产物被 `lint` 静默忽略（§5）——Day 0 "10 分钟接入"承诺在
   主力入口上是断的。→ 本轮修。

**问 4：低价值打磨陷阱在哪？**
历史 §6 硬清单（T1-T10）不变。本轮新增警惕：**"用顶配话术掩盖采用未发生"**——发布前做再多
内部打磨都不产生采用；最危险的是把"打磨"误当"推进"。§6 逐项留痕本轮明确拒绝的。

## 5. 本轮落地（即时最高杠杆自主项）

**C1：init/doctor --init 配置环收敛** — 修 Day 0 首发现验断点。

**根因（实测，逐行核对三源）**：配置面存在三命名漂移——

| 路径 | 落盘 | lint 是否读取 |
|---|---|---|
| `init`（主力） | `.prompt-cli.toml`（config.py 运行时 schema） | **否**（lint 首选发现只认 promptlint.toml/pyproject） |
| `doctor --init` | `.prompt-toolkit.yml`（YAML 子集） | 是（YAML rc 回退链） |
| P2-03 首选发现 | 找 `promptlint.toml` / `pyproject [tool.promptlint]` | 真源 |

→ 主力 `init` 产物被 `lint` **静默忽略**（项目 e2e docstring 早已点名此断点族"R186 init 配置
与自动发现链断裂"，但后续新增的 `init` 命令又重引入）。Day 0 "10 分钟接入" 在主力入口上断。

**修复（奥卡姆+不重复造轮子：复用既有 P2-03 发现/解析 + 既有 init/doctor 命令 + 既有 YAML
回退，只新增 1 常量 + 1 薄函数）**：
- `linter/project_config.py`：新增 `DEFAULT_PROMPTLINT_TOML`（P2-03 全 schema 单一真源模板，
  确定性无时间戳/无规则计数，防 R230-X1 漂移面）+ `write_default_config(target_dir,
  overwrite=False)`。
- `init`（template_commands.py）：落盘 `promptlint.toml`（经 `write_default_config`）；
  `--snippet` toml 片段切同一真源。
- `doctor --init`（cli_core.py）：经同一 `write_default_config` 生成 `promptlint.toml`
  （消除 doctor/init 双源）。
- **向后兼容**：`.prompt-toolkit.yml`（YAML rc 回退）仍被 lint 发现（存量不孤儿）；
  `.prompt-cli.toml` 用户的 lint 行为不变（此前也未被 lint 读取）。

**验证**：58 目标测试绿（含新增 `tests/test_r324_config_loop.py` 8 项：确定性逐字节一致 /
init→lint 首选发现命中闭环 / init==doctor --init 逐字节同 / P2-03 schema 可解析 / 幂等不覆盖 /
向后兼容）。全量门禁待 `release_gate --skip 1,2` 复跑。
