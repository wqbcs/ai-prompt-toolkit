# 09 · 执行路线图（R225-R232 轮次规划）

> 02 总板是"做什么"，本文是"按什么顺序、每轮交什么、卡住怎么办"。
> **轮（Round）定义**：一次 agent 会话推进 + 一次收口（门禁链全绿 + commit + push + CI 双绿 + 文档更新）。
> 估时口径：S=1 轮内可完成；M=2-3 轮；L=4-8 轮——本文按此把 02 的任务打包成轮。
> **铁律**：每轮 DoD 不达标不收口；收口动作=00 文档 §9 任务循环协议 8 步，无例外。
