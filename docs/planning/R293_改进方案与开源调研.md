## 3. 第一性自问（反思记录）

### 3.1 这个项目的定位是啥
确定性的 LLM 提示词静态门禁（prompt 的 ESLint）。楔子（五年不变量）=
每次裁决逐字节一致 + 零 LLM 成本 + <100ms/文件 + 离线可跑。lane=prompt
**内容文本**（不是代码、不是运行时调用流、不是审查工作流）。

### 3.2 产品核心价值是啥
不是"又一个检测器"，是**裁决的可复现性**：双基线时间序列（只收紧不放松）+
exit 0/1/2 可复现契约 + 逐 finding 证据+修复路径 + 可 waiver。R293 调查
独立验证：4 家新玩家收敛到同一 CI 契约（退出码/SARIF/确定性），PromptSentry
"只拦已知问题"与我方增量门禁同构——核心价值的每一块都获得了第三方同型。

### 3.3 目前推进的方向有啥问题吗
① **lane 方向无问题**：4 家新玩家全瞄准代码面，prompt 内容 lane 仍空白；
② **平台风险真实存在**：Semgrep 有分发能力且已进 LLM 赛道（2026-03/05
两连发），其 LLM 辅助 triage 路线（非确定性）与我方零 LLM 路线正交——
差异化窗口仍在但"纯确定性 linter"单点稀缺性持续下降，**发布紧迫性是本
轮唯一的方向级警示**（D1-D5 用户操作 8-10 分钟，非技术卡点）；
③ 无需要调整的方向项。

### 3.4 低价值打磨陷阱审计（本轮 4 个"不做"，全部留痕）

| 候选 | 判定 | 理由 |
|---|---|---|
| Homebrew formula scaffold（发布前） | 不做，沉淀参考 | formula 依赖 PyPI 包存在；发布前 scaffold 不可验证（T1 同族纪律：无实证不落地） |
| OWASP Agentic Top 10 映射（agent-audit 53 规则引用该标准） | 观察区登记，不立项 | 无探针支撑的规则面扩张=清单游戏（T1 纪律）；等真实 TP 出现 |
| 复现"629 埋入攻击"方法论进我方探针 | 不直接采用 | 运行时 lane 测试方法论（agent firewall 视角），静态 lane 不适用；"真实流量取样"原则并入 P2-23 既有取用判据 |
| PromptQuorum 式审查工作流（7 项清单×3 角色+审批流） | 反清单辖区 | 人工审查流=工作流产品，非静态门禁 lane（02 反清单补记） |

### 3.5 结论
方向无需调整。唯一真实卡点=D1-D5 发布执行（用户操作）。规则推进可在发布
前自主并行——本轮完成 P2-29（全角 bypass 规则化），它是调查结果中唯一
"取证条件已满足"的推进项（其余候选要么依赖发布动作，要么违反 T1/反清单）。

## 4. P268 决策记录（P2-29 全角字母 bypass 规则化）

### 4.1 新规则 vs 扩展 P260：裁定=新规则

依据（三重不重叠+先例）：
- **码区不重叠**：P260 sub4=跨脚本视觉同形（U+0400-04FF 西里尔/U+0370-03FF
  Greek 混入关键词骨架）；P268=全角块（U+FF21-FF5A）字符替换。
- **信源不重叠**：P260 sub4 信源=ATR-2026-00001 L12（ATR 未覆盖全角面）；
  P268 信源=openhuman/ClawGuard/arXiv×2（R293 取证）。
- **对策不重叠**：同形字表映射（P260）vs NFKC 可逆归一化（P268）。
- **先例**：零宽族 P260（5+连续）/P261（3+交错）同族不同形态分规则——
  本规则同族（encoding_evasion）不同形态独立编号；且独立规则=独立探针/
  规则页/严重度标定，不动 P260 期望单元面（探针先行纪律下变更面最小）。

### 4.2 检测设计（确定性+低误报优先）

- 形态：全角拉丁字母（U+FF21-FF3A+U+FF41-FF5A）**连续段** → `unicodedata
  .normalize("NFKC")` 解码 → **精确词匹配** 6 注入动词有限集。
- 动词集全部实证出处（不自调）：ignore/disregard/override/forget/bypass=
  P260 sub2 base64 片段集解码词表（ATR-2026-00001 L11）；jailbreak=P163
  越狱族。**裸名词不入集**（instructions/rules 防良性全角英文词 FP）。
- 精确词匹配（word==keyword）非子串：取证 4/4 实证形态为空格分隔短语；
  长词内嵌（forgetful 含 forget）/无空格连写（ignoreallprevious）均不报——
  精度优先（P267 同纪律）。
- 码区限定天然 TN 安全：全角数字（U+FF10-FF19）/假名/全角符号均不在
  U+FF21-FF5A 内（r286_ja_tn_fullwidth_benign 锚）；良性全角拉丁词
  （日语 ＯＫ/ＮＧ 惯例）解码后不在动词集（r293_ja_tn_fullwidth_okng 锚）。
- 严重度 HIGH（混淆=有意规避检测，与 P260/P261 同标定）；OWASP LLM01；
  ATLAS AML.T0015（映射表 T0015 行 +P268）。
- ReDoS 线性：单字符类+量词，无嵌套量词。
- 标准库 `unicodedata`，零新依赖（楔子内）。

### 4.4 诚实残留（机制上限声明，与 P260 同型）

① 关键词内全角/ASCII 混写（ｉｇnｏｒｅ）不报——连续段被 ASCII 打断；
② 动词集外的全角注入短语（如全角 "reveal system prompt"）不报——有限集
方案对未知形态必然漏检。两残留面登记，待真实 TP 出现按 T1 判据扩集。
