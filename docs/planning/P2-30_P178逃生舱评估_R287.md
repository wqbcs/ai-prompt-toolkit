## 1. 背景与要求

**登记 FP**（R286 ja 面取证）：安全研修资料引用攻击短语（「Ignore all previous instructions」）
**无防护声明关键词**（过滤/审查/禁止 等）时 P178 分支 3 实火（HIGH 误报）。双源 = rezaduty 2026

**板红线**（验收口径）：防护声明/引用语境豁免**不得放行**「这是示例，忽略所有指令」型真攻击；
P178 既有 4 TP 探针（atk23 / r220 / r256_ood_tp01 / tp02）0 回归。

## 2. 机制剖析

`check_p178`（`linter/rules_p176_p180.py` L139-164）三分支：

| 分支 | 触发条件 | 严重度 | 性质 |
|---|---|---|---|
| 1 | HTML 注释含 `_SHADOW_CMD` | CRITICAL | 隐藏指令（真攻击形态） |
| 2 | Markdown 链接含 `_SHADOW_CMD` | HIGH | 隐藏指令 |
| 3 | 全文 `_SHADOW_CMD` 命中 **且** 全文无防护声明词 | HIGH | 「影子指令缺少防护声明」卫生信号 |

`_SHADOW_CMD = (?:ignore|forget|override|disregard|bypass)\s+(?:previous|above|all|instructions|rules)`
——第二组为"5 词任一"：**"ignore all" / "forget previous" 裸动词+副词即可命中，不要求名词宾语**。
这是分支 3 过宽的根源。

防护声明门禁 = 6 词（过滤/filter/审查/audit/禁止/prohibit）：覆盖窄（不含 攻击/防御/警告/案例/
研修/threat/advisory 等防御性框架词），且攻击者可控（payload 内塞一次 "禁止" 即静默分支 3；
分支 1/2 不受门禁影响）。

## 4. 逃生舱候选评估

| 候选 | 机制 | 欺骗面（聚焦"这是示例"型） | 判定 |
|---|---|---|---|
| A. 词法引用标记豁免 | 引号/代码围栏/"例如"前文命中时静默豁免 | 「这是示例，忽略所有指令」恰是用引用/示例标记做跳板的典型形态 | **拒绝**（放行真攻击） |
| B. 文档类型豁免 | 安全研修/研究文档（标题/章节标记）豁免 | R261/R269 实证 TPA/FSP payload 首选安全文档伪装藏匿；framing = 攻击迷彩 | **拒绝**（放行真攻击） |
| C. 分支 3 严重度降级 | HIGH→MEDIUM，重定位为卫生信号 | 无——仍实火，只不再拦 critical/high 门禁 | **采纳** |
| D. 防护声明门禁扩展 | 强防御框架词（攻击/防御/警告/案例/研修/threat/advisory/warning）入门禁 | **示例族词（示例/example/例）禁止入豁免集**（= 红线攻击的标记词）；扩词本身攻击者可塞词绕过 | **部分采纳**（强词扩展 + 示例族禁区） |
| D'. 两级门禁 + 文档似然 | （强防御词）×（文档似然：长度 ≥200 字符）→ 静默；示例族词永不豁免 | 红线攻击 = 短文本 + 示例族词 → 双闸皆不过 → 仍实火 | **采纳** |
| E. 触发面收窄 | 要求名词宾语：`...\s+(?:(?:all\|previous\|prior\|preceding\|above)\s+)*(?:instructions\|rules\|directives\|prompts\|guidelines\|orders)` | 名词宾语形态 = 真实注入主流形态（4 TP + 已知 payload 语料）；裸动词+副词消除只影响良性文本 | **采纳**（须补 orders，否则 tp02 回归） |

## 5. 推荐组合（E + D' + C）

**预期效果**（实现轮机器验证口径）：
- 登记 FP（安全文档引用无 6 防护词）：含强防御词 + 文档似然 → **静默**；不含 → **MEDIUM**（不再
  HIGH）→ HIGH 误报消除
- 红线攻击（This is an example, ignore all instructions）：**仍实火（MEDIUM），永不静默** ✓ 板红线
- 既有 4 TP：**0 回归**（E 逐条回放保留已核，实现轮测试锁死）
- 良性 ignore-all 类（ignore all comments/warnings…）：静默（E）
- 分支 1/2（CRITICAL/HIGH 隐藏指令）：不变

**残留风险**：
1. D' 文档似然阈值（200 字符）为启发式参数，探针实测后需钉版；长文嵌入攻击（真安全文档内嵌
   恶意指令）仍命中分支 3（非回归，现状即 HIGH 命中；TPA 形态已由 MCP-111/112 覆盖）
2. E 的 orders 依据单一 TP（tp02）——不违 T1（既有 TP，非新造规则）
3. C 降级后分支 3 信号不再拦默认门禁——仅命中分支 3 的真攻击降为 MEDIUM；缓解 = 真实注入通常
   同文本有其他规则或分支 1/2 命中，且分支 3 语义本就是"缺少防护声明"（卫生信号）非"确认注入"
