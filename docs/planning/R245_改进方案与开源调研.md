## §3 落地内容

### 3.1 P3-10 CI 绿史徽章

- `scripts/check_ci_green_streak.py`（170 行）：
  - `compute_streak(runs, limit)` 纯函数：输入=Actions run 列表（newest first），
    输出=连续 success 链长度；非 success 即停；n/a（None）态处理
  - `fetch_recent_runs(workflow, limit=30)`：GitHub Actions REST（GH_TOKEN），
    只读；无 token/网络失败 → n/a 态（不红，徽章灰）
  - `render_svg(streak)`：SVG 生成，色阶固定（n/a=灰 / 1-6=黄 / 7-29=橙 /
    30+=绿），文案固定
  - CLI：`--workflow prompt-ci.yml --limit 30 --write-badge`；只读默认，
    `--write-badge` 才落盘 `badges/ci-streak.svg`
  - 退出码：0=成功（含 n/a 态），1=徽章写失败，2=参数错误
- `tests/test_r245_p310_green_streak.py`（13 测试）：
  - computeStreak 纯函数面：全 success/最近失败/中间断裂/空列表/limit 截断/
    n/a 透传/非 success 类型（failure/cancelled/timed_out）
  - render_svg 面：n/a 灰色/绿橙色阶/文案含天数
  - CLI 面：`--write-badge` 落盘/无 token n/a 态不红/参数错误 exit 2
- `.github/workflows/ci-green-streak.yml`（独立 cron，44 行）：
  - `schedule: cron "0 17 * * *"`（UTC 17:00 ≈ 北京 01:00）+ `workflow_dispatch`
  - `permissions: contents: write`（最小权限：只写 badge）
  - 步骤：compute（只读打印）→ write-badge + `git diff --quiet badges/`
    判断变化才 commit（无变化零 commit=git log 零噪音）
  - **无自触发环**：`badges/*.svg` 不命中 prompt-ci 任何 paths（src/tests/
    scripts/baselines/workflows/md/pyproject），badge commit 不触发主 CI
- README 徽章：`[![CI Green Streak](badges/ci-streak.svg)]`
- 首版徽章：本地无 GH_TOKEN → n/a 灰色态落盘（CI 首次 cron 后自动刷新为真实数字）
