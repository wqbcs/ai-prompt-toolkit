## 8. 鬼才 PM 四问

**Q1 项目定位是什么？**
确定性 LLM prompt 静态门禁 = **分层 LLM 防御里的 no-model baseline 层**（本轮 S7 文献
印证：Georgia Tech 建议报告 no-model baseline, Tom Ganz 实证 classifier 会被对抗后缀
翻转, Wagner 实证检测器只能作组合过滤层）。两面产品格局不变（簇 A 文件面 271 规则
+ 簇 B 配置面 P4-11 发布后）；本轮新增：簇 C（代码侧构造面）= 同桌不是对手（A8）。

**Q2 产品核心价值是什么？**
① **可自证**（双基线时间序列+operating curve+过防御+known-misses 一键机器复现——
本轮 S6 五源独立印证「固定低 FPR 检出率 + hard-benign FP + 可复现冻结集」正成为
行业报告语言, 我方是该语言的最强实现）② **零 LLM 离线逐字节确定**（S7 弹药：
分类器 12/12 被 GCG 后缀翻转 vs 我方裁决逐字节一致）③ **楔子组合规模**（271 规则/
708 探针/OWASP 2026 映射/五渠道/<100ms）④ **中文优先**（中国市场预算周期早期,
§6.1）。

**Q3 当前方向有什么问题？**
① **知名度空位**（未入任何 awesome/OWASP 清单, 竞品已入若干——R351 判定维持, 本轮
E2/E4 继续主攻）② **发布滞留**（v67.34.129-134 未推 tag, 用户侧 1 步 ~5 分钟——B1
维持, 本轮不代推）③ **scan 侧残留误报**（P2-34 DEF-ENC-001 gate 实测 FP——E1 本轮
裁决）④ **行业语言未对齐**（我方机制领先但 README 用词落后于行业正在收敛的术语——
E3 本轮补齐）⑤ 内部打磨边际收益递减（R351 判定不变, 本轮 0 纯打磨项）。

1. **「S6/S7 五源会不会是我方叙事的事后凑数？」** → 五源采集先于方案（§1 渠道表）,
   且方向一致是**对我方有利但非预期**的收敛（我方向来只做 lint 侧双基线, 本轮才把
   hard-benign/no-model baseline 术语对上）；对冲=引用全部留 URL+日期, 二手转引
   标注（Gartner/ICML Spotlight/CSA 均标注, 博客引用前回源核验）, 读者可自行复核。
2. **「E3 术语对齐会不会动到护栏数字被门禁抓？」** → 护栏脚本（sync_readme_metrics/
   check_language_baseline_readme）断言的是数字与徽章, 术语替换发生在 prose 面；
   执行后复跑两脚本 + 三语 README 测试文件（test_r214 族）验证。若某术语恰好被
   测试钉死, 该处不动（测试为准, 奥卡姆）。
3. **「E1 裁决会不会放过真攻击（逃生舱）？」** → P2-30/P2-31 方法论三护栏：既有 TP
   探针 0 回归 + 红线 pin（真实编码内容形态仍必须实火）+ 双基线不回归；裁决三态
   （收窄/守卫/保留）, 保留为默认安全选项。取证不达标（TP 面找不到实证）→ 保留
   不改, 留痕。
4. **「E2 博客草稿在仓内, 未发布, 是否『交付』？」** → 诚实边界：发布=用户侧动作
   （账号/渠道选择, 会话无发布权限）；本轮交付=可发布态草稿 + 渠道清单 + 引用留痕
   （复制即发）。不声称已发布（EXECUTION DISCIPLINE: 未验证不声称成功）。
5. **「为什么不本轮直接做 F4（过防御测量面）——它比 E3/E5 更『实质』？」** → F4 依赖
   P2-31 顺延决策（TN 语料三选一并拉取外部集）, 属测量面结构变更（T6 发布窗口纪律
   边界：新增基线文件+门禁步=结构变更, 发布后做）；且 S6 证据支持的是**内容面动作**
   （术语/叙事对齐）而非新机制——机制已在, 缺的是行业语言翻译。先做低门槛高杠杆的
   E2-E5, F4 入 R355+ 候选（清单 F4 已登记）。
