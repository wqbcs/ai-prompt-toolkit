# R249 改进方案与开源调研（执行轮：NotInject 硬负样本过防御基线 — 可信度"诚实度"面）

> 轮次：R249 | 日期：2026-10-08 | 版本：v67.34.41 → v67.34.42
> 性质：**可信度度量面补强轮**——零新规则、零探针改动、零新 core 依赖；
> 把业界公认的"过防御（over-defense）"度量（PIGuard/NotInject，ACL 2025）
> 落到本机确定性基线：339 条含触发词的良性语句上，通用安全族 89 规则命中
> 33.92%——这个数字此前无人测量、无人可见。本轮把它量出来、写进 README、
> 建时间序列数据基建（与双基线同纪律），为 R250+ 的过防御治理立基线。

## §1 定位与反思（鬼才 PM 自检，开工前）

**项目定位**：确定性的 LLM 提示词静态门禁——prompt 的 ESLint。
**楔子**（产品核心价值）：每次裁决逐字节一致 + 零 LLM 成本 + <100ms/文件 + 离线可跑。

**本轮反问四问**：

1. **定位是啥？** 让"被相信"有外部可复现的坐标。R242-R248 把**内部**可信度
   做到顶（60 干净样本 FP 0.91% + 150 探针漏检恒 0 + 33 点收紧史 sparkline），
   但内部数字有个未说破的软肋：**干净样本是自己选的**。业界（PIGuard ACL 2025、
   Meta PromptGuard 2、Lakera PINT 博客）共识是：真正区分工具好坏的是
   **过防御**——含 "ignore/cancel" 等触发词的**良性**语句会不会被误杀。
   我方 60 样本里没有一条是"讨论注入的良性语句"（用户粘贴攻击串进 support
   ticket、安全文档本身），这是 FP 基线的**盲区**，不是小缺口。

2. **问题在哪（实查，本轮联网+实测）**：
   - PIGuard（leolee99/PIGuard，ACL 2025，87★，MIT）发布 NotInject 数据集：
     339 条良性语句、每条含 1-3 个触发词、四主题（普通查询/技术查询/虚拟创作/
     多语言）——**就是为过防御设计的独立基准**，数据文件 91KB 可本地落盘。
   - 本轮实测（本机 lint_template 全链，0.7s，零 LLM）：通用安全族 89 规则
     （8 个 security 族 category，arkts/harmonyos 生态族排除——口径错误
     而非过防御信号）命中 **115/339 = 33.92%** 的良性语句。Top 贡献：
     P162(27)、P044(21)、P163(21)、P008(19)、P167(13)；排除面的 P226
     （arkts_security，32 命中，对中文"格调"房间描述误判）是疑似真缺陷，
     单列 P2-26 治理清单首项（不在口径里掩盖）。
   - 对照口径（诚实呈现，不藏）：内部 60 样本 FP 0.91% vs 外部 339 硬负样本
     33.92%——**差值就是盲区大小**。竞品 prompt-guard 自己在 OOD 数据集上
     recall 只有 ~20% 还"如实写进 README"，其"measured not vibes"叙事反而
     是获客点。我方 33.92% 如实公开+建时间序列=同一叙事、更强（有确定性+
     逐字节楔子背书）。
   - deepset/prompt-injections（662 条标注，263 注入/399 良性，Apache-2.0）
     是**漏检面**的 OOD 坐标（本轮 HF 接口连接失败，登记 P2-26 后续轮候选，
     不阻塞本轮 FP 面）。

3. **需要怎样调整？** 方向没错，但可信度叙事缺"外部锚点"。本轮收口
   P2-25（过防御度量面）：NotInject 落盘（MIT，LICENSE 留痕）→
   `ai_prompt_toolkit/overdefense.py` 单一真源（baselines.py 同形态：包内
   逻辑+样本进 data/，脚本与 CLI 复用）→ 确定性脚本（--json/--check）→
   release_gate 新步（append-only 时间序列 docs/overdefense_history.jsonl，
   与双基线同纪律）→ README 可信度节一行如实数字+出处。**R250+ 才动规则**
   （P2-26 治理清单，探针先行纪律，本轮不抢跑）。

4. **低价值打磨陷阱清单（本轮主动避开）**：

| 陷阱 | 判定 | 依据 |
|---|---|---|
| 本轮顺手修 32 条过防御规则 | ❌ 不抢跑 | 动规则=动裁决面，探针先行+双基线护栏纪律，单独立项 P2-26 逐条分析（P226 等疑似真缺陷需独立 TP/TN 探针实证）；本轮只度量 |
| 把 33.92% 藏起来/只写 0.91% | ❌ 禁止 | 诚实度是楔子延伸；竞品公开 OOD 差数字反而获客（prompt-guard recall ~20% 如实写进 README）；藏=可信度自毁 |
| 用 33.92% 立即做 CI 硬门禁（--fail-above） | ❌ 不做 | 首点=基线锚定轮，棘轮无历史无可比；R250 修规则后收紧阈值才有意义（双基线"只收紧不放松"同纪律）；本轮 --json 只测不判 |
| 引 sklearn/transformers 做 OOD 评估 | ❌ 不做 | 零 LLM 成本+core 零依赖楔子；过防御度量=规则引擎跑一遍计数，纯 stdlib 足够（实测 0.7s/339 样本） |
| 把 deepset 263 攻击样本本轮也拉进来 | ❌ 不抢跑 | 漏检面 OOD 是 P2-26 独立面（HF 接口本轮连接失败已实证）；FP 面与漏检面分开立项，一轮一主题 |
| arkts/harmonyos 生态规则计入过防御 | ❌ 排除（口径留痕） | 生态特定安全规则（arkts_security/harmonyos*）对通用语料命中=口径错误，只统计 category 含 "security" 且非生态族的 8 族 89 规则（通用+RAG+agent+推理安全面） |
| 把 NotInject 数据改造成探针进 golden_attacks | ❌ 不做 | 探针=该报的报了吗（expected 非空）；NotInject 是**不该报**的良性面，语义相反，混入破坏漏检基线语义 |

## §3 落地内容

### 3.1 过防御度量单一真源（P2-25）

- **数据落盘**：`src/ai_prompt_toolkit/data/external_bench/`
  （NotInject_one/two/three.json，91KB，MIT）+ `LICENSE_NOTES.md`
  （出处/许可/拉取日期/通道留痕；数据不改写，原样保存）。
- **包内模块** `src/ai_prompt_toolkit/overdefense.py`（baselines.py 同形态，
  样本进包=pip 用户可自证，R224-P0-1 纪律延续）：
  - 安全族 = category 含 "security" 且非生态族（R249 时点=8 族 89 规则），
    动态派生自 get_all_rules() 注册表（不硬编码规则 ID，规则增删自动跟随）；
    arkts/harmonyos 生态族排除口径写入 docstring+模块常量注释。
  - `load_notinject()`：按文件序读 3 个 json（确定性）。
  - `run_overdefense() -> dict`：全量 lint_template（apply_waivers=False，
    与漏检基线同纪律——度量绕过 waiver）→ 每 prompt 安全族命中集 →
    返回 rate/flagged 明细/per-rule 命中计数/top 规则（确定性排序）。
  - **零 LLM、纯 stdlib、确定性**（同输入同输出；无时钟面进结果字典）。
- **薄封装脚本** `scripts/check_overdefense.py`：
  - 默认：度量+append 一行到 `docs/overdefense_history.jsonl`（append-only
    时间序列，与双基线同纪律；**同 version 幂等覆盖末行**——release_gate
    重复跑不重复追加，文件序仍=时间序）
  - `--json`：JSON 输出（供 release_gate 消费/CI 断言）
  - `--check`：只读校验 jsonl 合法+字段齐全（不追加，append_baseline_history
    同形态）
- **接线**：release_gate 新步"过防御基线追加"（在 sparkline 步之后=数据链
  末尾；CI 经 --skip 1,2 自动继承，零 CI 改动）。
- **README**：可信度节（"为什么该信这个工具"下）加一行——硬负样本过防御
  33.92%（89 安全族规则 @ 339 硬负样本，NotInject/PIGuard ACL 2025）+
  一句话诚实声明（内部 60 样本 0.91% 是自选面，外部锚点见 jsonl 时间序列）。
  数字由 check_overdefense 真源计算，不手写漂移（sync_readme_metrics 后续
  轮可纳入，本轮手工核对一次+注释留痕）。
