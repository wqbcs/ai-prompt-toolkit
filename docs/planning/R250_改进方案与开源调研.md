## §1 定位与反思（鬼才 PM 自检，开工前）

**项目定位**：确定性的 LLM 提示词静态门禁——prompt 的 ESLint。
**楔子**（产品核心价值）：每次裁决逐字节一致 + 零 LLM 成本 + <100ms/文件 + 离线可跑。

**本轮反问四问**：

1. **定位是啥？** 把 R249 公开的数字**压下去**。过防御 33.92% 如实公开只是
   第一步；行业看的是曲线方向（"这个工具在变诚实"的收紧史叙事，与双基线
   33 点 FP 收紧史同构）。曲线只收紧不放松——过防御时间序列与双基线双线并进。

2. **问题在哪（R249 实查+本轮逐条 pattern 剖析）**：
   - **P226（32 命中，排除面=口径内最大单项）**：`_ANY_TYPE_PATTERN = \bany\b`
     忽略大小写——命中英语单词 "any"（"any accident"/"any questions"）。
     TS 的 any 类型只在 `: any`/`as any`/`any[]` 类型标注语境存在，
     **无上下文约束的正则=真缺陷**。
   - **P162（27 命中）**：`_CACHE_POISON_CTX` 含 `stor`/`hit` 裸子串——
     命中 "story"/"history"/"white"。`stor` 无词边界、`hit` 无词边界，
     **substring 级匹配=真缺陷**。
   - **P008（19 命中）**：中文 fallback 分支"任何/任意/所有裸出现即报"
     （"请描述关于'空'的任何信息"被报权限过宽）——宽量化词**无授权动词
     邻接**=检测无语义锚点，**真缺陷**；英文分支 `all`/`any` 同样缺 `\b`。
   - **P044（21 命中）**：两个 pattern（context 类 OR transfer 类）独立
     `any(p.search)` 命中即报——"history"（art history 作文题）+ 任一
     transfer 词组合爆炸。**部分真缺陷**：泄漏语义应为"有上下文**且**
     往外传"（AND 双信号），OR 是过宽设计。
   - **P163（21）/P167（13）判定=留 R251**：P163 的 `pretend/扮演` 语境
     与良性 roleplay 请求（"Can you pretend to be a tour guide"）在
     纯正则面**不可分**（需角色意图二阶信号，设计面更大）；P167 的
     `knowledge/information` 语境过宽但 DECL 面可扩（修面在声明侧而非
     语境侧）。两条各需独立设计轮，本轮不混入（一轮一主题）。
   - **可达上限（本轮原型实测，非纸面模拟）**：修 4 条（P226/P162/P008/
     P044）→ **20.94%（71/339）**；漏检率保持 0.0（127 期望单元）；
     内部 60 样本 FP 0.0091→0.0087 不升反降。P163+P167 留 R251 后再压
     （预计可再降 ~10pp，见 R251 候选登记）。

3. **需要怎样调整？** 方向无偏差，本轮纯执行：4 条 pattern 修复（每条
   先补 TP+TN 探针≥2 再动 pattern——探针先行纪律）→ 过防御时间序列第二点
   （33.92%→20.94%，首次收紧）→ 双基线不回归验证。P163/P167 登记 R251。

## §3 落地内容

### 3.1 探针先行（先于 pattern 改动落 golden）

4 条规则 ×（TP×2 + TN×2）= **16 条新探针**（探针 150→166，
expected 单元 127→135）：

- **P226**（ArkTS 类型绕过）：
  - TP：`let buf: any = readRaw();` 无 strict 声明（any 类型真绕过）；
    `// @ts-ignore` 注释绕过真形态
  - TN：NotInject 派生"any"英语单词句（"prevent any accident"）×2
- **P162**（缓存投毒防护缺失）：
  - TP：Redis 缓存用户会话无签名/过期策略（真缓存投毒场景）×2 形态
  - TN：NotInject 派生 "story/history" 作文题（"journey to Mars"）×2
- **P008**（权限过宽）：
  - TP：「你可以执行任意命令」/「the model may access all files」（真过宽授权）
  - TN：NotInject 派生"任何信息"描述请求（"关于'空'的任何信息"）×2
- **P044**（上下文边界侵蚀）：
  - TP：「Agent 将会话历史传递给第三方 API」×2 形态（真上下文外泄）
  - TN：NotInject 派生 "art history" 作文题 + "secure password" 讨论句×2

**探针来源纪律**：TN 从 NotInject 命中样本派生（R249 数据直接复用，
零新语料成本）+ 出处 note 标注 `source: NotInject #N`；TP 为人工构造的
真实攻击/缺陷形态（与 golden 既有探针同形态）。

### 3.2 pattern 修复（4 条，最小必要修改）

| 规则 | 缺陷 | 修复 | 手法先例 |
|---|---|---|---|
| P226 | `\bany\b` 忽略大小写命中英语 any | `_ANY_TYPE_PATTERN = r'(?::\s*any\b\s*[;,)\}\]]\|as\s+any\b\|\bany\s*\[)'` — any 仅在类型标注语境（`: any`/`as any`/`any[]`）计数；@ts-ignore 分支不变 | 负向上下文约束（ai-tc skill 第 2 步） |
| P162 | `stor`/`hit` 裸子串命中 story/history/white | `stor`→`storage\|storing\|\bstore\w*`（真存储语义）；`hit`→`\bhit\w*`（词边界，"white" 不再中） | 词边界断言（ai-tc skill 第 2 步） |
| P008 | 中文 fallback 宽量化词裸出现即报；英文 all/any 缺 \b | 英文分支 `任何\|任意\|所有\|\banything\|\beverything\|\ball\|\bany`；中文 fallback 改为**授权动词邻接**：`(?:可以\|允许\|准许\|授权\|放行\|let\|may\|can\|allowed)\s*[^。！？\n]{0,20}(?:任何\|任意\|所有)`（动词后 20 字内出现宽量化词才算授权） | 共现门（ai-tc requiresNearby 同型） |
| P044 | context 类 OR transfer 类独立命中即报（组合爆炸） | 改 **AND 双信号**：`_H4_CTX.search AND _H4_XFER.search` 同时命中才进入 DECL 判定（泄漏语义=有上下文**且**往外传）；BOUNDARY 豁免面不变 | 共现门（ai-tc requiresNearby 直接先例） |

**不动项**：4 条规则的 severity/remediation/OWASP 映射/rule_id 全部不变；
P163/P167/P009/P160 等 R251 候选规则本轮零触碰。
