## 0 · 定位反问（每轮必答，本轮结论）

### 0.1 这个项目的定位是什么

**确定性的 LLM 提示词/agent 配置静态门禁**——prompt 的 ESLint/gitleaks。四不变量楔子：
逐字节一致裁决 + 零 LLM 成本 + <100ms/文件 + 离线可跑。

**赛道坐标（本轮外部验证坐实）**：2026 提示词安全工具链被**动态评估/红队**工具主导
（promptfoo 33.8k★、NVIDIA Garak、Microsoft PyRIT、UK AISI Inspect AI、DeepPMD）——它们回答
"这个 prompt 在模型上表现如何 / 模型是否可被攻破"（慢、LLM 成本、在线）。**本项目是不同的
niche**：回答"这个 prompt **文件**在合入/上线前是否结构合规 + 注入安全"（快、零 LLM、离线、
可进 CI 门禁）。**不与之竞争，互补**——动态评估在 CI 尾部跑，静态门禁在 PR 时跑。

### 0.2 核心价值是什么

**可信度，不是规则数**。本轮外部数据给出关键证据（devsecops.space 2026 市场报告）：
"按 GitHub star 排序的前三名，不是企业真正在跑的产品；受监管生产环境部署最多的两款
（Lakera Guard、Microsoft AI Red Team）在 GitHub 上最不显山露水。"

→ **star ≠ 采用**。本项目 00 板行长期追踪竞品 star 数是**误导性指标**。真正的护城河是：
字节级双基线（可复现的漏检/误报率）+ 确定性（同输入同输出，可审计）+ OWASP 2026 映射
（262/267）。这些是**可证明**的，star 不是。**产品本体=可信度楔子，规则数=table stakes。**

### 0.3 方向有什么问题 / 需要怎样调整

**真问题只有一个：采用瓶颈是用户阻塞的（P0-03 公开 + P0-04 PyPI），不是技术。**
项目内部已到极高成熟度（271 规则 / 多通道 / 27 步门禁 / 双基线 / 过防御面），但仓库私有 +
未上 PyPI = **零外部用户**。332 轮内部打磨 × 零外部用户 = 内部可信度在空转。

**调整**：
1. **杠杆 #1（我无法自主）= 推动 P0-03/P0-04**。这是 ~10 分钟的用户动作，解锁整个 S2
   "被采用"阶段。任何内部工作在其解锁前都乘于零。
2. **杠杆 #2（我可自主，外部验证）= 检测深度，不是规则广度**。两处被外部量化为"紧迫"的
   检测缺口（见 §1.3/§1.4）：编码变形规避（占真实规避 65.4%）+ agent 配置面（84% 网络抓取
   缺口）。这是**真能力**，不是打磨。
3. **停止**：追 star / 铺端 / 加规则凑数 / 上 LLM 动态检测（稀释楔子）。

### 0.4 低价值打磨陷阱（本轮明确拒绝，对抗性审查结论）

| 诱惑 | 为什么是陷阱 | 处置 |
|---|---|---|
| 追 GitHub star / 营销 / "做 #1" | 市场数据：star≠采用，真企业玩家 star 最低 | 拒绝；投入转可信度+分发 |
| 加规则凑数（271→更多） | 规则数=table stakes，广度已到顶，边际价值低 | 拒绝；转检测**深度** |
| 每端最优技术栈 / 铺端 | 反清单"不为全端而全端"；CLI/LSP/MCP/VSCode/Docker/Action 面已全 | 拒绝；核在检测深度 |
| 上 LLM 动态检测（对标 promptfoo/garak） | 稀释确定性楔子，进对手主场，慢/贵/在线 | 拒绝；确定性是本分 |
| i18n / playground / 负向规则行级定位 | 反清单既有 ⏸/拒绝项 | 维持拒绝 |
| 更多内部门禁步 / 更多自证脚本 | 332 轮已把内部纪律拉满，边际=过度工程 | 拒绝；除非暴露真 bug |

## 1 · 外部新鲜信号（R332 后调研，2026-10-20）

### 1.1 赛道格局：确定性静态 vs 动态评估/红队

- 动态/评估/红队（LLM 成本、在线、慢）：promptfoo、Garak（NVIDIA）、PyRIT（MS）、
  Inspect AI（UK AISI）、DeepPMD、Lakera Guard、Protect AI（Robust Intelligence）。
- 静态/确定性（本项目 niche，少）：gitleaks/trufflehog（secret 检测范式）、LintLang
  （agent 配置，16 模式）、promptguard.dev（含 23 编码变形测试）。
- **空位**：把"确定性静态"做到"字节级双基线可信度"的项目极少——这是本项目的护城河空位。

### 1.2 关键市场数据（devsecops.space，2026-05）

> "按 GitHub star 排序的前三名，不是企业真正在跑的；受监管生产环境部署最多的 Lakera Guard
> 与 Microsoft AI Red Team，在 GitHub 上最不显眼。"

→ **star 是误导性采用代理**。本项目应优化**分发**（PyPI/CI/pre-commit）+ **可信度**
（双基线/确定性/OWASP），而非 star。00 板行的竞品 star 追踪降级为"背景参考"，非北极星。

### 1.3 注入规避量化（arXiv 2509.22241，2025-09，"Prompt Evasion in the Wild"）

- **12.8%** 的真实世界 prompt 能绕过至少一个商业安全扫描器。
- **65.4%** 的规避 prompt 利用**编码变形**（base64 / hex / ROT13 / Unicode 转义序列）。
- 仅 **21%** 靠简单关键词替换成功——多数靠编码 + 多步。

→ **坐实本项目 normalization 缺口是真实世界主导规避向量**。R330 07 X2 已登记：prompt-guard
覆盖 7 种变形，本项目仅覆盖 2/7，缺 5 种（hex / \u00XX 转义 / rot13 / leetspeak / homoglyph）。
**外部 65.4% 数据把"补这 5 种编码归一化"从"锦上添花"升级为"堵主导规避向量"。** 复用资源：
promptguard.dev 测试套件（100+ 用例，含 23 编码）+ 本 arXiv 分类法 → 取 ≥2 真实 TP 满足 T1。

### 1.4 agent 配置面（agentguard.dev，2026-10）

- 语料：**261 个 agent 文件**（CLAUDE.md/AGENTS.md 等）/ 18,200 公开仓库。
- **84%** 允许任意网络抓取（curl/wget/requests 在 64% 配置里）= 注入点（agent 抓取恶意网页）。
- **97%** 无输出限制（agent 可回显 secret/token）。
- 仅 **44.9%** 有显式工具限制。
- **22%** 在 CLAUDE.md 里明文 API key。
- **76.3%** 用自然语言规则（零机器强制）="AI-washing"（规则只给人读，无机器执行）。

→ **外部坐实 agent 配置面是真实且紧迫的攻击面**。本项目 LintLang（R242-X2，检测 AGENTS/
CLAUDE.md 16 风险模式，本仓 AGENTS/CLAUDE.md 是首批自证语料）定位精准。**复用**：agentguard
261 文件语料 → 取 ≥2 真实 TP 深化 16 模式检测。

### 1.5 可复用组件清单（不重复造轮子）

| 资源 | 用途 | 取什么 |
|---|---|---|
| promptguard.dev 测试套件（100+ 用例，23 编码） | normalization 缺口 T1 探针 | hex/转义/rot13/leetspeak/homoglyph 真实 TP ≥2 |
| arXiv 2509.22241 规避分类法 | 编码归一化规则的威胁模型 | 65.4% 编码占比 + 多步规避形态 |
| agentguard.dev 261 文件语料 | agent 配置面 T1 探针 | 明文 key/网络抓取/零强制真实 TP ≥2 |
| OWASP GenAI 2026（LLM01/08/09/10） | 规则映射权威源 | LLM08(vector+poisoning) 最被低估，本项目 P177/P188/P189 已覆盖 |
| gitleaks/trufflehog（secret 检测范式） | 本项目 secret 面（P006/P266/P267）对标 | 熵+正则+allowlist 三段式（已对齐） |

## 2 · 改进方案清单（按杠杆排序，对齐确定性楔子）

### T0 · 用户授权（唯一真瓶颈，我无法自主——最高杠杆）

- **P0-03** 仓库转公开 + **P0-04** PyPI 发布。~10 分钟用户动作，解锁整个采用阶段。
  解锁后同轮收尾：P5-13（GH topics/org profile）+ P1-08（60 秒 Quickstart）+ P5-14（权威背书）。

### T1 · 自主高价值（外部验证的检测深度，T1 探针先行）

1. **编码归一化缺口**（§1.3，65.4% 主导向量）：取 promptguard 编码测试 ≥2 真实 TP →
   补 hex / \u00XX / rot13 / leetspeak / homoglyph 归一化 → 规则（OWASP LLM01 映射）。
   **这是"堵真实世界主导规避"，不是打磨。** 前提：先验证这 5 种变形当前确实漏检（TP 红）。
2. **agent 配置面深化**（§1.4，R242-X2 LintLang）：取 agentguard 语料 ≥2 真实 TP →
   深化 16 模式（重点：明文 key + 网络抓取白名单 + 输出限制缺失）。

### T2 · 自主正确性（R333 本轮执行）

- **P3-21 相邻面**：非增量 `--fail-on critical` 的存量 high 覆写判定（R331 登记，独立验证面）。

### 明确拒绝（陷阱，见 §0.4）

追 star / 铺端 / 加规则凑数 / 上 LLM 动态检测 / i18n / playground / 负向规则行级定位。
