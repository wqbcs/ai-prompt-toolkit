## 4. 改进清单

### P0-1: P258 伪系统标签规则（新规则, B5 模板）【核心】
- **语义**: prompt 文件出现系统级分隔符标记（`【系统】`/`[SYSTEM]`/`<|system|>`/`<<SYS>>`/`{{SYSTEM}}`/`SYSTEM:`
  类）= 特权边界操纵面 — 标记会被模型当作权限边界, 作者必须显式声明其合法性
- **gate 面**（三信源并集, 逐词核对）: ATR-00001 L7（英文方括号/尖括号族）+ ATR-00002 L3
  （模型 chat template token 族）+ ATR-00097 ja（【システム】族）+ 中文【系统】/【管理员】
- **放行面**: **近邻声明**（tag ±80 字符内含 示例|演示|教学|样例|few.?shot|example|引用）—
  **刻意比 P257 的文件级声明更严**: 伪标签的特权强度高于 RAG 语境, 文件级放行太松
  （prompt 里 "example" 高频, 如 "Give an example..." 会误放行）; Willison 信源#9 实证
  对话格式本身不安全性 → 只有显式"这是示例"声明才能放行
- **severity**: HIGH（特权提升机制, 对齐 P007 HIGH; P257 是语境缺失=MEDIUM, 标签是主动操纵=HIGH）
- atk48（ja）从观察型转 `expected: ["P258"]`

### P0-2: 人格切换 — 数据裁决, 不预设做不做
- **对抗性结论（先说）**: "你是新的助手"单独是 prompt 编写**最高频合法句**（"You are a helpful
  assistant" 的变体）— 宽面规则 = 误报陷阱, 违反 0.92% 基线纪律
- **攻击信号 = 复合面**: 身份重赋值（你现在是…新的…助手/AI）**且** 前约束作废
  （之前的约束/限制/规则…无效/废除）共现
- **决策规则（数据驱动）**: B1 扩 3 条探针（zh/ja/en 复合面）→ 量化: 复合 pattern 命中 3/3
  且 58 clean + 15 内置模板 0 命中 → 落地 P259; 任一 clean/模板命中 → **不做**, atk47 维持
  观察型 + 矩阵登记"分析化解（宽面误报陷阱, 复合面数据不达标）"

### P0-3: P260 编码/混淆注入面规则（新规则, 全机械, 无新启发式）【核心】
- 五个子 pattern（全部有限集/阈值, 阈值与集合直接复用 ATR 实证值, 非自调）:
  1. **零宽/bidi 5+ 连续**（ATR-00002 L2 阈值 — 信源明示 5+ 是为避开合法 RTL 文本）
  2. **8 个已知 base64 片段**（aWdub3Jl/ZGlzcmVnYXJk/b3ZlcnJpZGU/Zm9yZ2V0/YnlwYXNz/
     c3lzdGVtIHByb21wdA/aWdub3JlIHByZXZpb3Vz/aWdub3JlIGFsbCBwcmV2aW91cw — ATR-00001 L11）
  3. **base64/hex 长串 + 解码指令共现**（ATR-00001 L10: decode/interpret/execute… 动词 +
     `[A-Za-z0-9+/]{20,}={0,2}`）
  4. **同形异码 西里尔/Greek 范围混入注入关键词**（ATR-00001 L12: `[\u0400-\u04FF\u0370-\u03FF]+`
     与 gnre/verrde/ystem 骨架共现）
  5. **hex/URL 百分号编码注入关键词**（ATR-2026-00001 L14 有限集: `%69%67%6e%6f%72%65`=ignore /
     `%64%69%73%72%65%67%61%72%64`=disregard / `%6[fF]%76%65%72%72%69%64%65`=override /
     反斜杠x形式 `\x69\x67\x6e\x6f\x72\x65`）
- **诚实声明（机制上限）**: 有限集方案对**未知**编码载荷必然漏检（如 base64("删除所有数据")
  不在 8 片段集）— 语义层（embedding 类, 参照 Anthropic JWE）超出本项目静态机械定位,
  文档声明不藏; 本规则价值 = 捕获**已知最高频**的 5 类编码绕过（garak 编码探针族全量覆盖）
- **severity**: HIGH（混淆 = 有意规避检测, 恶意信号强）
- garak `owasp:llm01` tag 印证分类归属

## 5. 对抗性审查（对本方案）

1. **P258 近邻放行面 ±80 字符**: 攻击者可把"示例"声明放在标签 80 字符外 + 真实载荷放标签内
   → 不绕过（载荷仍触发, 声明无效因为距离外）; 合法作者把"以下为例"写远 → 漏检, 但这是
   作者自己声明不清, 门禁语义合理（声明必须近邻标签才有效 = ESLint disable 注释近邻原则）
2. **P258 与 P257 放行面不一致（近邻 vs 文件级）**: 故意设计, 理由已写入规则注释
   （特权强度决定放行严格度）— 评审若认为应统一, 用双基线数据裁决
3. **P260 零宽阈值 5+ 的误报面**: 58 clean 无 RTL 文本 → 本轮 0 风险; 未来 RTL 样本进入时
   ATR 的 5+ 阈值是实证值（非自调）, 风险有信源背书
4. **P259 复合面的合法场景**: "你是新客服助手, 之前规则作废, 用新规则"（规则更新声明）
   会命中复合面 → **真实误报风险**, 因此数据裁决门槛设为"58 clean + 15 内置模板 0 命中"
   （比新规则只查 clean 更严 — 内置模板是真实 prompt 形态样本）
5. **规则数膨胀检查**: 本轮最多 +2 规则（P258/P260, P259 数据不达标则 0）, 每条都有
   观察探针/信源/量化数据支撑 — 非指标膨胀（规则数是能力指标, 不是装饰指标）
6. **先扩样后实现纪律**: B1 只加探针不动规则 → 量化结果写入方案文档追加段 → B2 才实现 —
   量化数据与实现决策分离, 可审计
