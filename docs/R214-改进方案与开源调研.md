# R214 改进方案与开源调研（多语言检测面 — 增量轮）

> 定位: R213 后的下一轮循环。R213 已解决"规则数量/豁免/MCP面/新规则流程",
> R214 解决**检测语言面缺口** — 实测证明攻击者换日语即可绕过全部 257 条规则。
> 本轮为增量调研（复用 R213 的 10 信源基础, 新增 4 信源只针对多语言方向）。

## 一、定位反问（第一性原理, 承接 R213）

- **项目定位**: 零 LLM 确定性静态 prompt 安全/质量 lint（ESLint for LLM prompts）。
- **产品核心价值**: 让团队在 CI 中**机械可复现**地发现 prompt 安全/质量缺陷。
- **本轮核心判断**: 257 条规则的语言面近乎纯中英（42 golden 探针 41 中文/1 英文/0 日语/
  0 emoji）。这不是"指标没做满", 是**真实安全能力缺口** — 实测 4 个日语攻击变体
  （系统提示词泄露/直接注入/RAG边界/硬编码凭据）**全部漏检**。确定性工具的价值
  建立在"覆盖声明"可信上, 覆盖语言面是声明的一部分, 不修则 README 的"多语言"
  能力是虚的。
- **方向自审**: R213 连续做了"规则数+流程+配置面", 本轮若再堆规则数是指标膨胀;
  多语言面是**同一批规则的真实能力补全**, 不新增规则数量（只扩 pattern 语言面 +
  探针扩样）— 与"反指标膨胀"纪律一致。

## 二、增量调研结论（4 信源, 思路复用非代码）

| 信源 | 关键结论 | 对本项目 |
|---|---|---|
| **garak-multilingual**（fevziegeyurtsevenler, 基于 NVIDIA garak Apache-2.0） | 8 语言（tr/de/es/ru/ar/zh/fr/fa）注入探针包; 每条 payload 带 provenance note（标注语言技巧/原型）+ BCP-47 标签; 映射 OWASP LLM01/ATLAS T0051; 土耳其 İ/ı casefold 绕过专门成类 | ①**其 8 语言不含日语** — 日语缺口是行业普遍盲区, 我们补它即差异化 ②per-payload provenance note 与 BCP-47 标签直接借鉴进 golden 探针 schema ③语言面覆盖≠优越, 是"complement"定位（不替换现有中英 pattern） |
| **ATR-2026-00097 CJK injection patterns**（Agent-Threat-Rule, 开源 YAML 规则库） | CJK（中/日/韩）注入权威 pattern 源; 日语 5 类: 忽略先前指令/系统提示词提取/人格切换/金融操作绕过/伪造系统标签; **evasion_tests 实证三种绕过**: CJK 空格插入（"忽 略"）/语言切换/口语化改写 | ①日语 pattern 词表（指示|指令|ルール + 無視|忘れ|スキップ 等）作参考词源 ②**空格插入是已实证绕过** — 需决策处理 ③其分层架构（英文主规则 + CJK 独立权威规则文件）印证"语言面独立文件"的架构选择 |
| **llm-fw PR#77 "Catch prompt injection in every language"**（PIsberg） | "无通用多语言机制时, 覆盖是**偶然的**（瑞典被拦, 乌尔都/印地静默通过）"; embedding 模型跨语言对齐是运行时方案; 启发式归一化必须保留变音符（日语促音 small-kana 会被 diacritic-strip 破坏）; 终态 21/22 语言廉价阶段拦截 + **零误报**双口径 | ①"覆盖是偶然的"直接支持本轮价值判断 ②embedding 方案**不适用**（我们零 LLM 静态定位红线, 不做 ML 阶段）③日语促音/变音符号不能粗暴归一化 ④"拦截+零误报"双口径 = 本项目双基线纪律的同构印证 |
| **openclaw-defender**（nyosegawa, 零运行时依赖 3 层防御） | Layer1 规则层 **语言×攻击类型覆盖矩阵**（9 语言 × ignore-previous/new-role/system-prompt-leak/jailbreak, 逐格标注 yes/—） | ①覆盖矩阵是语言面覆盖的**可审计文档形态**, 直接借鉴（docs/语言面覆盖矩阵.md）②日语 4 类全 yes 证明日语规则化可行 ③不要求 9 语言全满（葡/阿 3 格为 —）— 覆盖深度按语言分级, 不平均主义 |

**调研红线核对**: 所有信源的多语言检测均为确定性 pattern（cheap stage）—
与我们零 LLM 定位一致; embedding/LLM 判官属运行时防御阶段, **明确不做**
（会破坏"机械可复现"核心价值, 且引入模型依赖 = 技术栈绑定, 违反约束）。

## 四、改进清单（按优先级）

### P0-1: 修复 P241/P243 `name` 子串盲区（R213 审查发现, 小且安全）
- `_PERSONAL_DATA_PATTERN` 裸 `name` 子串误配 "namespace"/"rename"/"filename"
- 加词边界 `\bname\b`（与 B5 race 修复同型）; 重跑双基线

### P0-2: 日语语言面扩展（核心 — 实测 4 条漏检规则）
- **先扩样后修规则**（R213-B5 立下的纪律, 本轮沿用）:
  1. golden +6 日语探针（系统提示词泄露/直接注入/RAG边界/硬编码凭据/人格切换/
     伪系统标签, 每条带 BCP-47 `lang` 标签 + provenance note, 借鉴 garak-multilingual）
  2. 跑漏检基线 → 量化日语漏检率（预计显著上升 = 暴露真实盲区, 不藏）
  3. 修复 4 条规则的日语 pattern 面:
     - P007 直接注入: 补 無視|忘れ|指示|ルール 词面
     - P113 系统提示词泄露: 补 システムプロンプト|プロンプトを出力 词面
     - P257 RAG 门: `_RAG_CTX_GATE` 补 検索|ナレッジベース 词面 + 日语声明面
     - P006/P051 凭据: 词面本就语言无关（sk-xxx 形态）, 排查为何漏检
       （疑似 CTX 门中文词 — 需定位）
  4. 58 干净样本 0 新增误报断言 + 双基线全量重跑（漏检回落 0.00%, 误报不破 0.93%）
- 词表参考 ATR-2026-00097（开源 YAML, 词源参考非代码复制; 逐词核对避免
  把其误报面一并搬入）

### P1-3: 繁体中文 + CJK 空格插入探针（暴露 → 数据决策）
- golden +4: 繁体变体（無視/忘記/跳過 词面）+ 空格插入变体（"忽 略"/"ignore the
  above instruc tions" 类, ATR evasion_tests 实证技术）
- **决策规则（数据驱动, 不预设方案）**: 跑完看漏检面 → 若空格插入漏检面广,
  候选方案 A（lint 入口 CJK 空白归一化层, 全规则受益, 但需 58 干净样本验证
  不产生新误报）vs 方案 B（仅高危注入 pattern 空格容忍）— 按误报增量选
- 若归一化新误报 >0 → 记录 L3, 本轮只做方案 B

### P2-4: 语言面覆盖矩阵文档（可审计形态）
- `docs/语言面覆盖矩阵.md`: 语言（中简/中繁/英/日）× 攻击类型（注入/泄露/RAG/

- 未覆盖格不藏 — 矩阵本身即 R215+ 的排期依据

### P2-5: 探针 schema 加 `lang` 标签（BCP-47）

  分面展示（分语言漏检率 = 语言面覆盖的机械度量, 无新启发式）

## 五、对抗性审查（对本方案）

1. **是否指标膨胀?** 否 — 不新增规则数量（257 不变）, 只扩既有规则 pattern
   语言面 + 探针扩样（42→52+）。指标变化（分语言漏检率）机械派生自既有
   expected 单元, 无手调权重。
2. **低价值打磨陷阱识别（明确不做）**:
   - ❌ 8 语言一次做全 — 日语是实测缺口且行业盲区（garak-multilingual 都没做）;
     韩/西/德等无实测证据, 需求未验证不排期（同 R213 npm 分发决策逻辑）
   - ❌ embedding/ML 多语言阶段 — 违反零 LLM 定位红线, 引入模型依赖
   - ❌ 无数据先做全局空白归一化 — 影响 257 条规则全局行为, 必须先有
     空格插入探针的漏检数据 + 58 干净样本的误报验证
   - ❌ 日语 pattern 照抄 ATR — 其实验规则可能带自己的误报面, 逐词核对 +
     双基线门禁兜底
   - ❌ emoji 专项 — 实测 emoji+英文不阻碍 pattern（emoji_inject 命中）,
     无真实绕过证据, 不投入
3. **奥卡姆**: P0 两项（name 词边界 + 日语面）覆盖全部实测漏检; P1 是暴露型
   扩样（成本=4 条探针, 收益=空格插入这个高危绕过技术的数据）; P2 是文档与
   schema（零行为改变）。
4. **不重复造轮子核对**: 日语词表参考 ATR-2026-00097 / 探针 provenance 借鉴
   garak-multilingual / 覆盖矩阵借鉴 openclaw-defender / 双口径纪律印证
   llm-fw — 全部思路复用, 零新依赖, 零新组件（除 P1 可能的归一化层, 且有数据
   前置门槛）。
5. **风险**: 日语 pattern 扩面可能抬误报（日语词撞中文干净样本? 干净样本
   41 中文, 日语词面如 システムプロンプト 与中文无交集, 风险低; 但 検索 是
   中文词"检索"的日文写法… 注意 `検索` 与中文 `检索` 是不同字符, 无碰撞）。
   门禁: 58 干净样本 0 新增 + 误报棘轮 0.93% 不破。
