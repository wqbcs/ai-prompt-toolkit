## 一、功能增添

### F1. Prompt版本管理与Diff追踪（参考Langfuse）
- **描述**：添加Prompt版本管理能力，支持版本对比、回滚安全检查增强、版本元数据追踪
- **参考**：Langfuse的Prompt Version管理 + prompt_diff.py已有基础
- **实现**：在prompt_diff.py中增加VersionManager类，支持git-like版本链、语义diff增强
- **优先级**：高 | **工作量**：2开发日

### F2. LLM-as-Judge增强评估（参考DeepEval/promptfoo）
- **描述**：扩展评估指标至30+维度，增加Agentic评估、MCP工具评估、Multi-Turn对话评估
- **参考**：DeepEval 30+指标 + promptfoo LLM-as-judge
- **实现**：evaluator.py添加AgenticDimension/MCPDimension/MultiTurnDimension
- **优先级**：高 | **工作量**：3开发日

### F3. 评估结果可观测性Tracing（参考Langfuse）
- **描述**：评估结果自动记录trace，支持时间序列分析、回归检测、评分趋势图
- **参考**：Langfuse Tracing + eval_store.py已有SQLite基础
- **实现**：eval_store.py增加trace表、趋势查询API、回归告警增强
- **优先级**：中 | **工作量**：2开发日

### F4. 华为云ModelArts推理端点集成
- **描述**：华为云ModelArts MaaS推理集成，支持昇腾NPU推理调用
- **参考**：华为云ModelArts API + 华为云ECS SDK
- **实现**：ab_test/providers/添加modelarts_provider.py + 昇腾NPU适配
- **优先级**：高 | **工作量**：2开发日

### F5. CodeArts Pipeline CI/CD集成（参考promptfoo）
- **描述**：华为云CodeArts Pipeline集成，PR自动lint+scan+evaluate
- **参考**：promptfoo的GitHub Action + 华为云CodeArts Pipeline API
- **实现**：添加.codearts/pipeline.yml模板 + CLI退出码规范化
- **优先级**：中 | **工作量**：1开发日

### F6. Prompt编译优化器（参考DSPy）
- **描述**：自动Prompt优化，基于评估反馈迭代改进Prompt文本
- **参考**：DSPy的GEPA/MIPROv2优化器
- **实现**：添加prompt_optimizer.py，支持基于评分反馈的自动Prompt重写
- **优先级**：低 | **工作量**：3开发日

### F7. P191-P195 AI Agent安全Lint规则
- **描述**：Agent安全规则(P191 Agent权限边界/P192 工具调用约束/P193 思维链泄露/P194 多Agent协调安全/P195 Agent记忆隔离)
- **参考**：garak的Agent probe + OWASP LLM Agent Top10
- **实现**：rules_p191_p195.py + OWASP映射
- **优先级**：高 | **工作量**：1开发日

### F8. 自定义Lint规则DSL
- **描述**：用户可通过YAML/Python自定义Lint规则，无需修改源码
- **参考**：promptfoo的自定义断言 + ESLint自定义规则
- **实现**：添加custom_rules/目录 + YAML规则解析器
- **优先级**：中 | **工作量**：2开发日
