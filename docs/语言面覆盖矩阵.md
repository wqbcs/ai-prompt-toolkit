## 语言面扩展的防误报纪律（B2/B3 验证过）

1. 精确复合词, 不加裸词（不加裸 プロンプト — 任何提 prompt 的日语 prompt 会误触 P113）
2. 每批扩面前后: 58 干净样本 0 新增误报断言 + FP 棘轮 0.01 不破（B2: 0.92% 持平,
   B3: 0.92% 持平）
3. 测试内建守卫: `test_r214_japanese_surface.py` / `test_r214_zhhant_split.py`
   的 clean 样本零命中断言 + P113/clean26 存量误报基线不变断言
4. 词源标注: 每条新增 pattern 注释标注 ATR-2026-00097 词源（思路复用非代码复制,
   逐词核对避免带入其误报面）
