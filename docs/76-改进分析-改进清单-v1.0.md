## 开源调查结果

### 1. llm-guard (protectai/llm-guard) ⭐3.2k — 已归档但可借鉴
- **输出扫描器**(我们缺失): NoRefusal, Bias, Relevance, FactualConsistency, MaliciousURLs, URLReachability, Sensitive, Gibberish, ReadingTime
- **输入扫描器**(我们部分覆盖): BanCode, BanCompetitors, BanSubstrings, BanTopics, InvisibleText, Language, Sentiment, Toxicity
- **关键痛点**: 缺少输出安全扫描是最大gap

### 2. promptfoo (promptfoo/promptfoo) ⭐23.6k — OpenAI收购
- **红队能力**: 声明式YAML配置 + CLI + CI/CD集成
- **代码扫描Action**: GitHub Code Scanning集成(我们已有prompt-lint-ci.yml)
- **模型对比**: 侧边对比矩阵(我们已有AB测试)
- **关键痛点**: 我们的lint规则覆盖面更广，但缺少promptfoo的Web UI查看器

### 3. garak (NVIDIA/garak) — LLM漏洞扫描器
- **Probe类型**: continuation, encoding, glitch, goodcode, knownbaddate, leakrev, etc.
- **我们已有**: 15 Probes + 8 Detectors, OWASP覆盖
- **关键痛点**: garak的encoding/glitch probe我们未覆盖
