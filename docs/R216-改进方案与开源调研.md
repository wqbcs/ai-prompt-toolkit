  边际收益 < 横切层一次封闭整个规避类。

  3. **归一化越界陷阱** — 只做 CJK-CJK ASCII 空格(有 W3C 依据), 不碰 U+3000/换行/
     CJK↔拉丁边界/谚文(各有相反惯例或合法用途), 误报面由双基线实证裁决;
  4. **观察探针清零陷阱** — atk72/atk73 观察型探针的"漏"是设计目的(量化缺口), 不以
     清零观察探针为 KPI。

## 4. 决策

### D1 — L3-14 裁决: 作用域受限的 CJK-CJK 空格归一化, 全局生效

- **变换**: 删除两个 CJK 字符之间（允许连续）的 ASCII 空格 0x20。CJK 类 =
  汉字(U+3400-4DBF, U+4E00-9FFF) + 平假名(U+3040-309F) + 片假名(U+30A0-30FF)。
- **严格边界（每条都有依据, 越界即回退）**:
  - 仅 ASCII 空格（U+3000 全角空格不碰 — CJK 排版中仍有合法用途, 真实案例出现再重评）;
  - 仅 CJK-CJK（谚文不碰 — 空格是韩文分词符; CJK↔拉丁/数字边界不碰 — 相反惯例要求空格;
    换行不碰 — 行结构必须保持, 行号契约依赖它）;
  - `{{...}}` 占位符内部不碰 — 渲染器契约（渲染引擎看原文; 占位符内空格致渲染器
    静默填不上 = P256 真实缺陷面, 归一化"修复"它 = 让 P256 失明于渲染器破坏性规避。
    B4 全量回归实证: 不排除则 test_malformed_placeholder_inner_space 失败）;
  - 匹配语义=归一化文本; **报告回映原文**（PromptSonar 同款）。
- **集成层**（关键设计）:
  - `normalize_cjk_spaces(text) -> (norm, pos_map)` 组件入 rules.py（共享, 机械, 无启发式）;
  - **包装器在 `_CHECKERS_EXTENDED` 构造处统一注入**（`functools.wraps` 保 `__name__`,
    FP 门禁的 `check_p*` 名称过滤不受影响）→ 所有调用点（lint 管线/FP 门禁直调/漏检门禁/
    profiled 版）行为一致, 零调用点改动;
  - **行号不变量**: 变换只删行内空格 → `location`（"line N" 字符串）天然正确, 无需翻译;
    仅 `details["position"]`（int 字符偏移, 如 P258）经 pos_map 回映原文索引;
  - **性能**: 每检查器调用归一化一次（260×O(n), 与多一次全文扫描同量级）, 不加缓存
    （零内存增长/零陈旧风险; profiling 证明是瓶颈再上 lru_cache, 一行改动）。
- **误报护栏（实证裁决, 不预支）**: 58 clean + 15 模板 FP 门禁 + 全量套件 + 漏检门禁;
  门禁若暴露新 FP → 逐规则处置（waiver/模式修正）, **不退回逐规则容忍**（碎片化即 L3-14
  问题的复现）。
- **探针裁决**: atk70（【系 统】）→ expected=["P258"]; atk71（你 是…）→ expected=["P259"]
  （翻转, expected 单元 68→70）。
- **与 R214 否决的关系**: R214-B3 否决的是"空白归一化**层**（含换行/CJK↔拉丁, 260 规则
  全局行为不可控）"; 本决策是其作用域受限变体（仅 CJK-CJK ASCII 空格 + W3C 学理依据 +
  双基线实证护栏）, 否决理由不迁移。
