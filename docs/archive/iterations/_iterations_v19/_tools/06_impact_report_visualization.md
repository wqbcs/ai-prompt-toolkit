## 影响评估报告模板

```markdown
# 提示词变更影响评估报告

## 变更概要
- **版本A**: v18.2.1 (2026-07-10)
- **版本B**: v18.3.0 (2026-07-12)
- **综合风险**: 🟡 中等 (0.42)

## 语义变更清单
| # | 类别 | 变更描述 | 评分 | 风险 |
|---|------|---------|------|------|
| 1 | 约束修改 | 输出长度限制从500→1000字 | 0.45 | 中 |
| 2 | 示例替换 | Python示例→Go示例 | 0.35 | 中 |
| 3 | 格式修饰 | 添加分隔线 | 0.05 | 低 |

## 受影响场景
| 场景ID | 场景名称 | 影响等级 | 需要测试 |
|--------|---------|---------|---------|
| S-012 | 代码审查 | 显著 | ✓ |
| S-023 | 技术文档 | 轻微 | ✗ |

## 兼容性矩阵
| 场景 | v18.2.1 | v18.3.0 | 迁移需求 |
|------|---------|---------|---------|
| S-012 | ✓ 兼容 | △ 部分兼容 | 需要 |
| S-023 | ✓ 兼容 | ✓ 兼容 | 不需要 |

## 建议操作
1. [高优先] 对S-012场景执行回归测试
2. [中优先] 验证输出长度变更对下游解析的影响
3. [低优先] 更新示例文档
```

## Diff可视化系统

### 可视化模式

#### 1. Side-by-Side（左右对比）
```
┌─ v18.2.1 ──────────┐┌─ v18.3.0 ──────────┐
│ # Role: 代码审查专家 ││ # Role: 代码审查专家 │
│                     ││                     │
│ ## 约束             ││ ## 约束             │
│ - 输出不超过500字    ││ - 输出不超过1000字  │ ← 变更
│ - 必须包含代码示例   ││ - 必须包含代码示例   │
│                     ││                     │
│ ## 示例             ││ ## 示例             │
│ 输入: Python代码     ││ 输入: Go代码        │ ← 变更
│ 输出: {...}         ││ 输出: {...}         │
└─────────────────────┘└─────────────────────┘
```

#### 2. Unified（统一视图）
```diff
 # Role: 代码审查专家
 
 ## 约束
-- 输出不超过500字
+- 输出不超过1000字
 - 必须包含代码示例
 
 ## 示例
-输入: Python代码
+输入: Go代码
 输出: {...}
```

#### 3. Semantic（语义视图）
```
🔴 [高影响] 约束修改: 输出长度 500→1000 (评分: 0.45)
🟡 [中影响] 示例替换: Python→Go (评分: 0.35)
🟢 [低影响] 格式修饰: 添加分隔线 (评分: 0.05)
```

#### 4. Impact（影响视图）
```
受影响场景热力图:
S-012 ████████░░ 80% (显著)
S-023 ██░░░░░░░░ 20% (轻微)
S-045 ░░░░░░░░░░  0% (无影响)
```

### CLI命令

```bash
# 对比两个版本
prompt-diff compare v18.2.1 v18.3.0

# 语义变更检测
prompt-diff semantic v18.2.1 v18.3.0

# 生成影响报告
prompt-diff impact v18.2.1 v18.3.0 --output report.md

# 指定可视化模式
prompt-diff compare v18.2.1 v18.3.0 --view side-by-side
prompt-diff compare v18.2.1 v18.3.0 --view semantic
```
