## P7-01 3问题交互式向导UI设计

### 向导组件规范

```typescript
interface WizardConfig {
  steps: WizardStep[]
  theme: 'light' | 'dark' | 'system'
  animation: 'slide' | 'fade' | 'none'
  showProgress: boolean
  allowSkip: boolean
  allowBack: boolean
}

interface WizardStep {
  id: string
  title: string
  subtitle: string
  question: string
  options: WizardOption[]
  allowCustom: boolean
  customPlaceholder: string
  icon: string
}

interface WizardOption {
  id: string
  label: string
  icon?: string
  value: string
  tags: string[]
}
```
