- **NVIDIA garak** (8.5k★): 20+攻击大类Probe体系，Plugin架构，自适应探测

## R43改进项

### H1: Prompt消毒器(Prompt Sanitizer) — 参考PromptSage
- 新模块: `prompt_sanitizer.py`
- 功能: 去除Prompt中的恶意内容/注入标记/混淆编码
- 规则: Base64解码检测/Unicode归一化/模板注入清理/敏感信息脱敏
- MCP Tool: `prompt_sanitize`
- 优先级: HIGH(安全核心)

### H2: 评估矩阵可视化 — 参考promptfoo
- 新模块: `eval_matrix.py`
- 功能: 多模型×多Prompt评估矩阵生成
- 输出: Rich Table/HTML矩阵+得分热力图
- 优先级: HIGH(评估体验)

### F1: Prompt自动优化器 — 参考DSPy
- 新模块: `prompt_optimizer.py`
- 功能: 基于Lint评分的迭代优化(无LLM依赖，纯规则优化)
- 策略: 自动补全角色/添加约束/去除歧义/格式化
- MCP Tool: `prompt_auto_optimize`
- 优先级: HIGH(核心差异化)

### F2: 版本Diff可视化 — 参考Pezzo
- 增强模块: `prompt_version.py`
- 功能: 版本间结构化Diff可视化(Rich/HTML输出)
- 新增: `visual_diff()`方法生成带颜色高亮的对比视图
- 优先级: MEDIUM(版本管理体验)

### D1: CI质量门禁增强 — 参考lintlang
- 增强模块: GitHub Action
- 功能: PR级别质量门禁，SARIF输出增强，质量趋势图
- 优先级: MEDIUM(CI/CD集成)

## 不做的事
- 不引入LLM调用依赖(保持零LLM架构)
- 不引入FAISS等外部向量库(保持纯Python)
- 不做Web UI(保持CLI/MCP架构)
