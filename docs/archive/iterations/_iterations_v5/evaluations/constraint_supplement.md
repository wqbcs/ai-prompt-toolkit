## 二、补充约束清单

### 2.1 安全约束补充(3项)

| 文档.场景 | 缺失约束 | 补充内容 |
|----------|---------|---------|
| 02_架构设计.场景D(API设计) | API认证约束 | 所有外部API必须实现认证(OAuth2/JWT/API Key)，内部服务间调用使用mTLS |
| 03_编码规范.场景B(AI代码审查) | AI输出安全约束 | AI生成代码必须经过安全扫描(SAST+依赖检查)，禁止直接执行AI生成的Shell命令 |
| 09_性能优化.场景D(全链路压测) | 压测数据安全约束 | 压测数据必须脱敏，禁止使用生产真实数据，压测流量必须标记可识别 |

### 2.2 性能约束补充(10项)

| 文档.场景 | 缺失约束 | 补充内容 |
|----------|---------|---------|
| 01_需求分析.场景A(PRD生成) | PRD规模约束 | PRD文档≤50页/15000字，超过需拆分为Epic级PRD |
| 01_需求分析.场景C(优先级排序) | 需求数量约束 | 单次排序需求数≤50，超过需分层排序(先按Epic→再按Story) |
| 02_架构设计.场景A(架构评审) | 架构复杂度约束 | 微服务数≤当前团队数×2，单服务代码量≤50K行 |
| 05_测试策略.场景A(测试策略) | 测试执行时间约束 | 单元测试总耗时≤5min，集成测试≤30min，E2E测试≤2h |
| 05_测试策略.场景C(自动化测试) | 测试维护成本约束 | 自动化用例维护成本≤开发成本10%，Flaky率≤2% |
| 06_CI/CD.场景B(部署策略) | 部署耗时约束 | 单次部署≤15min(含验证)，回滚≤5min |
| 07_监控运维.场景C(容量规划) | 资源利用率约束 | 日常CPU利用率≤70%，内存利用率≤80%，预留30%突发容量 |
| 10_文档沉淀.场景A(API文档) | 文档同步约束 | API变更后文档更新延迟≤1工作日，过期文档标注警告 |
| 11_项目管理.场景B(风险管理) | 风险评估频率约束 | 风险评估频率≥每迭代1次，P0风险≥每日跟踪 |
| 11_项目管理.场景D(度量体系) | 度量采集约束 | 度量数据延迟≤1天，度量报表自动生成频率≥每周 |

### 2.3 合规约束补充(9项)

| 文档.场景 | 缺失约束 | 补充内容 |
|----------|---------|---------|
| 01_需求分析.场景D(竞品分析) | 数据来源合规约束 | 竞品数据来源必须合规(公开信息+授权数据)，禁止爬取非公开数据 |
| 02_架构设计.场景B(技术选型) | 开源合规约束 | 开源选型必须通过许可证审查(GPL/AGPL需法务审批)，依赖SCA扫描 |
| 03_编码规范.场景C(技术迁移) | 数据迁移合规约束 | 数据迁移需DPIA评估，跨境迁移需安全评估+主管部门审批 |
| 04_代码审查.场景C(架构合规) | 架构合规约束 | 架构变更需Architecture Review Board审批，影响>3团队需CTO审批 |
| 05_测试策略.场景D(契约测试) | 测试数据合规约束 | 测试数据脱敏率100%，禁止在非生产环境使用真实PII数据 |
| 07_监控运维.场景C(容量规划) | 资源采购合规约束 | 资源扩容需经FinOps审批，月度云费用增长>20%需专项审批 |
| 10_文档沉淀.场景D(知识库) | 知识产权约束 | 知识库内容需标注来源和授权，禁止存储第三方知识产权内容 |
| 11_项目管理.场景A(项目规划) | 项目合规约束 | 项目立项需安全评估+隐私影响评估，敏感项目需等保备案 |
| 12_AI时代.场景B(Prompt安全) | AI使用合规约束 | AI生成代码需标注AI贡献，关键系统AI决策需可解释+人工审核 |
