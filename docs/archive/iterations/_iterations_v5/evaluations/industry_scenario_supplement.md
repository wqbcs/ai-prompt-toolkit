## 一、金融行业专用场景模板

### 场景：金融代码审查(04-Financial)

```markdown
## 场景描述
针对金融行业代码的特殊审查要求，在通用代码审查基础上叠加金融安全/交易一致性/资金安全专项检查。

## 输入要素
- 必需：代码变更diff+交易类型+涉及资金流
- 可选：风控规则+监管要求+历史审计发现

## 输出格式
```json
{
  "financial_review": {
    "standard_issues": [],
    "financial_specific": {
      "transaction_safety": {"issues": [], "risk_level": ""},
      "fund_integrity": {"issues": [], "risk_level": ""},
      "regulatory_compliance": {"issues": [], "regulations": []}
    },
    "pci_dss_alignment": {"compliant_items": [], "gaps": []},
    "overall_risk_assessment": ""
  }
}
```

## 检查清单(金融专项)
1. 金额计算精度：是否使用BigDecimal/Decimal(禁止float/double)
2. 交易原子性：分布式事务是否使用Saga/TCC模式
3. 幂等性保障：重复请求是否有幂等key+去重逻辑
4. 资金正负平衡：借贷是否平衡(复式记账)
5. 日终对账逻辑：是否有完整对账+差错处理
6. 敏感数据脱敏：卡号/身份证/手机号是否脱敏
7. 审计日志完整性：交易全链路是否有不可篡改审计日志
8. 限额检查：单笔/单日/单月限额是否校验
9. 反洗钱规则：大额/频繁/异常交易是否有AML标记
10. 加密传输：资金相关接口是否强制TLS1.2+双向认证

## 验收标准
- 金额计算无精度丢失
- 交易100%幂等
- 审计日志不可篡改
- PCI-DSS合规无P0差距
```

### 场景：金融安全审计(08-Financial)

```markdown
## 场景描述
金融行业专项安全审计，叠加PCI-DSS/等保2.0三级/反洗钱等金融特殊安全要求。

## 检查清单(金融专项)
1. PCI-DSS 12项要求逐条检查
2. 支付卡数据加密存储(强加密+密钥轮换)
3. 网络分段(持卡数据环境CDE隔离)
4. 多因素认证(管理访问+持卡数据访问)
5. 日志监控+入侵检测(文件完整性监控)
6. 安全测试策略(渗透测试频率+范围)
7. 反洗钱(AML)系统安全
8. 交易监控防绕过
9. SWIFT报文安全
10. KYC数据加密存储+访问审计
```

## 二、医疗行业专用场景模板

### 场景：医疗安全审计(08-Healthcare)

```markdown
## 场景描述
医疗行业专项安全审计，叠加HIPAA/医疗数据安全/医疗器械软件等医疗特殊安全要求。

## 输入要素
- 必需：系统架构+数据流图+PHI数据范围
- 可选：医疗器械认证状态+NMPA/FDA合规要求

## 输出格式
```json
{
  "healthcare_audit": {
    "standard_findings": [],
    "healthcare_specific": {
      "hipaa_compliance": {"status": "", "gaps": []},
      "phi_protection": {"encryption": "", "access_control": "", "audit_trail": ""},
      "medical_device_safety": {"issues": [], "risk_level": ""}
    },
    "remediation_plan": []
  }
}
```

## 检查清单(医疗专项)
1. HIPAA隐私规则：PHI使用/披露/最小必要原则
2. HIPAA安全规则：行政/物理/技术保障3类
3. PHI加密：静止加密(AES-256)+传输加密(TLS1.2)+使用中加密
4. 最小必要原则：数据访问是否按角色最小化
5. 患者同意管理：数据使用是否获取明确同意
6. 数据保留策略：PHI保留期限+安全销毁
7. BAA业务伙伴协议：第三方PHI处理者是否有BAA
8. 违规通知：是否有60天内通知机制
9. 医疗器械软件安全：IEC 62304合规
10. AI辅助诊断安全：NMPA/FDA AI医疗器械认证
11. 远程医疗安全：端到端加密+身份验证
12. 电子病历互操作：HL7 FHIR安全+OAuth2
```

## 三、电商行业专用场景模板

### 场景：电商性能优化(09-Ecommerce)

```markdown
## 场景描述
电商行业专项性能优化，叠加高并发/大促/秒杀/库存扣减等电商特殊性能要求。

## 输入要素
- 必需：当前性能指标+业务峰值预估+核心链路
- 可选：大促历史数据+库存架构+支付链路

## 输出格式
```json
{
  "ecommerce_optimization": {
    "baseline": {},
    "core_chain_analysis": {
      "product_detail": {"qps": 0, "latency_p95": 0, "optimization": ""},
      "search": {"qps": 0, "latency_p95": 0, "optimization": ""},
      "cart": {"qps": 0, "latency_p95": 0, "optimization": ""},
      "order": {"qps": 0, "latency_p95": 0, "optimization": ""},
      "payment": {"qps": 0, "latency_p95": 0, "optimization": ""},
      "inventory": {"qps": 0, "latency_p95": 0, "optimization": ""}
    },
    "promotion_readiness": {"status": "", "gaps": []},
    "capacity_plan": {}
  }
}
```

## 检查清单(电商专项)
1. 核心链路性能：商品详情/搜索/下单/支付P99延迟
2. 秒杀系统：库存预扣+异步下单+限流+防超卖
3. 缓存穿透/击穿/雪崩：布隆过滤器+互斥锁+随机过期
4. 库存扣减一致性：分布式锁+乐观锁+最终一致性
5. 订单号生成：雪花算法/号段模式+高可用
6. 搜索性能：ES索引优化+分片策略+查询DSL优化
7. 图片CDN：多级缓存+WebP+懒加载+预加载
8. 大促扩容方案：弹性伸缩+预热+限流降级+熔断
9. 支付链路：同步转异步+补偿机制+对账
10. 数据库优化：读写分离+分库分表+慢SQL治理
11. GC优化：G1/ZGC选择+堆大小+GC频率
12. 连接池优化：数据库/Redis/HTTP连接池参数调优
```
