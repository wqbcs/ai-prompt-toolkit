## 场景4：RAG评估

### 前置知识

- 理解RAG评估的核心维度
- 了解LLM-as-Judge评估模式
- 熟悉RAGAS评估框架

### 提示词模板

```markdown
# RAG评估方案设计

## 角色
你是一位RAG系统评估专家，精通自动化评估和LLM-as-Judge模式。

## 任务
为以下RAG系统设计评估方案。

## 输入
- RAG系统描述: {system_description}
- 评估目标: {eval_goals}
- 评估数据集: {eval_dataset}
- 预算限制: {budget}

## 评估维度
1. Faithfulness（忠实度）：回答是否忠于检索内容
2. Relevancy（相关性）：回答是否与问题相关
3. Retrieval（检索质量）：命中率/MRR/NDCG
4. Completeness（完整性）：是否覆盖所有要点
5. Coherence（连贯性）：回答是否逻辑连贯

## 请输出
1. 评估Pipeline架构图
2. 评估数据集设计（100条/5难度/5领域）
3. LLM-as-Judge提示词模板
4. 自动化评估脚本骨架
5. 评估报告模板（5维度+综合评分）
6. 迭代优化闭环方案
```

### 常见陷阱

| # | 陷阱 | 严重等级 | 规避方案 |
|---|------|---------|---------|
| 1 | 评估数据集偏斜：测试集与真实分布不一致 | P1 | 按真实查询分布采样+分层抽样 |
| 2 | LLM评估偏差：Judge模型偏好某类输出 | P2 | 多模型交叉评估+人类基线校准 |
| 3 | 仅评估最终输出：忽略中间检索质量 | P1 | 分层评估（检索质量+生成质量） |
| 4 | 评估不一致：相同输入不同评估结果 | P2 | 固定温度+多次评估取均值 |
| 5 | 无基准线：没有baseline无法衡量改进 | P1 | 建立baseline+定期回归测试 |

### 性能提示

| # | 提示 | 效果 | 实施难度 |
|---|------|------|---------|
| 1 | 批量评估+并行 | 评估速度提升5x | 低 |
| 2 | 评估结果缓存 | 重复评估成本降低80% | 低 |
| 3 | 采样评估（非全量） | 评估成本降低70% | 低 |
| 4 | 增量评估（仅评估变更部分） | 评估时间降低60% | 中 |
| 5 | 自动化CI/CD集成 | 评估效率提升10x | 中 |

### 安全提示

| # | 提示 | 威胁类型 | 严重等级 |
|---|------|---------|---------|
| 1 | 评估数据脱敏 | 隐私泄露 | P1 |
| 2 | Judge模型输出过滤 | 有害内容 | P2 |
| 3 | 评估结果访问控制 | 数据泄露 | P2 |
| 4 | 评估API Key安全管理 | 凭证泄露 | P0 |

## 场景5：RAG优化

### 前置知识

- 掌握RAG系统各环节优化技巧
- 了解查询改写和HyDE技术
- 熟悉索引优化和缓存策略

### 提示词模板

```markdown
# RAG系统优化方案

## 角色
你是一位RAG系统优化专家，精通检索优化、索引优化和生成优化。

## 任务
为以下RAG系统设计优化方案。

## 输入
- 当前系统: {current_system}
- 性能基线: {baseline_metrics}
- 瓶颈分析: {bottleneck}
- 优化目标: {optimization_target}

## 优化方向
1. 检索优化：查询改写/HyDE/Step-back/多查询
2. 索引优化：分层索引/元数据过滤/多模态索引
3. 生成优化：Citation/结构化输出/幻觉检测
4. 性能优化：缓存/预计算/异步检索
5. 成本优化：模型降级/Token压缩/批量处理

## 请输出
1. 瓶颈分析报告（3项瓶颈+根因）
2. 优化方案优先级排序（10项/按ROI排序）
3. 每项优化方案（改动点+预期效果+实施难度+风险）
4. A/B测试计划（对比优化前后）
5. 监控指标变更（基线→目标）
6. 实施路线图（3阶段）
```

### 常见陷阱

| # | 陷阱 | 严重等级 | 规避方案 |
|---|------|---------|---------|
| 1 | 过度优化：优化一个指标损害另一个 | P1 | 多指标权衡+帕累托最优 |
| 2 | 忽视评估：优化后不验证效果 | P0 | 每项优化必须A/B测试 |
| 3 | 缓存一致性：缓存结果与索引更新不一致 | P1 | TTL+失效机制+版本号 |
| 4 | HyDE幻觉：查询增强引入无关内容 | P2 | HyDE结果需验证+回退机制 |
| 5 | 成本陷阱：优化精度导致成本飙升 | P1 | 设置成本上限+性价比阈值 |

### 性能提示

| # | 提示 | 效果 | 实施难度 |
|---|------|------|---------|
| 1 | 查询改写（多查询扩展） | 召回率提升25% | 中 |
| 2 | HyDE假设文档嵌入 | 召回率提升20% | 中 |
| 3 | 分层索引（摘要+详情） | 延迟降低40% | 高 |
| 4 | 流式输出+SSE | 用户感知延迟降低50% | 低 |
| 5 | 语义缓存 | 重复查询成本降低95% | 中 |

### 安全提示

| # | 提示 | 威胁类型 | 严重等级 |
|---|------|---------|---------|
| 1 | 查询改写注入防护 | Prompt注入 | P0 |
| 2 | 缓存数据脱敏 | 隐私泄露 | P1 |
| 3 | 幻觉检测+标注 | 误导信息 | P1 |
| 4 | Citation来源验证 | 虚假引用 | P2 |
