## 场景1：DWS开发场景

### 前置知识
- 理解数据仓库基本概念（ODS/DWD/DWS/ADS分层）
- 熟悉PostgreSQL/GaussDB(DWS) SQL语法
- 了解MPP架构和列存储原理

### 提示词模板

```markdown
# DWS数据仓库开发方案

## 角色
你是一位华为云GaussDB(DWS)数据仓库专家。

## 任务
为以下数据仓库开发需求设计方案。

## 输入
- 业务场景: {business_scenario}
- 数据源: {data_sources}
- 分析需求: {analysis_requirements}
- 数据规模: {data_scale}

## 请输出
1. 分层建模方案（ODS→DWD→DWS→ADS各层表设计）
2. 建表DDL（分布键+分区+索引+压缩+列存/行存）
3. ETL Pipeline（GDS导入/INSERT/流式入库）
4. 物化视图设计（增量刷新策略）
5. 存储过程/函数开发（数据加工逻辑）
6. 数据质量检查规则（10项）
```

### 常见陷阱

| # | 陷阱 | 严重等级 | 规避方案 |
|---|------|---------|---------|
| 1 | 分布键选择不当：数据倾斜导致性能差 | P0 | 选择高基数列+验证分布均匀性 |
| 2 | 不分区：大表全表扫描 | P1 | 按时间/范围分区+分区裁剪 |
| 3 | 列存行存混用不当 | P2 | 分析表列存/维度表行存/小表复制 |
| 4 | 物化视图刷新不及时 | P1 | 增量刷新+触发器+调度任务 |
| 5 | 联邦查询性能差 | P2 | 本地化热点数据+OBS外表优化 |

## 场景2：DWS调优场景

### 前置知识
- 理解查询执行计划（EXPLAIN/EXPLAIN ANALYZE）
- 了解统计信息和CBO优化器
- 熟悉WLM（工作负载管理）

### 提示词模板

```markdown
# DWS性能调优方案

## 角色
你是一位华为云GaussDB(DWS)性能调优专家。

## 任务
为以下慢SQL设计调优方案。

## 输入
- 慢SQL: {slow_sql}
- 执行计划: {execution_plan}
- 表统计: {table_stats}
- 当前耗时: {current_latency}

## 请输出
1. 执行计划分析（瓶颈节点+估算vs实际行数）
2. 统计信息检查（是否过时/是否采样不足）
3. 优化方案清单（按优先级排序/预估提升幅度）
4. SQL改写建议（HINT/改写/拆分/并行）
5. 索引/分区建议（新增/修改/删除）
6. WLM资源池配置（内存/并发/优先级）
```

### 常见陷阱

| # | 陷阱 | 严重等级 | 规避方案 |
|---|------|---------|---------|
| 1 | 统计信息过时：CBO选择错误执行计划 | P0 | 定期ANALYZE+关键表手动收集 |
| 2 | 数据倾斜：Redistribute Motion瓶颈 | P1 | 调整分布键+Skew优化+广播小表 |
| 3 | 大表Join无分区裁剪 | P1 | 分区键对齐+分区Join+动态裁剪 |
| 4 | WLM配置不当：资源争抢 | P2 | 资源池隔离+队列优先级+内存限额 |
| 5 | 忽视Vacuum：表膨胀+死元组 | P1 | 定期VACUUM+自动VACUUM配置 |

## 场景3：DWS迁移场景

### 提示词模板

```markdown
# DWS数据迁移方案

## 角色
你是一位华为云GaussDB(DWS)数据迁移专家。

## 任务
为以下数据迁移需求设计方案。

## 输入
- 源数据库: {source_db}
- 目标DWS版本: {target_version}
- 数据规模: {data_scale}
- 迁移窗口: {migration_window}

## 请输出
1. 迁移评估报告（兼容性/数据量/风险/工期）
2. Schema迁移方案（DDL转换+不兼容处理）
3. 数据迁移方案（GDS/CDC/DRS/OBS中转）
4. 数据校验方案（行数/哈希/抽样/业务验证）
5. 回滚方案（双向同步+切换+回切）
6. 割接方案（停机窗口+切换步骤+验证清单）
```

### 常见陷阱

| # | 陷阱 | 严重等级 | 规避方案 |
|---|------|---------|---------|
| 1 | SQL不兼容：方言差异导致迁移失败 | P0 | 预先兼容性扫描+自动化转换工具 |
| 2 | 数据丢失：迁移过程中数据不一致 | P0 | 校验规则+增量同步+双写验证 |
| 3 | 性能退化：迁移后查询比源库慢 | P1 | 性能基准+分布键优化+统计信息收集 |
| 4 | 停机时间不足：迁移未完成需回滚 | P1 | 分批迁移+预迁移+增量同步 |
| 5 | 存储过程不兼容 | P2 | 逐个转换+功能等价验证 |
