## 一、依赖可视化

### 3种视图

| 视图 | 说明 | 适用 |
|------|------|------|
| 力导向图 | 节点弹簧布局+边连线 | 全局依赖概览 |
| 层级树 | 按依赖层级展开 | 依赖链分析 |
| 矩阵热力图 | 节点×节点矩阵 | 耦合度分析 |

### 可视化交互

| 操作 | 说明 |
|------|------|
| 点击节点 | 高亮直接依赖+被依赖 |
| 双击节点 | 进入子图视图 |
| 右键节点 | 影响分析/解环/重构建议 |
| 悬停边 | 显示依赖类型+强度 |
| 筛选 | 按类型/分类/风险等级过滤 |
| 搜索 | 按名称/标签搜索节点 |

### 节点颜色编码

| 颜色 | 含义 |
|------|------|
| 绿色 | 健康（无循环/低耦合） |
| 黄色 | 注意（高耦合/软循环） |
| 红色 | 危险（硬循环/破坏性变更） |
| 灰色 | 孤立节点 |
| 蓝色 | 选中/高亮 |

## 二、依赖健康报告

### 健康指标

```typescript
interface DependencyHealthReport {
  totalNodes: number
  totalEdges: number
  avgFanOut: number             // 平均扇出
  avgFanIn: number              // 平均扇入
  maxDepth: number              // 最大依赖深度
  cycleCount: number
  orphanCount: number
  avgCoupling: number
  avgCohesion: number
  healthScore: number           // 0-100
  grade: 'A+' | 'A' | 'B' | 'C' | 'D' | 'F'
}
```

### 评分规则

| 指标 | 权重 | A+阈值 | F阈值 |
|------|------|--------|-------|
| 循环依赖 | 30% | 0 | >5 |
| 平均耦合度 | 20% | <0.3 | >0.7 |
| 孤立节点率 | 15% | 0% | >10% |
| 依赖深度 | 15% | <3 | >7 |
| 扇出均值 | 10% | <3 | >7 |
| 版本一致性 | 10% | 100% | <80% |

## 三、自动重构建议

### 重构策略

| 策略 | 触发条件 | 建议 |
|------|---------|------|
| 提取公共 | 3+场景共享相同内容 | 提取为独立模板 |
| 合并相似 | 耦合度>0.7 | 合并为参数化场景 |
| 拆分复杂 | 扇出>7 | 拆分为子场景+路由 |
| 解除循环 | 存在循环依赖 | 断开弱依赖/提取层 |
| 版本对齐 | 版本不一致 | 统一版本号+兼容测试 |
| 清理孤立 | 孤立节点>0 | 评估删除或建立引用 |
