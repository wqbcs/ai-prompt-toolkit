## SMN专项-2场景

### 场景1：SMN集成场景

#### 前置知识
- 理解发布/订阅消息模式
- 了解华为云SMN服务基本概念（Topic/Subscription/Publish）
- 熟悉Webhook回调机制

#### 提示词模板

```markdown
# SMN消息通知集成方案

## 角色
你是一位华为云SMN消息通知集成专家。

## 任务
为以下消息通知需求设计SMN集成方案。

## 输入
- 业务场景: {scenario}
- 通知渠道: {channels}
- 消息类型: {message_types}
- 高可用需求: {ha_requirement}

## 请输出
1. Topic设计（命名规范+分类策略）
2. Subscription配置（协议/终端/过滤/重试）
3. 消息模板（参数化+多语言+变量替换）
4. 发布策略（批量/延迟/去重/优先级）
5. 错误处理（重试/降级/死信/监控）
6. 华为云服务集成（CES→SMN→FunctionGraph）
```

#### 常见陷阱

| # | 陷阱 | 严重等级 | 规避方案 |
|---|------|---------|---------|
| 1 | 消息风暴：大量告警同时触发 | P1 | 聚合+去重+限流+升级策略 |
| 2 | 订阅终端失效：邮件/短信发送失败 | P1 | 重试策略+多渠道备份+健康检查 |
| 3 | 消息模板变量缺失 | P2 | 模板验证+默认值+测试发送 |
| 4 | 权限过宽：Topic可被任意发布 | P0 | IAM策略+Topic策略+签名验证 |
| 5 | 无消息审计：无法追踪通知历史 | P2 | 开启日志+消息ID追踪+报表 |

## VPC专项-2场景

### 场景1：VPC网络配置场景

#### 前置知识
- 理解VPC/子网/CIDR基本概念
- 了解安全组和网络ACL区别
- 熟悉NAT网关/EIP/ELB配置

#### 提示词模板

```markdown
# VPC网络架构设计方案

## 角色
你是一位华为云VPC网络架构专家。

## 任务
为以下业务需求设计VPC网络架构方案。

## 输入
- 业务架构: {architecture}
- 安全等级: {security_level}
- 可用区: {availability_zones}
- 混合云需求: {hybrid_cloud}

## 请输出
1. VPC拓扑图（Mermaid格式：VPC+子网+AZ分布）
2. CIDR规划表（VPC/子网/服务/预留）
3. 安全组规则矩阵（入/出+协议+端口+源/目的）
4. NAT+EIP方案（SNAT/DNAT/共享带宽）
5. ELB配置（监听器+后端组+健康检查+会话保持）
6. 网络ACL规则（子网级无状态过滤）
```

#### 常见陷阱

| # | 陷阱 | 严重等级 | 规避方案 |
|---|------|---------|---------|
| 1 | CIDR重叠：VPC网段与本地IDC冲突 | P0 | 使用RFC1918保留地址+对等连接前验证 |
| 2 | 安全组过宽：0.0.0.0/0开放所有端口 | P0 | 最小化规则+定期审计+合规检查 |
| 3 | 单可用区部署：AZ故障导致服务不可用 | P1 | 跨AZ部署+ELB多AZ+自动故障切换 |
| 4 | NAT网关单点：SNAT瓶颈 | P1 | 多NAT网关+共享带宽+监控 |
| 5 | 子网IP耗尽：未预留扩展空间 | P2 | CIDR预留+子网扩容+IP监控 |

```markdown
## 输入
- 业务逻辑: {business_logic}

- 触发器: {triggers}

3. 环境变量配置（密钥/配置/动态参数）

```

### 常见陷阱

| # | 陷阱 | 严重等级 | 规避方案 |
|---|------|---------|---------|
| 1 | 冷启动慢：首次调用延迟高 | P1 | 预留实例+精简依赖+预热策略 |
| 2 | 依赖体积大：超过层大小限制 | P2 | 分层+自定义运行时+按需加载 |
| 3 | 超时设置不当：长任务被截断 | P1 | 合理超时+异步模式+Step Functions |
| 4 | 无状态设计错误：依赖本地缓存 | P0 | 状态外部化（OBS/Redis/DB） |
| 5 | 并发控制缺失：突发流量导致限流 | P1 | 预留并发+队列缓冲+限流 |
