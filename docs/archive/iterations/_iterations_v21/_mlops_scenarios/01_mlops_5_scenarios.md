## 场景1：模型训练

### 前置知识
- 理解机器学习训练流程（数据准备→特征工程→训练→验证）
- 熟悉PyTorch/TensorFlow/Keras
- 了解超参数调优（Grid Search/Bayesian/Evolutionary）

### 提示词模板

```markdown
# ML模型训练方案

## 角色
你是一位MLOps工程师，擅长模型训练流水线设计。

## 任务
为以下ML训练需求设计方案。

## 输入
- 任务类型: {task_type}
- 数据规模: {data_scale}
- 模型选择: {model_choice}
- 训练资源: {resources}
- 目标指标: {target_metrics}

## 请输出
1. 数据准备Pipeline（加载/清洗/增强/拆分）
2. 特征工程方案（编码/缩放/选择/生成）
3. 训练配置（超参数/分布式/检查点/EarlyStopping）
4. 超参数调优方案（搜索空间/策略/资源预算）
5. 训练监控指标（Loss/Metrics/GPU利用率/吞吐）
6. 实验追踪配置（MLflow/W&B/华为云ModelArts）
```

### 常见陷阱

| # | 陷阱 | 严重等级 | 规避方案 |
|---|------|---------|---------|
| 1 | 数据泄露：训练集包含验证集信息 | P0 | 严格时间拆分+Pipeline内拆分 |
| 2 | 过拟合：训练Loss低但验证Loss高 | P1 | 正则化+Dropout+EarlyStopping+数据增强 |
| 3 | 梯度爆炸/消失：深层网络训练不稳定 | P1 | BatchNorm+GradientClipping+学习率预热 |
| 4 | 超参搜索过拟合：搜索空间过小 | P2 | 多折验证+独立测试集 |
| 5 | 资源浪费：训练任务无自动扩缩容 | P2 | Spot实例+自动扩缩+断点续训 |

## 场景2：模型评估

### 前置知识
- 理解分类/回归/排序评估指标
- 了解交叉验证和统计检验
- 熟悉A/B测试设计

### 提示词模板

```markdown
# ML模型评估方案

## 角色
你是一位MLOps工程师，擅长模型评估和实验对比。

## 任务
为以下模型评估需求设计方案。

## 输入
- 模型列表: {models}
- 评估指标: {metrics}
- 数据集: {dataset}
- 对比基线: {baseline}

## 请输出
1. 评估Pipeline（数据加载→推理→指标计算→报告）
2. 评估指标定义表（指标/公式/阈值/方向）
3. 交叉验证方案（K折/分层/时间序列）
4. 统计显著性检验（配对t检验/McNemar/Wilcoxon）
5. 评估报告模板（模型×指标矩阵+统计检验结果）
6. A/B测试方案（样本量/时长/指标/决策规则）
```

### 常见陷阱

| # | 陷阱 | 严重等级 | 规避方案 |
|---|------|---------|---------|
| 1 | 评估指标错配：业务目标与评估指标不一致 | P0 | 明确业务指标→映射技术指标 |
| 2 | 测试集污染：多次评估导致隐式过拟合 | P1 | 严格锁定测试集+仅最终评估使用 |
| 3 | 忽视分布偏移：训练/推理数据分布不同 | P1 | 分布检测+域适应+监控 |
| 4 | 评估偏差：数据集不均衡导致指标失真 | P1 | 分层评估+混淆矩阵+F1宏平均 |
| 5 | 无不确定性估计：仅给点估计 | P2 | 置信区间+Bootstrap+校准 |

## 场景3：模型部署

### 前置知识
- 理解模型服务化（REST/gRPC/批量）
- 熟悉Docker/Kubernetes基础
- 了解模型格式（ONNX/TensorRT/TorchScript）

### 提示词模板

```markdown
# ML模型部署方案

## 角色
你是一位MLOps工程师，擅长模型部署和推理优化。

## 任务
为以下模型部署需求设计方案。

## 输入
- 模型类型: {model_type}
- 推理延迟要求: {latency_req}
- 吞吐量要求: {throughput_req}
- 部署环境: {deploy_env}
- 预算限制: {budget}

## 请输出
1. 部署架构图（Mermaid格式）
2. 模型优化方案（量化/剪枝/蒸馏/ONNX/TensorRT）
3. 服务化方案（REST/gRPC/批量/流式）
4. 容器化配置（Dockerfile+K8s manifests）
5. 弹性伸缩策略（HPA/VPA/KEDA）
6. 华为云ModelArts部署方案
```

### 常见陷阱

| # | 陷阱 | 严重等级 | 规避方案 |
|---|------|---------|---------|
| 1 | 冷启动慢：模型加载耗时超SLA | P1 | 模型预热+AOT编译+缓存 |
| 2 | 精度损失：量化/剪枝后精度下降 | P1 | 量化后评估+混合精度+校准 |
| 3 | 单点故障：推理服务无高可用 | P0 | 多副本+健康检查+自动恢复 |
| 4 | 版本不一致：训练/服务环境差异 | P1 | 容器化+MLflow模型注册+签名验证 |
| 5 | 安全漏洞：模型API无鉴权 | P0 | API网关+鉴权+限流+WAF |

## 场景4：模型监控

### 提示词模板

```markdown
# ML模型监控方案

## 角色
你是一位MLOps工程师，擅长模型监控和异常检测。

## 任务
为以下模型监控需求设计方案。

## 输入
- 模型服务: {model_service}
- 监控维度: {monitoring_dimensions}
- 告警要求: {alerting_req}

## 请输出
1. 监控架构图（指标采集→存储→分析→告警）
2. 监控指标清单（系统/模型/业务3层×10指标）
3. 数据漂移检测方案（PSI/KL散度/KS检验/ADWIN）
4. 概念漂移检测方案（DDM/EDDM/ADWIN）
5. 告警规则表（指标/阈值/等级/动作）
6. 华为云CES+ModelArts监控集成方案
```

### 常见陷阱

| # | 陷阱 | 严重等级 | 规避方案 |
|---|------|---------|---------|
| 1 | 仅监控系统指标：忽略模型质量指标 | P1 | 3层监控：系统+模型+业务 |
| 2 | 漂移检测滞后：累积显著后才告警 | P1 | 在线检测+滑动窗口+多粒度 |
| 3 | 告警疲劳：过多低优先级告警 | P2 | 告警分级+聚合+降噪+升级策略 |
| 4 | 无基线：不知道"正常"是什么 | P1 | 建立基线+动态阈值+季节性调整 |
| 5 | 监控盲区：未覆盖所有推理路径 | P2 | 全链路追踪+采样率100% |

## 场景5：模型迭代

### 提示词模板

```markdown
# ML模型迭代方案

## 角色
你是一位MLOps工程师，擅长模型迭代和持续改进。

## 任务
为以下模型迭代需求设计方案。

## 输入
- 当前模型: {current_model}
- 迭代原因: {iteration_reason}
- 新数据: {new_data}
- 迭代目标: {iteration_target}

## 请输出
1. 迭代决策框架（何时迭代/迭代什么/如何验证）
2. 数据更新Pipeline（增量/全量/标注+质量控制）
3. 重训练策略（全量重训/增量训练/微调/蒸馏）
4. A/B测试方案（影子模式→灰度→全量）
5. 回滚方案（触发条件+回滚步骤+数据恢复）
6. 迭代日历（日常迭代+紧急迭代+版本规划）
```

### 常见陷阱

| # | 陷阱 | 严重等级 | 规避方案 |
|---|------|---------|---------|
| 1 | 无回滚方案：新模型效果差无法恢复 | P0 | 模型版本管理+一键回滚+蓝绿部署 |
| 2 | 灰度不足：直接全量发布新模型 | P0 | 影子模式→5%灰度→50%灰度→全量 |
| 3 | 数据标注质量差：新数据引入噪声 | P1 | 标注质量检查+多标注一致性+审核 |
| 4 | 忘记旧知识：新数据训练后旧场景退化 | P1 | 混合训练+EWC+知识蒸馏 |
| 5 | 迭代过快：频繁迭代导致不稳定 | P2 | 迭代节奏控制+冻结期+回归测试 |
