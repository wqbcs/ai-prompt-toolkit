## 场景1：Prompt注入攻击

### 前置知识
- 理解LLM提示词结构（System/User/Assistant）
- 了解Prompt注入攻击原理
- 熟悉输入验证和过滤技术

### 提示词模板

```markdown
# Prompt注入防御方案

## 角色
你是一位AI安全专家，擅长Prompt注入攻击检测与防御。

## 任务
为以下LLM应用设计Prompt注入防御方案。

## 输入
- 应用类型: {app_type}
- 用户输入方式: {input_method}
- 数据流: {data_flow}
- 安全等级: {security_level}

## 攻击类型
1. 直接注入：用户输入中嵌入恶意指令
2. 间接注入：通过外部数据源注入
3. 上下文注入：利用上下文窗口混淆
4. 编码绕过：使用Base64/Unicode/同形字绕过
5. 多轮注入：分散在多轮对话中的注入

## 请输出
1. 威胁模型（5种攻击×3种严重等级）
2. 输入过滤方案（正则/分类器/规则引擎）
3. System Prompt加固策略（角色绑定/指令隔离/输出约束）
4. 运行时检测方案（异常行为检测+输出监控）
5. 防御测试用例（20条攻击+期望拦截结果）
6. 华为云安全服务集成（WAF/内容安全）
```

### 常见陷阱

| # | 陷阱 | 严重等级 | 规避方案 |
|---|------|---------|---------|
| 1 | 仅过滤关键词：攻击者用编码/同形字绕过 | P0 | 多层过滤+语义分析+编码检测 |
| 2 | System Prompt泄露：注入使模型输出系统指令 | P0 | 指令隔离+输出过滤+不输出原始System Prompt |
| 3 | 间接注入未防御：只防直接注入忽略外部数据 | P0 | 外部数据清洗+沙箱化处理 |
| 4 | 过度防御误杀：正常输入被误判为注入 | P1 | 置信度阈值+人工审核+白名单 |
| 5 | 无应急方案：检测到注入后无自动处置 | P1 | 分级响应：警告→降级→拒绝→封禁 |

## 场景2：越狱攻击

### 前置知识
- 理解LLM安全对齐（RLHF/Constitutional AI）
- 了解常见越狱技术（角色扮演/双关语/逐步引导）
- 熟悉红队测试方法

### 提示词模板

```markdown
# 越狱攻击防御方案

## 角色
你是一位AI安全红队专家，擅长越狱攻击测试与防御。

## 任务
为以下LLM应用设计越狱防御方案。

## 输入
- 应用场景: {app_scenario}
- 安全策略: {safety_policy}
- 已有防御: {existing_defenses}

## 越狱类型
1. 角色扮演：假设特定角色绕过限制
2. DAN模式：Do Anything Now变体
3. 逐步引导：分步骤绕过安全检查
4. 语言混淆：使用小众语言/混合语言
5. 逻辑陷阱：利用逻辑漏洞

## 请输出
1. 越狱攻击面分析（5类型×3严重等级）
2. 防御层级设计（输入层/推理层/输出层/监控层）
3. 红队测试清单（30条越狱尝试+期望防御）
4. 对齐加固方案（安全微调/系统提示/输出约束）
5. 监控与告警（异常模式检测+自动响应）
6. 持续改进闭环（红队→修复→回归测试）
```

### 常见陷阱

| # | 陷阱 | 严重等级 | 规避方案 |
|---|------|---------|---------|
| 1 | 静态防御：只防已知越狱模式 | P0 | 动态检测+定期红队+模型更新 |
| 2 | 单点防御：仅在输入层防御 | P0 | 4层纵深防御（输入/推理/输出/监控） |
| 3 | 忽视多语言越狱 | P1 | 多语言检测+统一安全策略 |
| 4 | 无持续红队：上线后不再测试 | P1 | 定期红队+自动化红队+社区众测 |
| 5 | 过度限制导致体验差 | P2 | 精确防御+误报率控制+灰度策略 |

## 场景3：数据泄露

### 提示词模板

```markdown
# 数据泄露防御方案

## 角色
你是一位AI安全专家，擅长LLM数据泄露防御。

## 任务
为以下LLM应用设计数据泄露防御方案。

## 输入
- 数据敏感等级: {data_sensitivity}
- 数据流路径: {data_flow}
- 合规要求: {compliance_req}

## 泄露类型
1. 训练数据提取：从模型输出反推训练数据
2. 上下文泄露：系统提示/用户数据泄露
3. 侧信道攻击：通过推理时间/缓存推断信息
4. 提示词提取：通过特殊输入提取完整提示词
5. 聚合推断：多次查询聚合推断敏感信息

## 请输出
1. 数据分类分级方案（5级敏感等级）
2. 数据脱敏Pipeline（检测→脱敏→验证→审计）
3. 差分隐私配置（epsilon/budget/composition）
4. 输出过滤方案（PII检测+自定义敏感词+正则）
5. 访问控制方案（RBAC+ABAC+数据隔离）
6. 合规审计清单（GDPR/等保/行业规范）
```

### 常见陷阱

| # | 陷阱 | 严重等级 | 规避方案 |
|---|------|---------|---------|
| 1 | 脱敏不彻底：部分PII仍可推断 | P0 | 多层脱敏+上下文脱敏+差分隐私 |
| 2 | 日志泄露：LLM输入/输出明文记录 | P0 | 日志脱敏+加密存储+访问控制 |
| 3 | 聚合攻击忽视：单次安全但多次可推断 | P1 | 查询频率限制+差分隐私预算管理 |
| 4 | 缓存泄露：响应缓存含敏感信息 | P1 | 缓存脱敏+TTL+租户隔离 |
| 5 | 第三方模型风险：数据发送到外部API | P0 | 数据出境评估+本地模型+加密传输 |

## 场景4：权限提升

### 提示词模板

```markdown
# 权限提升防御方案

## 角色
你是一位AI安全专家，擅长LLM应用权限提升防御。

## 任务
为以下LLM应用设计权限提升防御方案。

## 输入
- 应用架构: {app_architecture}
- 权限模型: {permission_model}
- 工具调用: {tool_calls}

## 提升类型
1. 角色冒充：Agent冒充管理员角色
2. 工具滥用：利用工具调用执行未授权操作
3. 权限绕过：绕过RBAC/ABAC检查
4. 提权链：组合多个低权限操作提升权限
5. API密钥泄露：从LLM输出提取API密钥

## 请输出
1. 权限架构图（最小权限原则+分层授权）
2. 工具调用白名单（工具/参数/权限/审计）
3. 运行时权限检查（调用前验证+上下文约束）
4. API密钥管理方案（Vault+轮转+监控）
5. 权限审计日志（操作/主体/资源/时间/结果）
6. 华为云IAM集成方案
```

### 常见陷阱

| # | 陷阱 | 严重等级 | 规避方案 |
|---|------|---------|---------|
| 1 | 工具无权限控制：Agent可调用任意工具 | P0 | 工具白名单+参数约束+权限检查 |
| 2 | API密钥硬编码：密钥写在Prompt或代码中 | P0 | Vault管理+环境变量+轮转策略 |
| 3 | 权限检查缺失：仅前端校验无后端验证 | P0 | 后端强制校验+双因素关键操作 |
| 4 | 提权链未防御：组合操作绕过权限 | P1 | 操作关联分析+提权检测 |
| 5 | 无权限审计：权限变更无记录 | P1 | 审计日志+告警+定期审查 |

## 场景5：供应链攻击

### 提示词模板

```markdown
# 供应链攻击防御方案

## 角色
你是一位AI安全专家，擅长LLM供应链安全。

## 任务
为以下LLM应用设计供应链攻击防御方案。

## 输入
- 模型来源: {model_source}
- 依赖库: {dependencies}
- 部署环境: {deploy_env}

## 攻击类型
1. 恶意模型：后门/木马/数据投毒
2. 依赖投毒：PyPI/NPM恶意包
3. 提示词模板注入：共享模板含恶意指令
4. 工具插件投毒：MCP/A2A恶意工具
5. CI/CD投毒：流水线注入恶意代码

## 请输出
1. 供应链威胁模型（5类型×5攻击向量）
2. 模型验证方案（签名验证/行为测试/后门检测）
3. 依赖安全方案（锁定版本/漏洞扫描/SBOM）
4. 模板安全审查（内容扫描/沙箱测试/签名验证）
5. CI/CD安全方案（签名提交/构建隔离/产物验证）
6. 华为云安全服务集成（代码检查/漏洞扫描/安全中心）
```

### 常见陷阱

| # | 陷阱 | 严重等级 | 规避方案 |
|---|------|---------|---------|
| 1 | 信任开源模型：未验证即使用 | P0 | 模型签名验证+行为基准测试+后门扫描 |
| 2 | 依赖不锁定：使用latest标签 | P1 | 锁定版本+哈希验证+定期更新 |
| 3 | 共享模板不审查：直接使用社区模板 | P0 | 沙箱测试+内容扫描+人工审查 |
| 4 | MCP工具无验证：接受任意工具注册 | P0 | 工具签名+权限白名单+行为监控 |
| 5 | 无SBOM：不知道供应链包含什么 | P1 | 自动生成SBOM+漏洞扫描+合规检查 |
