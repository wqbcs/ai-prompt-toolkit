## 5. 收敛判定

- **均分** = Σ(维度得分_20分制等效) / 18
- **标准差** = σ = sqrt(Σ(xi - x̄)² / 18)
- **终极收敛条件**：
  - 均分 ≥ 19.99
  - 标准差 ≤ 0.01
  - 最低分(20分制) ≥ 19.95
  - 实战认证度 ≥ 9.99
  - 生态繁荣度 ≥ 9.99
  - 原有16维度 ≥ 19.9(20分制)/9.9(10分制)
