## 1. 贡献者指南 CONTRIBUTING.md v2.0

### 1.1 贡献者旅程
```
Level 0: 浏览者 → 阅读文档+试用提示词
Level 1: 反馈者 → 提Issue/讨论/评分(需注册)
Level 2: 修复者 → 提交小PR(bug修复/文档/翻译)
Level 3: 贡献者 → 提交Feature PR(新场景/新检查项/优化)
Level 4: 专家 → 评审PR+架构决策+新维度提案
Level 5: 维护者 → 合并权限+版本发布+社区治理
```

### 1.2 贡献类型与积分

| 贡献类型 | 积分 | 权重 | 示例 |
|----------|------|------|------|
| Bug报告 | 10 | 1.0 | 发现提示词输出错误 |
| 文档改进 | 15 | 1.5 | 补充示例/改进措辞 |
| 翻译贡献 | 20 | 2.0 | 新语言翻译 |
| Bug修复 | 30 | 3.0 | 修复提示词逻辑错误 |
| 新检查项 | 40 | 4.0 | 新增检查清单项 |
| 新场景 | 60 | 6.0 | 新增完整场景提示词 |
| 性能优化 | 50 | 5.0 | 压缩/效率提升 |
| 架构改进 | 80 | 8.0 | 新维度/新原则/新反模式 |

**质量系数**：PR通过Review质量分/10
**时效系数**：1.0(正常)/1.5(48h内HotIssue)/2.0(安全关键修复)

## 2. 评审工作流

### 2.1 四阶段评审

```
提交 → 自动初审 → 同行评审 → 专家评审 → 合并
  │        │           │           │        │
  │     CI/CD       ≥1 Review    安全/架构   2+Approve
  │     格式检查     代码质量     影响评估   0 Reject
  │     安全扫描     文档完整     破坏性     Canary
  │     License     测试覆盖     新维度     发布
```

### 2.2 自动初审清单
| 检查项 | 阻断级别 | 标准 |
|--------|----------|------|
| 格式合规 | 阻断 | UPF v2.0格式 |
| Schema验证 | 阻断 | 输出Schema有效 |
| 安全扫描 | 阻断 | 无敏感信息泄露 |
| License合规 | 阻断 | Apache 2.0兼容 |
| 测试通过 | 阻断 | 新增测试全通过 |
| 文档完整 | 告警 | PromptCard完整 |
| 兼容性 | 阻断 | 向下兼容v10 |

### 2.3 评审角色与权限
| 角色 | 可Review | 可Approve | 可合并 | 范围 |
|------|----------|-----------|--------|------|
| 贡献者 | 自己的PR | - | - | - |
| 专家 | 所有PR | 非架构PR | - | 专长领域 |
| 维护者 | 所有PR | 所有PR | 所有 | 全局 |
| 安全专家 | 安全PR | 安全PR | - | 04/08场景 |

## 4. 社区治理

### 4.1 治理委员会
- **组成**：3核心维护+2专家+2社区代表(选举)
- **职责**：版本发布审批+架构决策+争议裁决+社区方向
- **会议**：月度例会+季度规划+年度复盘
- **投票**：简单多数(日常)+2/3多数(架构变更)+全体一致(安全关键)

### 4.2 与v10自治理体系对齐
- 贡献者积分 ↔ v10自治积分(8贡献类型)
- 评审工作流 ↔ v10质量门禁(7项)
- 治理委员会 ↔ v10自治模型(4角色+5等级)
- 版本决策 ↔ v10自动版本决策引擎
