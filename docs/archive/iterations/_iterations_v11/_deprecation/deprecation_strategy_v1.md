## 1. 废弃标准定义

### 1.1 三重废弃标准(必须同时满足)

| 标准 | 定义 | 量化阈值 | 验证方法 |
|------|------|----------|----------|
| S1-低使用率 | 使用率持续下降 | <5%且连续3月下降 | 使用统计+API调用量 |
| S2-有替代方案 | 存在功能等价或更优替代 | 替代方案覆盖率≥95% | 功能对比测试 |
| S3-已过时 | 不再符合当前技术/方法论 | 技术代差≥2代或方法论版本差≥2 | 技术评估+方法论版本 |

### 1.2 废弃流程

```
标记阶段(Deprecation)          过渡阶段(Transition)          移除阶段(Removal)
     │                              │                           │
  ┌──┴──┐                       ┌──┴──┐                    ┌──┴──┐
  │标记  │                       │过渡  │                    │移除  │
  │废弃  │──6个月──→             │保留  │──6个月──→          │清理  │
  │警告  │                       │兼容  │                    │归档  │
  └──────┘                       └──────┘                    └──────┘
     │                              │                           │
  ·@deprecated标注              ·兼容层保留                ·代码移除
  ·替代方案文档                  ·迁移指南                ·文档更新
  ·版本日志记录                  ·使用警告升级            ·版本日志
  ·使用统计开始                  ·废弃FAQ                 ·归档保存
```
