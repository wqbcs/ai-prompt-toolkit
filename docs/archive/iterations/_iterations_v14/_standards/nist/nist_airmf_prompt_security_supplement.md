# NIST AI RMF 提示词安全补充提案

> 版本：v14.0.0 | 日期：2026-05-29 | 提案编号：NIST-AI-RMF-PE-SUP-001

---

## 1. 提案概述

本提案为NIST AI风险管理框架(AI RMF 1.0)提供提示词工程安全补充，在GOV/MAP/MEASURE/MANAGE四大功能中嵌入提示词层风险管理。

---

## 2. GOV函数补充：提示词治理

### GOV-PE-01：提示词治理政策
组织应建立提示词治理政策，包含：
- 提示词分类与分级策略(L1公开/L2内部/L3机密/L4受限)
- 提示词变更管理流程(门禁体系19项)
- 提示词合规责任矩阵(RACI)
- 提示词事故响应流程

### GOV-PE-02：提示词风险管理文化
- 提示词安全意识培训(年度必修)
- 提示词安全责任到人
- 提示词安全事件学习机制
- 跨部门提示词安全协调

## 3. MAP函数补充：提示词风险识别与映射

### MAP-PE-01：提示词风险上下文映射
| 风险类别 | 描述 | 严重度 | 可能性 | 风险等级 |
|---------|------|--------|--------|---------|
| Prompt Injection | 恶意输入操纵提示词行为 | 高 | 高 | 极高 |
| Data Leakage | 提示词泄露训练数据或PII | 高 | 中 | 高 |
| Prompt Extraction | 系统提示词被提取/逆向 | 中 | 高 | 高 |
| Denial of Service | 资源耗尽或无限循环 | 中 | 中 | 中 |
| Bias Amplification | 提示词放大模型偏见 | 中 | 中 | 中 |
| Hallucination | 提示词引导模型产生虚假输出 | 高 | 高 | 极高 |
| Privilege Escalation | 提示词突破权限边界 | 高 | 低 | 中 |
| Non-compliance | 提示词违反法规要求 | 高 | 低 | 中 |

### MAP-PE-02：提示词Telemetry与上下文收集

## 4. MEASURE函数补充：提示词风险度量

### MEASURE-PE-01：提示词安全度量
```
安全度量 = f(注入防御率, 数据泄露率, 权限违规率, 审计覆盖率)
- 注入防御率 = 成功防御次数 / 注入攻击总次数
- 数据泄露率 = 泄露事件数 / 执行总次数
- 权限违规率 = 越权操作数 / 操作总次数
- 审计覆盖率 = 可审计操作数 / 操作总次数
```

### MEASURE-PE-02：提示词质量度量
- 24维度评估分数(均分≥18.00为可接受)
- 输出一致性(相同输入输出偏差≤ε)
- 语义保真度(输出与意图对齐度≥0.85)

### MEASURE-PE-03：提示词性能度量
| 指标 | 单位 | 基线 | 告警阈值 |
|------|------|------|---------|
| 延迟P50 | ms | 500 | 1000 |
| 延迟P99 | ms | 2000 | 5000 |
| Token利用率 | % | 70 | 90 |
| 错误率 | % | 0.1 | 1.0 |
| 注入防御率 | % | 99.5 | 95 |

## 5. MANAGE函数补充：提示词风险控制

### MANAGE-PE-01：提示词注入防御(4层)
```
L1-输入验证层：白名单字符+长度限制+格式校验
L2-指令隔离层：系统指令与用户输入严格分离
L3-输出过滤层：敏感信息检测+格式强制+幻觉标记
L4-行为监控层：异常行为检测+自动熔断+人工上报
```

### MANAGE-PE-02：提示词数据保护
- 数据分类与分级(自动标注+人工审核)
- 数据脱敏(PII/PHI/金融数据脱敏规则)
- 数据最小化(只传递任务必需数据)
- 数据加密(传输+存储+使用中加密)

### MANAGE-PE-03：提示词事故响应
| 阶段 | 动作 | SLA |
|------|------|-----|
| 检测 | 异常检测+告警 | ≤1min |
| 遏制 | 自动熔断+隔离 | ≤5min |
| 分析 | 根因分析+影响范围 | ≤1h |
| 恢复 | 修复+验证+恢复 | ≤4h |
| 改进 | 策略更新+培训+复盘 | ≤24h |

### MANAGE-PE-04：提示词持续监控
- 实时注入检测(模式匹配+语义分析)
- 漂移检测(输出质量退化监控)
- 合规监控(法规变更影响分析)
- A/B测试(安全变更灰度发布)

## 6. 与AI RMF配置文件(Profile)对齐

本补充提案可组合为AI RMF Profile：
- **关键基础设施Profile**：高安全等级(L3/L4)+严格注入防御+完整审计
- **金融服务Profile**：数据保护+合规覆盖+事故响应
- **医疗健康Profile**：PHI保护+幻觉防御+可解释性
- **通用Profile**：基础安全+质量监控+渐进加固
