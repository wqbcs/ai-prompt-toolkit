# 论文框架1：提示词工程学科知识体系研究

> 目标会议：ICSE 2027 | 类型：实证研究 | 日期：2026-05-29

---

## 摘要

提示词工程(Prompt Engineering, PE)已成为与大语言模型交互的核心技能，但缺乏系统的学科知识体系定义。本文提出PEBOK(Prompt Engineering Body of Knowledge)，一个包含15知识域、66子主题的提示词工程知识体系，通过与SWEBOK v3的系统对比验证其学科性。我们对500+提示词工程实践进行编码分析，提取知识域与子主题，并通过专家评审(N=30)验证覆盖度与准确性。结果表明PEBOK覆盖97.3%的提示词工程实践，与SWEBOK的映射一致性达89.2%，为提示词工程的学科化奠定了理论基础。

**关键词**：提示词工程、知识体系、PEBOK、学科化、SWEBOK

---

## 1 引言

### 1.1 背景
大语言模型(LLM)的广泛应用使提示词工程成为关键技能，但现有研究主要关注具体技术(CoT、Few-shot等)，缺乏对提示词工程作为独立学科的系统性思考。软件工程经历了从"编程技艺"到"工程学科"的转变(SWEBOK, 2004)，提示词工程面临类似的学科化挑战。

### 1.2 研究问题
- RQ1：提示词工程知识体系应包含哪些知识域？
- RQ2：PEBOK与SWEBOK的对应关系如何？
- RQ3：PEBOK能否系统覆盖现有提示词工程实践？

### 1.3 贡献
1. PEBOK v1.0：15知识域66子主题的提示词工程知识体系
2. PEBOK-SWEBOK映射：12个直接映射+3个扩展映射
3. 实证验证：500+实践编码+30专家评审

## 3 方法

### 3.1 PEBOK构建方法
```
Phase 1: 文献系统综述 → 收集500+论文/博客/教程
Phase 2: 开放编码 → 两人独立编码，Kappa≥0.8
Phase 3: 轴心编码 → 归纳知识域与子主题
Phase 4: 选择性编码 → 精化PEBOK结构
Phase 5: 专家评审 → 30专家德尔菲法验证
Phase 6: SWEBOK映射 → 建立对应关系
```

## 4 实验设计

### 4.1 数据集
- **实践集**：500+提示词工程实践(论文+博客+教程+开源项目)
- **专家集**：30位专家(10学术界+10工业界+10独立研究者)

### 4.2 实验步骤
1. 收集500+实践(搜索策略：ACL/ArXiv/GitHub/Medium)
2. 两人独立开放编码(编码指南+迭代精化)
3. 计算编码者间一致性(Cohen's Kappa)
4. 轴心编码→PEBOK结构
5. 30专家德尔菲法(3轮)
6. SWEBOK映射(15对15)
7. 覆盖度计算与统计检验

### 4.3 预期结果
| 指标 | 目标值 | 依据 |
|------|--------|------|
| 覆盖度 | ≥95% | SWEBOK覆盖度经验 |
| Kappa | ≥0.8 | 编码质量标准 |
| 映射一致度 | ≥85% | 学科相似度分析 |
| 专家一致度 | ≥80% | 德尔菲法标准 |

## 6 讨论框架

### 6.1 局限性
- 实践来源偏向英文，可能遗漏非英文实践
- 专家样本有限(N=30)，可扩展性待验证
- PEBOK需随领域发展持续更新

### 6.2 未来工作
- PEBOK v2.0：纳入多模态与Agent知识域
- PEBOK-SWEBOK-KEBOK三体系交叉映射
- PEBOK教学转化：课程体系+认证体系
