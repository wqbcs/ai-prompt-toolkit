# O6-1~2：三级入门路径设计

> **迭代编号**：O6-1~2 | **维度**：用户体验优化 | **日期**：2026-07-11

---

## 5分钟快速入门

### 目标：用最简场景走通一次完整流程

```
第1分钟：了解提示词体系是什么
├── 提示词体系 = 55个场景模板 + 9个工作流 + 10个行业包
├── 你只需要：选场景 → 填输入 → 获得AI输出
└── 最简场景：代码审查（无需准备复杂输入）

第2分钟：选择"代码审查"场景
├── 打开 04_代码审查与质量保障提示词.md
├── 找到"输入模板"部分
└── 准备一段代码（任意语言，10-50行）

第3-4分钟：执行
├── 复制提示词全文作为System Prompt
├── 在用户消息中填入代码+审查要求
└── AI返回结构化审查报告（JSON格式）

第5分钟：查看结果
├── 检查issues数组
├── 关注severity=high的问题
└── 根据suggestion修复代码
```

## 15分钟入门

### 目标：掌握3个场景+1个工作流

```
第1-5分钟：场景1 - 需求分析
├── 使用01_需求分析与产品规划提示词
├── 输入：项目idea描述
└── 输出：PRD+用户故事+功能列表

第6-10分钟：场景2 - 架构设计
├── 使用02_架构设计与技术选型提示词
├── 输入：PRD中的功能列表
└── 输出：架构图+技术选型报告

第11-13分钟：场景3 - 代码审查
├── 使用04_代码审查与质量保障提示词
├── 输入：一段代码
└── 输出：审查报告

第14-15分钟：工作流 - 需求→设计→编码
├── 查看 _workflows/requirement_design_coding.yaml
├── 理解3个场景如何串联
└── 尝试按工作流顺序执行
```

## 1小时精通

### 目标：完整场景+工作流+行业适配

```
第0-5分钟：概览（总览文档+架构图）
第5-15分钟：12个核心文档精读（各2分钟扫描结构）
第15-25分钟：完整工作流实践
├── 需求分析 → 架构设计 → 编码规范 → 代码审查 → 测试策略 → 部署
└── 每个环节填写真实项目信息

第25-35分钟：行业适配实践
├── 选择你所在行业（金融/医疗/电商/SaaS/游戏）
├── 查看对应行业包
└── 将行业检查清单嵌入对应场景

第35-45分钟：赛事专项实践
├── 鸿蒙开发者：使用 _harmonyos/ 提示词包
├── Flutter开发者：使用 _flutter/ 提示词包
└── 按迁移指南从现有技术栈迁移

第45-55分钟：高级功能
├── 自定义场景（_api/ SDK扩展接口）
├── 多人协作（_collaboration/）
└── 质量评估（_evaluations/）

第55-60分钟：持续改进
├── 了解循环改进机制（_loop/）
└── 创建个人改进计划
```
