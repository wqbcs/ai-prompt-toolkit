## 错误提示友好化模板（10种常见错误）

### 1. 场景不存在
```
❌ 原始：Error: scenario_not_found
✅ 友好：未找到该场景，可能原因：
   1. 场景ID拼写错误 → 查看可用场景列表
   2. 场景已被合并到其他分类 → 使用搜索功能
   3. 场景尚未创建 → 查看创建指南
   💡 建议：输入 "list" 查看所有可用场景
```

### 2. 输入验证失败
```
❌ 原始：ValidationError: required field 'code_snippet' is empty
✅ 友好：需要提供代码片段才能进行审查
   📋 必填项：
   - code_snippet：待审查的代码（支持50+语言）
   💡 提示：直接粘贴代码即可，系统会自动识别语言
```

### 3. 模型不可用
```
❌ 原始：ModelError: qwen-max is currently unavailable (503)
✅ 友好：当前模型(qwen-max)暂时不可用
   🔄 自动重试中...（3次/间隔5秒）
   📋 备选模型：
   1. deepseek-v3（推荐，质量相近）
   2. ernie-4.0（中文场景优秀）
   3. gpt-4-turbo（国际通用）
```

### 4. 输出格式错误
```
❌ 原始：JSON parse error: unexpected token at position 42
✅ 友好：AI输出格式异常，正在自动修复...
   ✅ 已修复：补全了缺失的闭合括号
   ⚠️ 建议检查issues数组最后一项是否完整
```

### 5. 速率限制
```
❌ 原始：RateLimitError: 429 Too Many Requests
✅ 友好：请求过于频繁，请稍后再试
   ⏰ 额度恢复时间：2分30秒后
   📊 今日已用：98/100次
   💡 建议：合并多个小请求为一次批量请求
```

### 6. 权限不足
```
❌ 原始：ForbiddenError: insufficient permissions
✅ 友好：当前角色(viewer)无法执行此操作
   🔒 需要：editor及以上角色
   📋 升级方式：联系管理员或申请临时权限
```

### 7. 版本冲突
```
❌ 原始：ConflictError: document version mismatch (expected 5, got 3)
✅ 友好：文档已被他人修改，请先同步最新版本
   📋 当前版本：v5 | 你的版本：v3
   💡 操作：点击"同步"按钮获取最新内容
```

### 8. 网络超时
```
❌ 原始：TimeoutError: request exceeded 30000ms
✅ 友好：请求超时，可能原因：
   1. 输入内容过大 → 尝试分段处理
   2. 网络不稳定 → 检查网络连接
   3. 模型负载高 → 稍后重试
   💡 建议：使用 --timeout 60000 增加超时时间
```

### 9. 语法错误
```
❌ 原始：SyntaxError: Unexpected token '{' in prompt template at line 42
✅ 友好：提示词模板语法错误
   📍 位置：第42行，'{'字符附近
   🔧 修复：请检查模板变量是否使用 {{variable}} 格式
   💡 常见原因：遗漏闭合的 }} 或使用了单层 {}
```

### 10. 循环依赖
```
❌ 原始：CircularDependencyError: scenario A → B → C → A
✅ 友好：检测到循环依赖：需求分析 → 架构设计 → 需求分析
   🔧 修复方案：
   1. 在架构设计步骤跳过"重新分析需求"
   2. 设置最大循环次数（推荐3次）
   3. 引入人工确认断点
```
