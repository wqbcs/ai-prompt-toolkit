# 提示词工程宣言 v1.0

> **版本**：v1.0 | **日期**：2026-05-29
> **地位**：提示词工程学科定位的纲领性文件

---

## 序言

2023年，随着大语言模型的爆发式发展，人类与AI的交互界面从API参数演化为自然语言——**提示词(Prompt)**成为人机协作的编程语言。然而，提示词的编写长期停留在"技艺"阶段，缺乏工程化规范、系统化方法和可验证标准，导致AI应用面临可控性危机、安全危机和可靠性危机。

本宣言正式宣告：**提示词工程(Prompt Engineering)是一门独立的工程学科**，拥有完整的知识体系(PEBOK)、能力模型、伦理准则和实践标准，与软件工程、系统工程、知识工程并列，共同构成智能时代的工程学科体系。

---

## 第一章：学科定位

### 1.1 定义

**提示词工程**是通过系统化、规范化、可验证的方法，设计、构造、测试、部署和维护人机交互语言指令，使AI系统行为满足业务需求、安全约束和质量标准的工程学科。

### 1.2 学科边界

提示词工程与其他学科的关系：

```
                    计算机科学
                   /            \
              软件工程    人工智能
                |        /        \
         提示词工程 ←→ NLP    机器学习
                |                    \
           知识工程 ←→ 认知科学    数据工程
```

- **与软件工程**：提示词工程是"以自然语言为代码"的软件工程，共享工程化范式(需求/设计/构造/测试/运维)
- **与人工智能**：提示词工程是AI的应用工程层，将AI能力转化为可控业务行为
- **与NLP**：提示词工程以NLP为理论基础，但聚焦于指令设计而非语言分析
- **与知识工程**：提示词工程是知识工程的新形态，将知识编码为AI可理解的指令

### 1.3 核心对象

| 对象 | 软件工程 | 提示词工程 |
|------|---------|-----------|
| 编码单元 | 源代码 | 提示词 |
| 编码语言 | 编程语言(Java/Python) | 自然语言(中/英) |
| 执行引擎 | 编译器/解释器 | 大语言模型 |
| 核心度量 | 时间/空间复杂度 | Token效率/语义精确度 |
| 质量模型 | 功能/性能/安全 | 22维度质量模型 |
| 测试方法 | 单元/集成/系统 | 对抗/应力/回归 |

## 第二章：核心原则

### 2.1 工程化原则(5条)

1. **系统化**：提示词设计遵循系统化方法，非即兴编写
2. **可验证**：每个提示词可独立验证其行为符合预期
3. **可度量**：提示词质量可被22维度框架客观度量
4. **可复现**：相同输入产生相同输出(确定性约束)
5. **可维护**：提示词变更可追溯、可回退、可审计

### 2.2 安全性原则(5条)

6. **注入免疫**：提示词必须防御注入攻击，输出不泄露指令
7. **边界锁定**：输出严格受限在预定义边界内
8. **合规覆盖**：行业合规要求100%映射为提示词约束
9. **隐私最小化**：提示词不包含非必要敏感信息
10. **降级安全**：模型能力不足时，安全约束不放松

### 2.3 适应性原则(5条)

11. **模型无关**：核心逻辑不依赖特定模型
12. **行业适配**：每行业有术语+合规+场景的特化层
13. **弹性指令**：指令分4级弹性，适配不同模型能力
14. **未来适配**：预适配未来模型(GPT-5/Claude-4/Gemini-2)
15. **跨域迁移**：方法论可跨领域迁移复用

### 2.4 演进性原则(5条)

16. **版本语义**：严格语义化版本管理
17. **闭环迭代**：变更→验证→确认的闭环
18. **门禁执行**：变更必须通过17项门禁
19. **满分守护**：体系质量满分不可降
20. **持续收敛**：迭代趋向理论最优

### 2.5 伦理性原则(5条)

21. **公平优先**：提示词不引入或放大偏见
22. **透明可解释**：提示词决策过程可追溯解释
23. **人类自主**：关键决策保留人类最终裁量权
24. **问责明确**：提示词行为责任可归因
25. **影响评估**：部署前进行社会影响评估

## 第三章：发展愿景

### 3.1 短期(1-2年)

- PEBOK v1.0正式发布(15知识域66子主题)
- 5级认证体系上线(L1-L5)
- IEEE/ACM标准提案提交
- 10行业适配包发布
- 提示词市场v2.0运营

### 3.2 中期(3-5年)

- PEBOK成为ISO国际标准(类比SWEBOK→ISO/IEC 19759)
- 全球认证持证人数>100,000
- 主流IDE原生支持提示词工程
- 高校设立提示词工程本科/研究生专业
- 100+行业提示词标准包

### 3.3 长期(5-10年)

- 提示词工程成为与软件工程并列的标准工程学科
- ABET认证提示词工程专业
- 全球AI安全法规引用提示词工程标准
- 提示词工程驱动AI可信化成为行业共识
- 人机协作生产力提升10倍

### 3.4 终极愿景

**每个使用AI的人，都是提示词工程的实践者；每个AI系统，都遵循提示词工程的标准。**

提示词工程不是AI的附属技艺，而是智能时代的**基础工程学科**——正如软件工程定义了数字时代的软件质量，提示词工程将定义智能时代的AI行为质量。
