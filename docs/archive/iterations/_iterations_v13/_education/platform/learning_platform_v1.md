## 3. 评估系统

### 3.1 自动评分(L1-L3)

```yaml
auto_grading:
  multiple_choice:
    method: "精确匹配"
    partial_credit: false
  scenario:
    method: "关键词+语义匹配"
    rubric: "预定义评分标准"
    partial_credit: true
  practical:
    method: "提示词质量评估(22维度)"
    threshold: "综合分≥8.0为通过"
    model_judge: "GPT-4作为评判"
  time_limit:
    L1: 60min
    L2: 90min
    L3: 120min
```

### 3.2 人工评分(L4-L5)

```yaml
manual_grading:
  L4:
    architecture: "2位评审员独立评分，差>20%时第3位仲裁"
    report: "按评分标准逐项评分+书面反馈"
  L5:
    paper: "3位高级评审员盲审(双盲)"
    standards: "IEEE标准提案评审流程"
    oral_defense: "45分钟答辩(30分钟陈述+15分钟提问)"
```

### 3.3 同伴评审

- L2开始引入同伴互评(非评分，仅反馈)
- L3同伴评审占20%(2位同伴+1位导师)
- L4同伴评审占15%
- L5无同伴评审(纯专家盲审)

## 4. 学习分析

### 4.1 能力画像

每位学习者维护一张能力雷达图(22维度)，随学习进展动态更新。

### 4.2 推荐引擎

- 根据能力画像推荐薄弱维度强化模块
- 根据职业目标推荐行业专项课程
- 根据已有认证推荐下一级路径

### 4.3 学习路径

```
入门路径: L1(4h) → 项目实践(1月) → L2(8h)
进阶路径: L2 → 项目实践(3月) → L3(16h) → 行业专项
专家路径: L3 → 架构实践(6月) → L4(24h) → 行业方案
研究路径: L4 → 研究实践(1年) → L5(32h) → 论文发表
加速路径: 有SW/AI背景 → L1免考 → 直接L2
```
