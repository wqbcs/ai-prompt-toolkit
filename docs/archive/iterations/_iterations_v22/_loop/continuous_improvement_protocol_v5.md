- 差异分析工具检查（字段+语义+影响3维）

- 最小可执行示例覆盖率检查（目标100%）

- JSON camelCase一致性检查（目标100%）

### 5. 模板市场v2合规扫描
- 发布流程5步验证完整性检查
- 安装依赖解析正确性检查

### 6. UX可用性扫描
