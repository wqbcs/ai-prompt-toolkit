## 2. 新增维度详细评估标准

### 2.1 Agent自主度维度(10分)

| 评分 | 标准 | 说明 |
|------|------|------|
| 0-2 | 无Agent支持 | 场景模板无Agent执行能力 |
| 2-4 | 有Agent协议定义 | Agent执行协议规范已定义 |
| 4-6 | 有Agent-First模板 | ≥3个场景有Agent-First模板 |
| 6-8 | Agent模板+工作流 | ≥5个场景+工作流Agent化 |
| 8-10 | 全场景Agent化+安全边界 | 8+场景+工作流+安全边界+自校验 |

### 2.2 形式化验证度维度(10分)

| 评分 | 标准 | 说明 |
|------|------|------|
| 0-2 | 无形式化验证 | 场景模板无形式化验证 |
| 2-4 | 有安全属性规约 | 安全属性已用PPSL规约 |
| 4-6 | 有模型检查配置 | 模型检查配置+抽象模型已定义 |
| 6-8 | 有模型检查通过 | 关键属性通过模型检查 |
| 8-10 | 有证明+CI/CD集成 | 安全证明+CI/CD门禁+持续验证 |

## 3. 均分与收敛判定

- **均分** = Σ(维度得分) / 12
- **标准差** = σ = sqrt(Σ(xi - x̄)² / 12)
- **收敛条件**：均分 ≥ 19.0 且 标准差 ≤ 0.6
