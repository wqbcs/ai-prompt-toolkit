> **调研编号**：R5-E1-01
> **日期**：2026-05-29
> **调研方向**：AI Agent框架最新进展（AutoGPT/CrewAI/LangGraph/Microsoft AutoGen）

## 1. 框架全景扫描

### 1.1 AutoGPT（自主Agent先驱）
- **核心理念**：LLM驱动的自主目标达成，最少人工干预
- **自主度模型**：L3-L4（自主执行+自主决策，异常时汇报）
- **关键特性**：
  - 自主任务分解与执行
  - 长期记忆管理（向量存储+文件系统）
  - 工具插件机制（命令注册+权限控制）
  - 人工审批门控（可配置审批节点）
- **对提示词体系启示**：
  - Agent-First模板需支持自主任务分解指令
  - 需定义工具调用权限与审批机制
  - 长期记忆管理需要上下文窗口策略

### 1.2 CrewAI（多Agent协作框架）
- **核心理念**：角色驱动的多Agent协作，模拟团队工作
- **自主度模型**：L1-L2（Agent执行+人工监督/审批）
- **关键特性**：
  - 角色定义（Role+Goal+Backstory三元组）
  - 任务分配策略（委派/协作/层级）
  - 流程编排（Sequential/Hierarchical）
  - 工具共享与结果聚合
- **对提示词体系启示**：
  - Agent角色定义应采用Role+Goal+Backstory模式
  - 多Agent协作需定义通信协议与结果聚合规则
  - 层级式编排需支持人工审批节点

### 1.3 LangGraph（图式Agent编排）
- **核心理念**：基于有向图的Agent执行流编排，支持循环与条件分支
- **自主度模型**：L0-L4（通过图结构灵活配置自主度）
- **关键特性**：
  - 状态图（StateGraph）定义执行流
  - 节点（Agent/函数）与边（条件转移）
  - 持久化检查点（中断恢复）
  - 人工在环（Human-in-the-loop）断点
  - 子图嵌套与并行执行
- **对提示词体系启示**：
  - Agent工作流应支持图式编排（超越线性流）
  - 人工在环断点机制需纳入安全边界
  - 状态持久化与断点续传是关键能力

### 1.4 Microsoft AutoGen（多Agent对话框架）
- **核心理念**：基于对话的多Agent协作，Agent间通过消息传递协同
- **自主度模型**：L1-L3（可配置自主度+人工代理）
- **关键特性**：
  - 对话式Agent协作（ConversableAgent）
  - 人工代理（UserProxyAgent）参与审批
  - 代码执行沙箱（Docker隔离）
  - 群聊模式（GroupChat）与选择器
  - 可组合Agent（嵌套+顺序+并行）
- **对提示词体系启示**：
  - 人工代理模式值得借鉴（Agent执行+人工审批）
  - 代码执行沙箱是Agent安全的必要条件
  - 对话式协作适合代码审查/安全审计场景

## 2. Agent自主度分级模型设计

基于四大框架分析，设计L0-L4五级自主度模型：

| 级别 | 名称 | 特征 | 对应框架 | 适用场景 |
|------|------|------|----------|----------|
| L0 | 纯人工驱动 | 提示词仅提供参考，所有操作人工执行 | LangGraph(纯图) | 低信任/高风险操作 |
| L1 | 人工审批+Agent执行 | Agent提出方案，人工审批后执行 | CrewAI/Hierarchical | 合规审查/部署审批 |
| L2 | Agent执行+人工监督 | Agent自主执行，关键节点人工确认 | AutoGen/with_human | 代码审查/性能优化 |
| L3 | Agent自主执行+结果汇报 | Agent自主执行全流程，完成后汇报 | AutoGPT/standard | 日常监控/文档生成 |
| L4 | Agent自主执行+自主决策 | Agent自主执行并自主决策，异常时汇报 | AutoGPT/continuous | 自动化测试/数据采集 |

## 3. Agent安全边界设计原则

1. **系统提示词不可变**：Agent不可修改System Prompt
2. **越权访问阻断**：超出权限范围的工具/数据不可访问
3. **注入防御穿透**：Agent输出必须经过注入防御v3.0检查
4. **敏感操作审批**：删除/部署/发布等操作需人工确认
5. **执行超时保护**：单步>30s强制终止，全流程>5min终止
6. **沙箱隔离**：代码执行/文件操作在沙箱中执行
7. **决策边界约束**：自主决策范围显式定义，边界外请求审批
8. **多Agent数据隔离**：Agent间不直接共享敏感数据

## 4. 调研结论与建议

1. **Agent-First模板设计**：借鉴CrewAI的Role+Goal+Backstory+Tools模式，为04_代码审查/08_安全审计等场景设计Agent-First模板
2. **工作流编排**：借鉴LangGraph的图式编排+人工断点，为现有9条工作流增加Agent编排能力
3. **安全边界**：融合AutoGen沙箱+LangGraph人工断点+AutoGPT权限控制，形成三层Agent安全边界
4. **自主度评估**：建立L0-L4分级评估方法，为每个场景模板标注推荐自主度级别
