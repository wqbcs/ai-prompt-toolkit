# AI Prompt Toolkit 改进清单 v5.0

> **版本**: v5.0 | **日期**: 2026-07-22 | **项目版本**: v42.0.0
> **开源调研**: promptfoo(23.5k⭐)/Arize Phoenix(10.7k⭐)/garak(3k⭐)/DeepEval(3k⭐)/textgrad(2k⭐)

---

## 开源调研核心发现

### promptfoo (23.5k⭐, 已被OpenAI收购)
- **核心功能**: 声明式YAML配置评估、红队扫描、模型对比、CI/CD集成
- **可借鉴**: YAML声明式配置模式、assert断言引擎、cache机制、promptfoo eval命令
- **痛点**: 纯Node.js生态、不支持中文场景、无Lint规则体系

### Arize Phoenix (10.7k⭐)
- **核心功能**: AI可观测性、Tracing、数据集版本化、Prompt管理、MCP Server
- **可借鉴**: 数据集版本化、实验追踪、Playground交互、Remote MCP Server
- **痛点**: 重量级平台、Python+TS双栈、非纯CLI工具

### garak (3k⭐)
- **核心功能**: LLM漏洞扫描器、90+Probes、自动化红队
- **可借鉴**: Probe分类体系、自动化扫描报告、漏洞严重性分级
- **痛点**: 仅扫描无修复、无Lint体系

### DeepEval (3k⭐)
- **核心功能**: LLM评估框架、指标体系、测试用例管理
- **可借鉴**: 评估指标体系(G-Eval/Answer Relevancy/Faithfulness)、测试用例管理
- **痛点**: 无安全扫描、无CLI工具链

### textgrad (2k⭐)
- **核心功能**: 基于梯度下降的Prompt自动优化
- **可借鉴**: 迭代优化策略、评分反馈机制
- **痛点**: 学术项目、生产就绪度低
