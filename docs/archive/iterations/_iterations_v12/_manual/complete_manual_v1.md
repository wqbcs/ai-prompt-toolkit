## 第1章：快速入门（15分钟上手）

### 1.1 什么是提示词体系？

AI提示词体系是一套工业级、可量化、自进化的提示词工程方法论，覆盖软件开发全生命周期的55个场景，经9轮深度迭代优化，十八维度均分20.00（满分）。

### 1.2 5分钟快速体验

```bash
# 1. 选择场景
场景编号: 04_代码审查与质量保障

# 2. 使用提示词
将 04_代码审查与质量保障提示词.md 中的内容复制到AI对话

# 3. 提供输入
粘贴待审查代码

# 4. 获取输出
AI将按Schema格式输出审查结果
```

### 1.3 10分钟进阶

```yaml
# 选择行业适配
industry: financial  # 金融/医疗/电商/SaaS/游戏

# 选择模型适配
model: gpt-4  # GPT-4/Claude/Gemini/DeepSeek/Qwen/ERNIE/Kimi

# 选择压缩级别
compression: L1  # L0(原始)/L1(轻度)/L2(中度)/L3(重度)
```

### 1.4 15分钟完整流程

1. **选场景**(01-12共12类55场景)
2. **选行业**(5软件行业+4跨域)
3. **选模型**(7+模型自动适配)
4. **选压缩**(L0-L3按需压缩)
5. **执行**(AI按提示词执行)
6. **验证**(检查清单逐项验证)

## 第5章：贡献与认证

### 5.1 贡献者等级

| 等级 | 要求 | 权限 |
|------|------|------|
| L1-观察者 | 注册 | 阅读+评论 |
| L2-贡献者 | 1+合并PR | 提交PR+评审 |
| L3-评审者 | 5+合并PR+3+评审 | 评审权限 |
| L4-维护者 | 20+合并PR+治理参与 | 合并权限 |
| L5-专家 | 领域专家+50+贡献 | 专家评审 |
| L6-架构师 | 体系级贡献 | 架构决策 |

### 5.2 认证流程

1. 提交认证申请(场景+证据)
2. 自动初审(格式+合规)
3. 同行评审(2+评审者)
4. 专家评审(1+专家)
5. 认证颁发(徽章+积分)

## 第6章：运维与排障

### 6.1 运维要点

- **版本管理**：语义化版本(v主.次.修)
- **废弃管理**：标记→6月过渡→移除
- **压缩管理**：L0-L3按需选择
- **模型管理**：7+模型效果矩阵
- **守护CI**：每次变更触发全维度评估

### 6.2 排障指南

| 问题 | 原因 | 解决 |
|------|------|------|
| 输出格式异常 | 模型切换 | 格式归一化后处理 |
| CoT推理失败 | 模型能力不足 | 降级到直接推理 |
| 安全拒绝过度 | 约束过强 | 校准安全边界 |
| Token超限 | 窗口不足 | 动态压缩策略 |
| 术语被替换 | 模型理解差异 | 术语锁定指令 |
