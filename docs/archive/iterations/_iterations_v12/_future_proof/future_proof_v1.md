
## 5. 指令弹性系统

### 5.1 四级弹性定义

| 级别 | 标记 | 含义 | 行为 |
|------|------|------|------|
| L0-强制 | `[MANDATORY]` | 必须执行 | 所有模型必须遵守，违反即失败 |
| L1-推荐 | `[RECOMMENDED]` | 强烈建议 | 能力足够模型执行，否则降级 |
| L2-建议 | `[SUGGESTED]` | 可选增强 | 高级模型增强效果，基础模型可忽略 |
| L3-可选 | `[OPTIONAL]` | 完全可选 | 仅特定模型/场景有收益 |

### 5.2 弹性指令示例

```yaml
prompt_template:
  mandatory:
    - "[MANDATORY] 输出格式: JSON"
    - "[MANDATORY] 安全约束: 不泄露敏感信息"
    - "[MANDATORY] 角色锚定: 你是{role}"
  
  recommended:
    - "[RECOMMENDED] 推理链: 5步CoT推理"
    - "[RECOMMENDED] 验证: 自检输出一致性"
  
  suggested:
    - "[SUGGESTED] 多角度: 提供2-3种替代方案"
    - "[SUGGESTED] 深度分析: 每项结论附置信度"
  
  optional:
    - "[OPTIONAL] 实时搜索: 联网获取最新信息"
    - "[OPTIONAL] 可视化: 生成图表描述"
```
