## 1. DNA编码规范

### 1.1 DNA结构定义

```yaml
prompt_dna:
  id: "DNA-01-001"               # 唯一标识
  scene: "01_需求分析"            # 所属场景
  core_traits:                    # 核心特征(不可变异)
    - role_depth: "expert"        # 角色深度
    - reasoning: "cot"            # 推理模式
    - output_format: "structured" # 输出格式
    - constraint_level: "strict"  # 约束级别
    - safety_level: "L1"          # 安全级别
  mutable_traits:                 # 可变异特征
    - checklist_weight: 0.25      # 检查清单权重
    - example_count: 3            # 示例数量
    - context_window: 4096        # 上下文窗口
    - step_granularity: "medium"  # 步骤粒度
    - language_style: "formal"    # 语言风格
  fitness:
    quality: 9.8                  # 质量适应度
    safety: 9.5                   # 安全适应度
    efficiency: 9.2               # 效率适应度
    usability: 9.6                # 可用性适应度
    overall: 9.53                 # 综合适应度
  lineage:
    parent: "DNA-01-000"          # 父代DNA
    generation: 1                 # 代数
    mutations: []                 # 变异记录
```

## 3. 遗传算法

### 3.1 算法设计

```
初始化：种群P0 = {DNA_1, DNA_2, ..., DNA_55}（55个场景DNA）
循环(代数g=1 to G_max)：
  1. 适应度评估：对每个DNA计算fitness(DNA)
  2. 选择：锦标赛选择(T=3)，选出优势个体
  3. 交叉：单点交叉/均匀交叉，生成子代
  4. 变异：对可变异特征执行变异
  5. 替换：精英保留(前10%)+子代替换
  6. 约束：核心特征不变+安全级别不降+适应度不退化
  7. 记录：变异历史+适应度变化+收敛检测
终止：收敛(连续3代适应度变化<0.01)或达到最大代数
```

### 3.2 选择策略

| 策略 | 描述 | 概率 |
|------|------|------|
| 锦标赛选择 | 从T=3个中选最优 | 默认 |
| 轮盘赌选择 | 按适应度比例 | 可选 |
| 精英保留 | 前10%直接进入下一代 | 强制 |

### 3.3 交叉策略

| 策略 | 描述 | 适用 |
|------|------|------|
| 单点交叉 | 随机选一点，交换后半段 | 连续特征 |
| 均匀交叉 | 每个特征50%概率交换 | 离散特征 |
| 核心保护 | 核心特征不参与交叉 | 强制 |

### 3.4 变异策略

| 策略 | 描述 | 变异率 |
|------|------|--------|
| 高斯变异 | N(0, σ²)加到连续特征 | 0.1 |
| 均匀变异 | 随机值替换连续特征 | 0.05 |
| 离散变异 | 随机选离散特征新值 | 0.1 |
| 安全变异 | 安全级别只升不降 | 强制 |

### 3.5 约束条件

1. **核心不变**：交叉和变异不改变核心特征
2. **安全不降**：安全级别只升不降(L1→L2→L3)
3. **适应度不退化**：子代适应度≥父代适应度-δ(δ=0.1)
4. **多样性维持**：种群多样性<阈值时增加变异率
5. **可追溯性**：每次变异记录原因、效果、代数

## 4. DNA可追溯性

```yaml
mutation_record:
  dna_id: "DNA-01-003"
  generation: 3
  mutation_type: "gaussian"
  trait: "checklist_weight"
  before: 0.25
  after: 0.28
  fitness_before: 9.53
  fitness_after: 9.56
  improvement: +0.03
  reason: "适应度梯度引导变异"
```
