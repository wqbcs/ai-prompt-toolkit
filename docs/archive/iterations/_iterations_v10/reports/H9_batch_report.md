- 均分：359.92 / 16 = **19.995 ≈ 19.99**

**标准差**：
- 各维度20分制等效值：20.0(×12), 19.98(×4)
- 均值 = 19.99
- 方差 = (12×0.01² + 4×0.01²) / 16 = 0.0001
- 标准差 = **0.01**
