## 1. GDPR(欧盟通用数据保护条例)

### 1.1 适用范围
- 27个EU成员国 + EEA国家
- 处理EU公民数据的任何组织(不论所在地)
- 生效日期：2018年5月25日

### 1.2 核心要求映射

| GDPR条款 | 要求 | 提示词体系影响 | 实现方式 |
|----------|------|---------------|---------|
| Art.5(1)(a) | 合法、公正、透明 | 提示词必须告知用户数据处理 | 数据处理声明模板 |
| Art.5(1)(b) | 目的限定 | 提示词仅用于声明目的 | 目的限定注解 |
| Art.5(1)(c) | 数据最小化 | 仅收集必要数据 | 最小数据字段定义 |
| Art.5(1)(d) | 准确性 | 数据必须准确且及时更新 | 数据验证规则 |
| Art.5(1)(e) | 存储限定 | 数据不过度保留 | 保留策略+自动删除 |
| Art.5(1)(f) | 完整性与保密性 | 安全处理 | 加密+访问控制 |
| Art.6 | 合法基础 | 明确处理的法律基础 | 合法基础声明 |
| Art.13-14 | 告知义务 | 数据主体知情 | 隐私声明本地化 |
| Art.15 | 访问权 | 主体可访问其数据 | 数据访问API |
| Art.17 | 删除权(被遗忘权) | 主体可要求删除数据 | 数据删除API+级联删除 |
| Art.20 | 可携带权 | 数据可转移 | 数据导出(标准格式) |
| Art.35 | DPIA | 高风险处理需影响评估 | DPIA模板+评估流程 |
| Art.37 | DPO | 指定数据保护官 | DPO联系方式声明 |
| Art.44-49 | 跨境传输 | 传输到第三国需保障 | SCCs+充分性决定 |

### 6.2 合规区域自动检测

```python
def detect_compliance_region(request):
    """根据请求来源自动判定适用法规"""
    regions = []
    if request.user_location in EU_COUNTRIES:
        regions.append("GDPR")
    if request.user_location == "CA" or request.business_in_california:
        regions.append("CCPA")
    if request.user_location == "CN" or request.processes_cn_data:
        regions.append("PIPL")
    if request.user_location == "BR":
        regions.append("LGPD")
    if request.user_location == "SG":
        regions.append("PDPA")
    return regions or ["GDPR"]  # 默认最严格
```
