# 提示词商店治理体系

> 版本：v16.0.0

---

## 1. 质量门槛

### 1.1 发布门槛(必须全部通过)

| # | 门槛 | 标准 | 检查方式 |
|---|------|------|---------|
| Q1 | Schema合规 | 所有场景符合场景Schema | 自动检查 |
| Q2 | 安全扫描 | 无注入/无敏感信息/无恶意代码 | 自动SAST |
| Q3 | 测试覆盖 | 核心场景测试覆盖率≥80% | 自动检测 |
| Q4 | 文档完整 | README+CHANGELOG+LICENSE存在 | 自动检查 |
| Q5 | 许可证合规 | 使用SPDX标准许可标识 | 自动检查 |
| Q6 | 语义版本 | 符合SemVer 2.0规范 | 自动验证 |
| Q7 | i18n合规 | 无硬编码可翻译字符串 | 伪本地化检测 |
| Q8 | 依赖安全 | 无已知高危依赖 | SCA扫描 |

### 1.2 推荐门槛(额外加分)

| # | 门槛 | 标准 | 加分 |
|---|------|------|------|
| R1 | 多语言 | 支持3+语言 | +10 |
| R2 | 性能基准 | 有性能基准数据 | +5 |
| R3 | 示例丰富 | 每场景有2+示例 | +5 |
| R4 | 社区验证 | 5+用户使用反馈 | +10 |

## 2. 审核流程

### 2.1 自动审核(即时)

```
提交 → Schema检查 → 安全扫描 → 依赖扫描 → i18n检查 → 许可证检查
  │                                                           │
  └─── 任一失败 → 拒绝(附原因) ────────────────────────────────┘
  │                                                           │
  └─── 全部通过 → 进入人工审核队列 ─────────────────────────────┘
```

### 2.2 人工审核(1-3工作日)

| 审核员 | 审核范围 | 资格 |
|--------|---------|------|
| 自动审核 | Schema+安全+依赖+i18n+许可证 | 自动化 |
| 社区Reviewer | 内容质量+可操作性+示例完整性 | Silver级+ |
| Maintainer | 整体质量+兼容性+命名规范 | Platinum级+ |
| 安全Reviewer | 安全深度审查(如涉及) | 安全 Officer |

### 2.3 审核标准

| 审核维度 | 权重 | 评分标准 |
|---------|------|---------|
| 正确性 | 30% | 输出符合Schema，逻辑正确 |
| 安全性 | 25% | 无注入/泄露/恶意行为 |
| 可操作性 | 20% | 步骤清晰，可直接执行 |
| 文档质量 | 15% | 描述完整，示例充分 |
| 代码质量 | 10% | 规范，可读，可维护 |

## 3. 下架标准

### 3.1 强制下架(立即)

| # | 标准 | 触发条件 |
|---|------|---------|
| D1 | 安全漏洞 | 发现高危漏洞且7天内未修复 |
| D2 | 恶意行为 | 包含数据窃取/后门/挖矿代码 |
| D3 | 许可证违规 | 使用不兼容许可证或侵权 |
| D4 | 法律要求 | 收到法律下架通知 |
| D5 | 垃圾内容 | 纯垃圾/占位/无意义内容 |

### 3.2 警告下架(30天整改期)

| # | 标准 | 触发条件 |
|---|------|---------|
| D6 | 长期不维护 | 12个月无更新+有未解决Issue |
| D7 | 质量退化 | 评分降至2.0以下 |
| D8 | 兼容性断裂 | 与当前SDK不兼容且不更新 |
| D9 | 重复包 | 与已有包高度重复(>80%)且质量更低 |

### 3.3 下架流程

```
触发下架标准 → 通知作者(7天响应期)
  │
  ├── 作者修复 → 重新审核 → 恢复上架
  │
  └── 作者未响应/未修复 → 下架公告 → 标记deprecated → 30天后移除
```

## 4. 纠纷处理

### 4.1 纠纷类型

| 类型 | 示例 | 处理方 |
|------|------|--------|
| 命名争议 | 两个包使用相似名称 | Maintainer仲裁 |
| 质量投诉 | 包质量与描述不符 | Reviewer核实 |
| 许可证纠纷 | 许可证不兼容争议 | 法律顾问 |
| 抄袭争议 | 内容抄袭他人作品 | Maintainer+法律 |
| 安全争议 | 对安全性评估有异议 | Security Officer |

### 4.2 纠纷处理流程

```
提交纠纷 → 初审(1工作日) → 分类 → 指派处理方
  │
  ├── 简单纠纷 → 直接处理(3工作日)
  ├── 复杂纠纷 → 调查+听证(14工作日)
  └── 重大纠纷 → 委员会决议(30工作日)
  │
  └── 处理结果 → 通知双方 → 执行 → 归档
```

### 4.3 申诉机制

- 对纠纷结果不满可申诉(7天内)
- 申诉由更高级别处理方审理
- 最终由技术委员会裁决

## 5. 商店分级

| 级别 | 标志 | 条件 | 权益 |
|------|------|------|------|
| Verified | ✓ | 质量分≥80+安全通过+3月+维护 | 搜索加权+官方推荐 |
| Official | ★ | PEA联盟官方发布 | 置顶+信任标记+优先支持 |
| Community | — | 通过基本审核 | 正常展示 |
