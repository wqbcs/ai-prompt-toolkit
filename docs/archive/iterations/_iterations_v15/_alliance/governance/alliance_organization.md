# 提示词工程联盟(PEA)组织架构

> 版本：v1.0 | 日期：2026-05-29

---

## 1. 联盟概述

**Prompt Engineering Alliance (PEA)** — 提示词工程联盟

- **使命**：建立提示词工程作为独立学科，推动标准制定、参考实现和生态发展
- **愿景**：成为提示词工程领域的全球权威组织，类似CNCF之于云原生
- **成立时间**：2026年Q4(计划)
- **托管方**：Linux Foundation(计划)

## 3. 理事会

### 3.1 席位分配

| 席位类型 | 数量 | 产生方式 | 任期 |
|----------|------|---------|------|
| 创始会员代表 | 3 | 创始会员指定 | 2年 |
| 正式会员代表 | 2 | 正式会员选举 | 2年 |
| 社区代表 | 2 | 个人会员选举 | 1年 |

### 3.2 理事会职责

- 批准年度预算和战略方向
- 任命执行董事(ED)和首席技术官(CTO)
- 批准新项目进入沙箱/孵化/毕业
- 批准标准发布
- 修改联盟章程

### 3.3 投票机制

- 每项决议需简单多数(>50%)通过
- 标准发布需2/3多数通过
- 章程修改需3/4多数通过

## 4. 技术委员会(TC)

### 4.1 席位分配(9席)

| 来源 | 席位 |
|------|------|
| 创始会员技术代表 | 3 |
| 正式会员技术代表 | 2 |
| 项目负责人(毕业级) | 2 |
| 社区选举 | 2 |

### 4.2 四个工作组

| 工作组 | 职责 | 产出 |
|--------|------|------|
| UPPL标准工作组 | UPPL语言规范制定+演进 | UPPL Spec v1.0/v2.0/v3.0 |
| 运行时规范工作组 | 运行时API+沙箱+安全规范 | Runtime Spec v1.0/v2.0 |
| SDK规范工作组 | SDK接口规范+兼容性测试 | SDK Spec v1.0 |
| 安全与合规工作组 | 安全基线+合规框架+威胁模型 | Security Baseline v1.0 |

### 4.3 项目成熟度模型

```
沙箱(Sandbox)          入户(Incubating)        毕业(Graduated)         认证(Certified)
├── 概念验证               ├── ≥5活跃贡献者          ├── ≥10活跃贡献者        ├── 安全审计通过
├── ≥2贡献者               ├── CI/CD+测试覆盖        ├── 生产部署案例          ├── 合规认证
├── 基础文档               ├── 完整文档+示例         ├── i18n文档             ├── 性能基线达标
├── CLA签署                ├── 安全扫描              ├── 安全扫描+修复         ├── 互操作认证
└── TC赞助人               ├── 社区健康指标          ├── 发布版本≥3            └── 品牌授权
```

## 5. 教育委员会(EC)

### 5.1 三个工作组

| 工作组 | 职责 |
|--------|------|
| 课程工作组 | PE-101/201/301课程设计+教材编写 |
| 认证工作组 | PEC-P/A/E三级认证+考试设计 |
| 培训工作组 | 培训合作伙伴+讲师认证 |

### 5.2 认证体系

| 级别 | 名称 | 要求 | 目标人群 |
|------|------|------|---------|
| PEC-P | Prompt Engineer - Practitioner | PE-101课程+考试 | 从业者 |
| PEC-A | Prompt Engineer - Associate | PE-201课程+考试+项目 | 中级工程师 |
| PEC-E | Prompt Engineer - Expert | PE-301课程+考试+贡献 | 高级工程师 |

## 6. 社区委员会(CC)

### 6.1 大使计划

- 全球50位PEA大使
- 每位大使负责一个地区/领域
- 年度大使峰会
- 大使任期1年，可续任

### 6.2 本地社区

- PE-Meetup：月度本地聚会
- PE-Hackathon：季度黑客松
- PE-Bootcamp：新手训练营

## 7. 标准对外委员会(SC)

### 7.1 ISO/IEC对接

- 提交NP(新工作项目提案)
- 参与WD/CD/DIS/FDIS各阶段
- 维护国内镜像委员会

### 7.2 NIST对接

- AI RMF提示词安全补充
- 参与NIST AI评估框架

### 7.3 其他标准组织

- W3C：提示词API标准化
- IEEE：提示词质量度量标准
- ANSI：美国国家标准镜像
