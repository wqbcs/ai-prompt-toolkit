### 1.2 定期自动扫描

| 扫描项 | 频率 | 检查内容 |
|--------|------|---------|
| 维度完整性 | 每日 | 42维度168子维度覆盖检查 |
| 场景模板健康 | 每日 | 陷阱/性能/安全项缺失检查 |
| 错误码一致性 | 每周 | PE-XXXX编码规范+分段检查 |
| 输出格式合规 | 每周 | 编号列表+格式要求+示例检查 |
| 检查清单标签 | 每周 | 安全/性能/功能/规范/合规标签检查 |
| 故障排查覆盖 | 每周 | Top5故障+诊断+修复覆盖检查 |
| 依赖健康度 | 每日 | 场景间依赖断裂/循环检查 |
| 语义漂移 | 每周 | 提示词语义偏离基线检查 |

### 1.3 衰减检测增强

| 检测类型 | 算法 | 阈值 |
|---------|------|------|
| 渐进衰减 | 线性回归斜率 | 斜率<-0.01/日 |
| 急性衰减 | 突变检测(Z-score) | Z>3 |
| 周期衰减 | FFT频谱分析 | 周期性振幅>0.1 |
| 累积衰减 | 指数加权移动平均 | EWMA下降>5% |
| 跨维度衰减 | 相关性矩阵变化 | 相关系数变化>0.15 |

### 1.4 健康评分体系

| 等级 | 分数范围 | 含义 | 动作 |
|------|---------|------|------|
| A+ | 95-100 | 优秀 | 维持 |
| A | 90-94 | 良好 | 持续优化 |
| B | 80-89 | 合格 | 定期改进 |
| C | 70-79 | 需关注 | 限期改进 |
| D | 60-69 | 不合格 | 紧急改进 |
| F | <60 | 严重 | 立即修复 |

### 1.5 智能改进建议

| 建议类型 | 生成方式 | 优先级排序 |
|---------|---------|-----------|
| 缺失补充 | 扫描结果→模板填充建议 | 高→低按缺失数 |
| 质量提升 | 低分项→改进方案 | 按提升潜力 |
| 衰减修复 | 衰减检测→修复建议 | 按严重程度 |
| 合规修复 | 规范扫描→修复建议 | 按影响范围 |
| 性能优化 | 基准测试→优化建议 | 按ROI排序 |

### 1.6 自动修复流程

```
扫描检测 → 生成建议 → 人工审批 → 自动执行 → 验证确认
    ↑                                       │
    └─────────── 修复失败回滚 ───────────────┘
```
