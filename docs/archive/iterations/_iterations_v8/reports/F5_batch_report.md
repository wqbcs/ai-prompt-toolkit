## 迭代F5-2：步骤级评估定义

**目标**：评估精度从场景级到步骤级
**操作**：
- 三级评估精度：
  - L1场景级：整体场景评分（现有级别）
  - L2步骤级：场景内每个步骤评分
  - L3检查点级：每个步骤的每个检查点评分
- 评分计算：
  - L3检查点分 = 通过/总数 × 满分
  - L2步骤分 = ΣL3分 / L3数
  - L1场景分 = ΣL2分 / L2数

**效果**：推理模式适配性+0.1
