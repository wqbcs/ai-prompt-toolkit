## 一、功能增添 (高优先级)

### F1. Prompt Playground交互式测试环境
- **参考**: Langfuse Playground、promptfoo Web Viewer
- **描述**: 本地Web UI，可实时编辑Prompt、选择模型、查看输出、对比不同版本
- **实现**: 使用Rich Live + Textual TUI，或生成静态HTML单文件playground
- **MCP**: 新增 `prompt_playground` tool

### F2. OpenTelemetry原生集成
- **参考**: Langfuse OTel集成、华为云AOM
- **描述**: 当前tracing.py已有OTLP导出，但未集成OTel SDK标准API
- **实现**: 添加 `opentelemetry-api` 可选依赖，Tracer实现OTel TracerProvider接口

### F3. CI-CD GitHub Action
- **参考**: promptfoo code-scan-action
- **描述**: 发布GitHub Action，在PR中自动运行lint+security+eval
- **实现**: 创建 `.github/action/` 目录，action.yml + Dockerfile

### F4. Prompt版本管理增强
- **参考**: Langfuse Prompt Management
- **描述**: 当前prompt_version.py只有简单版本保存，缺少diff/rollback/tag
- **实现**: 添加版本对比、标签、一键回滚

### F5. 攻击签名学习(VectorDB)
- **参考**: Rebuff自硬化机制
- **描述**: 将检测到的注入攻击embedding存储，下次相似攻击自动拦截
- **实现**: 纯Python实现简易向量索引(FAISS-free)，余弦相似度匹配

## 二、内容改进 (中优先级)

### C1. Lint规则描述/修复建议中英双语
- 当前85条规则描述全中文，国际用户不友好
- 添加 `description_en` / `remediation_en` 字段

### C2. 华为云赛事模板集扩充
- 当前53个场景模板，华为云专项仅10个
- 新增: 华为云FunctionGraph/CCN/DWS/GaussDB/ROMA模板

### C3. Red Team Probe文档完善
- 90个Probes缺少详细文档和使用示例
- 生成Probe Catalog文档，含攻击向量+预期行为+检测方式

## 三、细节优化 (中优先级)

### D1. PromptCache批量操作
- 当前只支持单key操作，缺少batch_put/batch_get
- 添加 `put_batch()` / `get_batch()` 方法

### D2. Linter规则性能基准
- 85条规则逐条运行，未做性能优化
- 添加规则执行耗时统计，识别慢规则，支持并行检查

### D3. Fixer修复冲突检测
- 多个修复可能互相冲突(如P048改标点+P081改变量)
- 添加冲突检测，按优先级排序修复

### D4. MCP Server流式响应
- 当前MCP响应是完整JSON，大评估报告可能超限
- 支持分页/流式响应

## 四、用户体验改善 (高优先级)

### U1. CLI进度条和实时反馈
- 长时间运行的lint/eval缺少进度提示
- 使用Rich Progress添加进度条

### U2. 错误提示友好化
- 当前错误信息偏技术化，普通用户难理解
- 添加 `--verbose` 模式和友好错误提示

### U3. 配置文件支持
- 当前所有配置通过CLI参数，缺少.pyproject.toml/promptkit.toml配置文件
- 添加 `promptkit.toml` 配置文件支持，含默认lint规则/缓存配置/输出格式

### U4. init命令模板选择
- `promptkit init` 当前只生成基础文件
- 添加交互式模板选择(Huawei Cloud/HarmonyOS/Security/General)
