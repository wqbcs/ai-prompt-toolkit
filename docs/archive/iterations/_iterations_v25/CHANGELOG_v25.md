## v25.0.0 (2026-07-12)

### 功能增添 (3项)

- **F1 A/B测试v2引擎**: 多模型并行对比(2-8模型)，参考promptfoo架构
  - 配置Schema (ab_test_v2_config.yaml)
  - 并行执行调度器 (Promise.allSettled模式)
  - 统计评估引擎 (t检验 + Mann-Whitney U检验 + Cohen's d + 置信区间)
  - 胜率矩阵生成器 (M×N矩阵 + 颜色编码 + 样本量标注)
  - 最优匹配推荐器 (胜率+显著性双模式)
  - 对比报告模板 (6维评估+胜率矩阵+推荐+统计+异常)

- **F2 模板继承引擎**: 单继承+覆盖/扩展+深度限制，参考Fabric Pattern
  - 继承元数据Schema (单继承 + 覆盖 + 扩展)
  - 继承关系图谱 (DFS循环检测 + 深度≤5 + 断裂检测)
  - 模板合并引擎 (子优先覆盖 + 扩展追加 + Token限制检查 + 冲突检测)
  - 变更传播报告 (高/中/低影响分析)

- **F3 条件编译引擎**: 三维度条件指令，参考C预处理器+Handlebars
  - 语法规范 (model/language/industry + ==/!=/in/not_in + &&/||)
  - 编译引擎 (解析器 + 副作用检测 + 条件匹配器 + 结果生成器)
  - LRU缓存层 (命中率≥80%, 命中<10ms, 最大1000条, TTL=24h)
  - 编译报告模板 (激活/忽略/未覆盖分支 + 告警)
