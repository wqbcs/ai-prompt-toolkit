## 功能增添 (3项)

### F1 A/B测试v2引擎

多模型并行对比框架，参考promptfoo/promptfoo架构设计：

- **配置Schema**: 支持2-8个模型并行对比，6维评估（准确性/相关性/连贯性/完整性/效率/安全性）
- **并行执行调度器**: Promise.allSettled模式，N模型并发耗时≤1.5×单模型
- **统计评估引擎**: t检验（正态+大样本）+ Mann-Whitney U检验（非正态/小样本）+ Cohen's d效果量 + 置信区间
- **胜率矩阵**: M×N矩阵（M模板×N模型），含胜率+样本量+p值+颜色编码
- **最优匹配推荐**: 基于胜率+统计显著性的自动推荐，排除不稳定结果
- **对比报告**: 6维评估结果+胜率矩阵+最优匹配+统计显著性+异常标注

### F2 模板继承引擎

单继承+覆盖/扩展机制，参考Fabric Pattern链式调用：

- **继承元数据Schema**: 单继承+覆盖字段+扩展字段
- **继承关系图谱**: DFS循环继承检测+深度限制(≤5层)+链断裂检测
- **模板合并引擎**: 子优先覆盖+扩展追加+Token限制检查+冲突检测与报告
- **变更传播报告**: 父模板变更自动分析影响范围（高/中/低影响级别）

### F3 条件编译引擎

三维度条件编译，参考C预处理器+Handlebars语法：

- **语法规范**: `{{#if}}`/`{{#else}}`/`{{/if}}`，三维度(model/language/industry)，4操作符(==/!=/in/not_in)，2逻辑符(&&/||)，嵌套≤3层
- **编译引擎**: 解析器+副作用检测+条件匹配器+结果生成器
- **LRU缓存**: 缓存命中率≥80%，命中响应<10ms，最大1000条，TTL=24h
- **编译报告**: 激活/忽略/未覆盖分支+未覆盖条件告警+语法校验
