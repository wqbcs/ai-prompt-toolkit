## 二、多模态Prompt设计模式

### 2.1 图文分离模式（推荐用于架构评审）

```
[系统指令]
你是一位架构评审专家。

[文本输入]
项目使用微服务架构，包含以下服务：{服务列表}

[图像输入]
<image:架构图.png>
请先描述图中展示的架构结构，然后结合文本信息进行评审。

[处理指令]
1. 图像→文本：将架构图转换为结构化文本描述
2. 文本+文本描述→综合分析
3. 输出：架构评审报告(JSON)
```

### 2.2 图文融合模式（推荐用于监控分析）

```
[系统指令]
你是一位监控运维专家。

[图像输入]
<image:仪表盘截图.png>

[文本输入]
当前告警：{告警列表}

[处理指令]
1. 从仪表盘截图中提取关键指标数值
2. 与告警列表交叉验证
3. 识别告警根因
4. 输出：根因分析报告+修复建议
```

### 2.3 代码截图模式（推荐用于代码审查）

```
[系统指令]
你是一位代码审查专家。

[图像输入]
<image:代码截图.png>

[处理指令]
1. OCR提取代码文本
2. 识别编程语言
3. 执行代码审查（安全性/性能/可维护性）
4. 输出：审查结果(JSON)
```

## 三、最佳实践总结

### 3.1 设计原则

| 原则 | 说明 | 优先级 |
|------|------|--------|
| 文本优先 | 图像先转文本描述再处理 | P0 |
| 降级兼容 | 无图像时纯文本仍可工作 | P0 |
| 格式约束 | 图像描述遵循结构化模板 | P1 |
| 跨模态验证 | 图文交叉验证一致性 | P1 |
| 不确定性标注 | 单模态结论标注[待验证] | P2 |

### 3.2 性能优化

- 图像预处理：裁剪/压缩至模型最优分辨率
- 批量处理：多图场景采用单次多图而非多次单图
- 缓存策略：相同图像描述结果缓存复用
- 降级策略：视觉模型不可用时回退至OCR+纯文本

### 3.3 对本体系的建议

1. 为02/07/09/10场景添加多模态输入处理指令
2. 定义标准化的图像描述模板(架构图/流程图/时序图/仪表盘)
3. 在接口定义中增加可选的`image_input`字段
4. 为国产模型(Qwen-VL/DeepSeek-VL)设计降级适配策略
5. 在评估框架中增加多模态场景的专项评估维度
