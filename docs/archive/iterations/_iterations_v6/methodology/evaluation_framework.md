## 三、LLM-as-Judge评估(v3.0升级)

### 3.1 设计原则
1. 每维度独立Judge Prompt(含新增互操作/生态维度)
2. 3次采样取中位数
3. 交叉评估(不同模型Judge同一输出)
4. 反转测试(验证位置偏差)
5. 基线锚定(已知质量样本校准)
6. Promptfoo CI/CD自动触发(v3.0新增)
7. 评估Dashboard实时可视化(v3.0新增)

### 3.2 Judge模板扩展

```
你是AI提示词体系质量评估专家。请对以下场景模板输出进行十维度评估：

评估维度：
1. 结构完整性(0-20)：5要素覆盖
2. 约束完备性(0-20)：4维度覆盖
3. 角色设定深度(0-20)：4要素完整
4. 输出格式精确性(0-20)：格式+示例
5. 检查清单覆盖度(0-20)：覆盖度+分组
6. 推理模式适配性(0-20)：CoT/Few-shot/自纠错
7. 前沿技术适配度(0-10)：PoT/Active-Prompt/Agent-First
8. 行业垂直化覆盖度(0-10)：3件套+专用场景
9. 互操作性(0-10)：接口契约+零损耗传递
10. 生态开放度(0-10)：贡献+API+Dashboard

输出格式：JSON {dimension: score, reasoning: string}
```
