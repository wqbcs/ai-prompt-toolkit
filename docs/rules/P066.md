# P066 — 多轮对话上下文窗口溢出风险

> 严重级: 🟡 medium | 类别: performance | 家族: context_window | 可自动修复: ✂ 是

## 描述

多轮对话Prompt未设定上下文截断或摘要策略

<details><summary>English</summary>

Multi-turn dialog Prompt does not set context truncation or summarization strategy
</details>

## 修复建议

<details><summary>English</summary>

Add context window limit (e.g., 'Only reference the last N turns') or summarization instructions
</details>
