# P197 — LLM输出长度失控

> 严重级: 🟠 high | 类别: inference2security | 家族: inference_max_tokens | 可自动修复: ✂ 是

## 描述

LLM推理未限制max_tokens, 输出长度失控可能致成本暴增

<details><summary>English</summary>

LLM inference has no max_tokens limit, output length uncontrolled may cause cost explosion
</details>

## 修复建议

限制输出长度: max_tokens=2048(对话)/4096(长文), 如 generation: {max_tokens: 2048}

<details><summary>English</summary>

Limit output length: max_tokens=2048(chat)/4096(long), e.g. generation: {max_tokens: 2048}
</details>
