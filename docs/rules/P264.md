# P264 — 厂商专属对话格式硬编码

> 严重级: 🟢 low | 类别: portability | 家族: cross_model_portability | 可自动修复: 否

## 描述

Prompt硬编码厂商专属对话分隔符(Human:/Assistant:、### Instruction:/### Response:、<|system|>、[INST]等) — 该格式只对特定模型/框架有效, 移植后结构语义丢失

<details><summary>English</summary>

Prompt hardcodes vendor-specific chat delimiters (Human:/Assistant:, '### Instruction:/'### Response:', <|system|>, [INST], etc.) — the format is only meaningful to one specific model/framework; structural semantics are lost when ported
</details>

## 修复建议

改用调用方消息API的role字段(system/user/assistant)承载对话结构, prompt正文不硬编码厂商分隔符

<details><summary>English</summary>

Use the API's role fields (system/user/assistant) to carry conversation structure instead of hardcoding vendor delimiters in the prompt body
</details>
