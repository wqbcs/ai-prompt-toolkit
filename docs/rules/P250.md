# P250 — Prompt缓存中毒

> 严重级: 🟠 high | 类别: prompt_governance | 家族: governance_cache_poison | 可自动修复: ✂ 是

## 描述

共享Prompt缓存可被污染, 导致恶意输出注入到其他用户响应

<details><summary>English</summary>

Shared Prompt cache can be poisoned, injecting malicious output into other users' responses
</details>

## 修复建议

缓存安全: 命名空间隔离+签名验证+TTL+缓存清洗, 如 cache_ns=user_id, verify_signature(cached), ttl=300s, sanitize(cache_entry)

<details><summary>English</summary>

Cache security: namespace isolation+signature verification+TTL+cache sanitization
</details>
