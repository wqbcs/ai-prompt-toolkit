# P256 — 模板变量完整性

> 严重级: 🟠 high | 类别: structure | 家族: template_integrity | 可自动修复: 否

## 描述

模板占位符畸形({{ }}/{{my-var}}渲染器不识别, 静默未填充)或引用了声明段之外的变量, 渲染期才暴露

<details><summary>English</summary>

Malformed template placeholders ({{ }}, {{my-var}} — renderer keeps them silently) or references to variables missing from the declared variables section, surfacing only at render time
</details>

## 修复建议

变量完整性: 占位符名仅用\w+, 有回退用{{var|default('x')}}; 显式声明段与正文引用交叉核对

<details><summary>English</summary>

Variable integrity: placeholder names use \w+ only, use {{var|default('x')}} for fallbacks; cross-check declared section against body references
</details>
