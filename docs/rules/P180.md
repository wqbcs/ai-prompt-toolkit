# P180 — 链式Prompt注入

> 严重级: 🔴 critical | 类别: security | 家族: chain_injection | 可自动修复: ✂ 是

## 描述

Prompt存在跨步骤链式注入传播风险, 恶意内容可从步骤N传播到步骤N+1(参考promptfoo chain scan)

<details><summary>English</summary>

Cross-step chain injection propagation risk, malicious content can spread from step N to N+1 (ref: promptfoo chain scan)
</details>

## 修复建议

每步输出作为下步输入前进行安全清洗, 实现步骤间沙箱隔离, 对中间结果做注入检测

<details><summary>English</summary>

Sanitize each step output before next input, implement step sandboxing, detect injection in intermediate results
</details>
