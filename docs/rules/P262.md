# P262 — 跨模型身份绑定

> 严重级: 🟡 medium | 类别: portability | 家族: cross_model_portability | 可自动修复: 否

## 描述

Prompt将自身身份绑定到特定模型品牌(你是ChatGPT/You are a GPT-4 assistant等) — 移植到其他模型时身份声明失真, 且向模型植入未授权的身份

<details><summary>English</summary>

Prompt binds its identity to a specific model brand (e.g. 'You are ChatGPT' / 'You are a GPT-4 assistant') — identity declaration goes stale when ported to another model and injects an unauthorized identity
</details>

## 修复建议

删除模型品牌名的身份声明, 用能力/角色描述替代(如'你是一个专业代码审查助手'), 模型选择由调用方在API参数指定而非写进prompt正文

<details><summary>English</summary>

Remove the model-brand identity declaration; describe the role/capability instead (e.g. 'You are a professional code-review assistant'); select the model via API parameters, not prompt body
</details>
