# P183 — 环境隔离不足

> 严重级: 🟡 medium | 类别: operations | 家族: prompt_isolation | 可自动修复: ✂ 是

## 描述

Prompt缺少环境隔离配置, 生产/测试/开发环境可能混用导致意外行为

<details><summary>English</summary>

Prompt lacks environment isolation, prod/test/dev may mix causing unexpected behavior
</details>

## 修复建议

为不同环境配置不同参数(模型/温度/约束), 使用环境变量或配置文件隔离

<details><summary>English</summary>

Configure different parameters per environment (model/temperature/constraints), use env vars or config files
</details>
