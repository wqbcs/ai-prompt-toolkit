# P266 — 连接串密码字面暴露

> 严重级: 🔴 critical | 类别: security | 家族: pii_exposure | 可自动修复: 否

## 描述

Prompt中含带密码段的连接串(scheme://user:password@host, 密码非空) — 凭据字面进 prompt 即泄露(对话记录/日志/模型输出面均可复现); 与P006(赋值面password=xxx)互补, 本规则管URL内嵌面

<details><summary>English</summary>

Connection string with embedded password (scheme://user:password@host, non-empty password) in the prompt — a literal credential in a prompt is a leak (reproducible from chat logs, traces, and model outputs); complements P006 (assignment form password=xxx): this rule covers the URL-embedded form
</details>

## 修复建议

凭据移出prompt: 环境变量/密钥管理服务(KMS)引用, prompt内只保留无密码的连接信息(scheme://host:port/db); 已暴露的凭据立即轮换

<details><summary>English</summary>

Move the credential out of the prompt: reference it via environment variable or KMS, keep only password-free connection info (scheme://host:port/db) in the prompt; rotate any already-exposed credential
</details>
