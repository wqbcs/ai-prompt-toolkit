# P182 — 依赖声明缺失

> 严重级: 🟡 medium | 类别: operations | 家族: prompt_dependencies | 可自动修复: ✂ 是

## 描述

Prompt缺少外部依赖声明(模型/API/工具), 变更时无法评估影响范围

<details><summary>English</summary>

Prompt lacks dependency declaration (model/API/tool), cannot assess impact on change
</details>

## 修复建议

声明Prompt依赖的模型版本、API端点、工具列表, 如 dependencies: [gpt-4, weather-api]

<details><summary>English</summary>

Declare model version, API endpoints, tool list in Prompt, e.g. dependencies: [gpt-4, weather-api]
</details>
