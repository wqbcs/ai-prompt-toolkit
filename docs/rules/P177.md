# P177 — Base64编码混淆注入

> 严重级: 🔴 critical | 类别: security | 家族: encoding_injection | 可自动修复: ✂ 是

## 描述

Prompt包含Base64/十六进制/Unicode编码内容, 可能混淆绕过安全检测(参考garak encoding probe)

<details><summary>English</summary>

Prompt contains Base64/hex/Unicode encoded content, may bypass security checks (ref: garak encoding probe)
</details>

## 修复建议

解码所有编码内容后进行安全审查, 禁止Prompt中包含未解码的编码指令

<details><summary>English</summary>

Decode all encoded content for security review, prohibit undecoded instructions in prompts
</details>
