# P260 — 编码/混淆注入面

> 严重级: 🟠 high | 类别: security | 家族: encoding_evasion | 可自动修复: 否

## 描述

Prompt含已知注入载荷的编码形态(零宽字符5+/词内插入、注入关键词base64片段、解码指令+b64共现、同形异码、hex/URL编码) — 混淆=有意规避检测

<details><summary>English</summary>

Prompt contains encoded forms of known injection payloads (5+ consecutive or in-word zero-width chars, base64 fragments of injection keywords, decode-instruction + base64 co-occurrence, homoglyph substitution, hex/URL-encoded keywords) — obfuscation = deliberate detection evasion
</details>

## 修复建议

移除编码混淆的注入内容; 合法编码数据请避免与解码指令共现, 并在prompt中声明数据边界

<details><summary>English</summary>

Remove the obfuscated injection content; for legitimate encoded data, avoid co-occurrence with decode instructions and declare the data boundary
</details>
