# P261 — 不可见字符交错/BiDi反转注入面

> 严重级: 🟠 high | 类别: security | 家族: encoding_evasion | 可自动修复: 否

## 描述

Prompt含零宽字符(U+200B/200C/2060)3+交错或BiDi override/isolate控制字符(U+202C-2E/U+2066-69, 含\u转义形态) — 不可见隐藏=检测规避或Trojan Source显示反转

<details><summary>English</summary>

Prompt contains 3+ interleaved zero-width chars (U+200B/200C/2060) or BiDi override/isolate control chars (U+202C-2E/U+2066-69, incl. \u-escaped forms) — invisible concealment = detection evasion or Trojan Source display reversal
</details>

## 修复建议

移除不可见控制字符及其转义形态; 合法RTL文字(阿/希/波斯文字字符)不受影响, 仅不可见override控制字符被报

<details><summary>English</summary>

Remove the invisible control characters and their escaped forms; legitimate RTL script text (Arabic/Hebrew/Persian) is not affected — only invisible override controls are reported
</details>
