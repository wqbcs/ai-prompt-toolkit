# P047 — 角色混淆(H7)

> 严重级: 🟠 high | 类别: quality | 家族: role_confusion | 可自动修复: 否

## 描述

多角色Prompt中角色定义存在冲突或重叠，模型行为边界不清晰

<details><summary>English</summary>

Multi-role Prompt has conflicting or overlapping role definitions, model behavior boundaries unclear
</details>

## 修复建议

明确每个角色的职责边界: 使用分隔符区分角色、避免角色功能重叠、定义角色间交互协议

<details><summary>English</summary>

Clarify each role's responsibility boundary: use separators to distinguish roles, avoid role overlap, define inter-role interaction protocol
</details>
