## 描述

推理加载模型权重未校验完整性, 替换攻击可植入后门模型

<details><summary>English</summary>

Inference loads model weights without integrity check, replacement attack can implant backdoored model
</details>

## 修复建议

权重完整性: SHA256校验+签名验证+可信源下载+加载前校验, 如 verify_checksum(weights, expected='sha256:abc...') + verify_signature(weights, pub_key)

<details><summary>English</summary>

Weight integrity: SHA256 checksum+signature verification+trusted source+pre-load verification
</details>
