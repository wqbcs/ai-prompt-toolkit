# P263 — 确定性与随机性声明矛盾

> 严重级: 🟡 medium | 类别: portability | 家族: cross_model_portability | 可自动修复: 否

## 描述

Prompt同时声明确定性/一致性要求(必须一致/可复现/deterministic)与随机性/创造性要求(随机/creative/多样性) — 两者互斥, 不同模型对矛盾约束的取舍不同, 移植时行为漂移

<details><summary>English</summary>

Prompt declares both determinism/consistency requirements (must be identical / reproducible / deterministic) and randomness/creativity requirements (random / creative / diverse) — mutually exclusive; different models resolve the conflict differently, so behavior drifts when ported
</details>

## 修复建议

二选一: 要可复现就删随机性要求并固定temperature=0; 要多样性就删确定性声明。明确声明预期行为边界, 不靠模型自行调和矛盾

<details><summary>English</summary>

Pick one: for reproducibility remove the randomness requirement and pin temperature=0; for diversity remove the determinism declaration. State the expected behavior boundary explicitly instead of letting the model reconcile
</details>
