# P041 — 工具描述模糊性(H1)

> 严重级: 🟠 high | 类别: agent | 家族: agent_tool | 可自动修复: 否

## 描述

Agent型Prompt中工具/函数描述模糊或过于简短，模型可能无法正确选择和调用

<details><summary>English</summary>

Agent Prompt has vague or overly brief tool/function descriptions, model may not select and call correctly
</details>

## 修复建议

为每个工具提供清晰的描述: 功能、参数、返回值、使用场景、注意事项

<details><summary>English</summary>

Provide clear descriptions for each tool: functionality, parameters, return values, use cases, caveats
</details>
