# P241 — GDPR数据最小化违规

> 严重级: 🟠 high | 类别: compliance_audit | 家族: compliance_gdpr_minimization | 可自动修复: ✂ 是

## 描述

Prompt收集超出必要范围的个人数据(姓名/地址/身份证/健康), 违反GDPR数据最小化原则

<details><summary>English</summary>

Prompt collects personal data beyond necessary scope (name/address/ID/health), violating GDPR data minimization
</details>

## 修复建议

数据最小化: 仅收集任务必需数据+匿名化/假名化+定期审查, 如 collect(name='optional', email='required', address='excluded')

<details><summary>English</summary>

Data minimization: collect only task-essential data+anonymization+pseudonymization+regular review
</details>
