# P258 — 伪造系统级标签声明缺失

> 严重级: 🟠 high | 类别: security | 家族: injection_surface | 可自动修复: 否

## 描述

Prompt含伪造系统级分隔标签(【系统】/[SYSTEM]/<|system|>/<<SYS>>), 且标签近邻无'示例/演示'声明 — 标签是特权边界操纵面

<details><summary>English</summary>

Prompt contains fake system-level delimiter tags (【系统】/[SYSTEM]/<|system|>/<<SYS>>) without a nearby 'example/demonstration' declaration — tags are a privilege-boundary manipulation surface
</details>

## 修复建议

删除伪系统标签; 若为few-shot示例, 在标签80字符内声明'以下是示例/供参考'

<details><summary>English</summary>

Remove the fake system tag; if it is a few-shot example, declare 'the following is an example' within 80 characters of the tag
</details>
