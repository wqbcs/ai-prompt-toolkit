# P271 — 指令文件编码隐藏指令（base64隐藏形态）

> 严重级: 🟠 high | 类别: security | 家族: injection | 可自动修复: 否

## 描述

Prompt/指令文件含 base64 隐藏指令: HTML 注释内 base64 块（24+字符）或 data:text/* URI 内 base64 文本载荷 — 指令文件 IPI 典型隐藏载体（解码=采集/外传指令+'不告知用户'掩饰; data:image/* 内嵌图片为良性不报）

<details><summary>English</summary>

Prompt/instruction file contains base64-encoded hidden instructions: a base64 block (24+ chars) inside an HTML comment, or a base64 text payload in a data:text/* URI — the typical hidden-instruction carrier in agent IPI (decodes to harvest/exfil instructions with concealment phrases; data:image/* embedded images are benign and not flagged)
</details>

## 修复建议

审查注释/data URI 中的 base64 内容: 解码检查是否含采集/外传类隐藏指令; 合法文档场景无注释内长 base64 或 data:text/* 载荷用途。此类文件应按供应链投毒处置（隔离+审查来源）

<details><summary>English</summary>

Audit base64 content in comments/data URIs: decode and check for hidden harvest/exfiltration instructions; legitimate documentation has no use for long base64 in comments or data:text/* payloads. Treat such files as supply-chain poisoning (isolate + review provenance)
</details>
