# P268 — 全角字母注入bypass面

> 严重级: 🟠 high | 类别: security | 家族: encoding_evasion | 可自动修复: 否

## 描述

Prompt含全角拉丁字母(U+FF21-FF5A)连续段且NFKC解码后精确命中注入动词(ignore/disregard/override/forget/bypass/jailbreak) — 全角化=有意规避英文检测(行业共识对策=NFKC归一化, 本规则为该对策的确定性静态实现)

<details><summary>English</summary>

Prompt contains a run of fullwidth Latin letters (U+FF21-FF5A) that NFKC-decodes exactly to an injection verb (ignore/disregard/override/forget/bypass/jailbreak) — fullwidth substitution is deliberate evasion of English detection (the industry consensus countermeasure is NFKC normalization; this rule is its deterministic static implementation)
</details>

## 修复建议

移除全角字母伪装: 全角注入内容仍按注入处置(改回半角不改变攻击性质); 良性全角拉丁(如日语ＯＫ/ＮＧ)不受本规则影响

<details><summary>English</summary>

Remove the fullwidth-letter disguise: a fullwidth injection payload is still an injection (converting it back to halfwidth does not change its nature); legitimate fullwidth Latin (e.g. Japanese OK/NG) is not affected by this rule
</details>
