# P265 — 缓存前缀含运行时动态内容

> 严重级: 🟡 medium | 类别: portability | 家族: prompt_caching | 可自动修复: 否

## 描述

Prompt前缀区(前512有效字符, frontmatter豁免)含运行时动态token(datetime.now()/uuid/{timestamp}/'当前时间：{xxx}'等, 每次渲染值都变)且prompt有缓存收益(缓存意图词或长prompt) — prompt caching是前缀精确字节匹配, 前缀任一点变化击溃其后全部缓存, 成本静默翻倍

<details><summary>English</summary>

Runtime-varying tokens (datetime.now() / uuid / {timestamp} / '当前时间：{x}' etc. — value changes on every render) sit in the stable prefix zone (first 512 effective chars, frontmatter exempt) of a prompt that benefits from caching — prompt caching is an exact prefix-byte match, any prefix change invalidates everything after it (silent cost doubling)
</details>

## 修复建议

把运行时动态内容移到prompt末尾(追加位置不影响前缀); 序列化用sort_keys固定JSON key顺序; 时间戳/请求ID等改为API参数或尾部消息承载, 不进系统提示前缀

<details><summary>English</summary>

Move runtime-varying content to the end of the prompt (append position leaves the prefix intact); serialize JSON with sorted keys; carry timestamps/request IDs as API parameters or trailing messages instead of in the system-prompt prefix
</details>
