# P106 — 负面示例缺失

> 严重级: 🟢 low | 类别: quality | 家族: negative_example | 可自动修复: ✂ 是

## 描述

Prompt仅提供正面示例而缺少反例/负面示例，模型可能无法识别错误模式

<details><summary>English</summary>

Prompt only provides positive examples without negative examples, model may not recognize error patterns
</details>

## 修复建议

添加1-2个反例展示不期望的输出格式或内容

<details><summary>English</summary>

Add 1-2 counter-examples showing undesired output format or content
</details>
