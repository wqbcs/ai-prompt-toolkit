# P184 — 降级策略缺失

> 严重级: 🟡 medium | 类别: operations | 家族: prompt_degradation | 可自动修复: ✂ 是

## 描述

Prompt缺少降级策略, 当主模型不可用时无备用方案, 服务可能中断

<details><summary>English</summary>

Prompt lacks degradation strategy, no fallback when primary model unavailable, service may break
</details>

## 修复建议

声明降级策略: 主模型→备用模型→规则回复, 如 fallback: [gpt-3.5, template-response]

<details><summary>English</summary>

Declare fallback: primary→secondary→rule-based, e.g. fallback: [gpt-3.5, template-response]
</details>
