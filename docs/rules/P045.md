# P045 — 隐式指令失败(H5)

> 严重级: 🟡 medium | 类别: quality | 家族: implicit_instruction | 可自动修复: 否

## 描述

Prompt中存在隐含但未明确表达的期望，模型可能无法正确理解

<details><summary>English</summary>

Prompt contains implicit but unexpressed expectations, model may not understand correctly
</details>

## 修复建议

将隐式期望转为显式声明: 使用'必须'/'务必'代替默认假设，明确所有边界条件

<details><summary>English</summary>

Convert implicit expectations to explicit declarations: use 'must'/'shall' instead of default assumptions, clarify all boundary conditions
</details>
