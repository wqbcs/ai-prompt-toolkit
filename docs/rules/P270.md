# P270 — 指令文件提权/外传形态

> 严重级: 🟠 high | 类别: security | 家族: injection | 可自动修复: 否

## 描述

Prompt/指令文件含 agent 提权或外传攻击形态（自动批准/不请求确认/永不拒绝命令；凭据路径+外传动词+外部URL三信号共现；curl 外传系统指纹命令输出）— 指令文件 IPI 典型面（CLAUDE.md/AGENTS.md/SKILL.md 投毒）

<details><summary>English</summary>

Prompt/instruction file contains agent privilege-escalation or exfiltration attack patterns (auto-approve / never-ask-for-confirmation / never-refuse instructions; credential path + exfil verb + external URL co-occurrence; curl exfiltrating system-fingerprint command output) — the typical IPI surface in agent instruction files (CLAUDE.md/AGENTS.md/SKILL.md poisoning)
</details>

## 修复建议

移除提权/外传指令：自动批准与'永不拒绝'消除人工确认边界；凭据路径+外传=凭据外传攻击；curl 外传系统指纹=信息泄露。此类指令文件应按供应链投毒处置（隔离+审查来源）

<details><summary>English</summary>

Remove the privilege-escalation/exfiltration instructions: auto-approve and never-refuse eliminate the human confirmation boundary; credential path + exfiltration is a credential-exfiltration attack; curl-based system-fingerprint exfiltration is data leakage. Treat such instruction files as supply-chain poisoning (isolate + review provenance)
</details>
