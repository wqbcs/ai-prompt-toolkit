# P218 — 跨模态信息泄露

> 严重级: 🟠 high | 类别: multimodal_security | 家族: multimodal_cross_leak | 可自动修复: ✂ 是

## 描述

多模态上下文中, 一种模态的敏感信息可能通过另一种模态泄露(如图片中的文字被OCR提取)

<details><summary>English</summary>

Sensitive info in one modality may leak through another (e.g., text in image extracted by OCR)
</details>

## 修复建议

跨模态隔离: 模态间敏感标注+脱敏传递+访问控制, 如 tag_sensitive(image, 'PII') + redact_before_cross_modal(data)

<details><summary>English</summary>

Cross-modal isolation: sensitive tagging+redaction propagation+access control between modalities
</details>
