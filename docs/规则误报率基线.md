## 处置原则（R206 执行）

1. **100% 误报的 6 条（P010/P020/P158/P164/P166/P203）优先**：要么是正则恒匹配（恒真 bug），要么是检测条件写反 —— 逐条读源码定性。
2. 处置方式按序：修正则/补条件 > 降 severity > 移出默认规则集（保留手动启用） > 删除（仅当规则语义本身不成立）。
3. 每修一条必须：加负样本断言（干净样本不报）+ 保留原正样本命中（tests/test_rules_* 已覆盖的不动）。
4. 基线棘轮：CI 用 `--fail-above 0.084`（当前值）防劣化；每轮收紧规则后允许下调阈值，禁止上调。

## 样本扩充约定

- 新增干净 prompt 必须入库 `tests/fixtures/clean_prompts/` 并重新跑基线。

- 含敏感样例（密钥/注入）的**脏样本**不放此目录（脏样本属 `tests/test_rules_*` 的正样本职责）。
