## 处置原则（沿用）

1. 处置方式按序：修正则/补条件 > 降 severity > 移出默认规则集（保留手动启用） > 删除（仅当规则语义本身不成立）。
2. 每修一条必须：加负样本断言（干净样本不报）+ 保留原正样本命中（正样本升级为强语义词）。
3. 基线棘轮：CI 用 `--fail-above` 阈值防劣化；R207处置后全局3.17%，下轮收紧至0.034（当前值留裕度），禁止上调。

## 样本扩充约定

- 新增干净 prompt 必须入库 `tests/fixtures/clean_prompts/` 并重新跑基线。
- 样本需覆盖：结构完整的中文 prompt、英文 prompt、代码块、模板语法（`{{var}}`）、特殊字符。
- 含敏感样例（密钥/注入）的**脏样本**不放此目录（脏样本属 `tests/test_rules_*` 的正样本职责）。
