# ai-prompt-toolkit OSC2026 参赛示例

## 项目简介

**ai-prompt-toolkit** 是"ESLint for Prompts"——AI提示词全生命周期安全与质量工具链。

核心特性:
- 255条Lint规则(P001-P255), 196可自动修复, OWASP覆盖率100%
- 130评估维度 + 7行业权重预设 + S/A/B/C/D/F评分等级
- 73个MCP工具 + 25+ Provider(含华为云ModelArts/昇腾NPU)
- 声明式YAML测试套件 + 基线管理 + 成本追踪
- 鸿蒙ArkTS安全规则(P226-P230) + 华为云Pipeline模板G模板

## 快速开始

```bash
# 安装
pip install ai-prompt-toolkit

# Lint检查
prompt lint -t your_prompt.md

# 安全扫描
prompt scan -t your_prompt.md

# 评估
prompt eval -t your_prompt.md

# 基线管理
prompt lint -t your_prompt.md --baseline .baseline.json --baseline-save
prompt lint -t your_prompt.md --baseline .baseline.json

# 成本追踪
prompt eval -t your_prompt.md --cost-track
```

## 华为云集成

### CodeArts Pipeline
```yaml
# .codearts/pipeline-lint.yml
stages:
  - name: prompt-lint
    steps:
      - run: prompt lint -t prompts/ --statistics --owasp-report
  - name: prompt=eval
    steps:
      - run: prompt eval -t prompts/ --gate
```

### ModelArts评测
```bash
# 华为云鹏鹏模型评估
prompt eval -t prompt.md --provider huawei_modelarts --model pangu-large
```
