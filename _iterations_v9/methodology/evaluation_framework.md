## 3. 三级评估精度

| 级别 | 名称 | 粒度 | 用途 |
|------|------|------|------|
| L1 | 场景级 | 整体场景评分 | 版本收敛判定 |
| L2 | 步骤级 | 场景内步骤评分 | 步骤级优化 |
| L3 | 检查点级 | 每步骤每检查点 | 精确问题定位 |

**聚合规则**：
- L3→L2：步骤分 = Σ检查点分 / 检查点数
- L2→L1：场景分 = Σ步骤分 / 步骤数
- 子维度→主维度：主维度分 = Σ(子维度分×权重)

---

## 4. 收敛判定

- **均分** = Σ(维度得分_20分制等效) / 14
- **标准差** = σ = sqrt(Σ(xi - x̄)² / 14)
- **极致收敛条件**：
  - 均分 ≥ 19.8
  - 标准差 ≤ 0.03
  - 最低分(20分制) ≥ 19.5
  - 自进化度 ≥ 9.5
  - 可观测度 ≥ 9.5
