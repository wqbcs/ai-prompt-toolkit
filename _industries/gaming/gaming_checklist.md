# 游戏行业专项检查清单

> **版本**：v1.0.0
> **适用**：在线游戏服务端、游戏平台、游戏运营、电竞系统

---

## 一、实时性检查

### 1.1 网络延迟优化
- [ ] 就近接入：全球多区域部署+智能DNS/Anycast路由
- [ ] 协议选择：UDP(帧同步/状态同步)+TCP(非实时)+WebSocket(推送)
- [ ] 帧同步：固定步长(16ms/60fps)+客户端预测+服务端权威
- [ ] 状态同步：变化增量同步+插值/外推+兴趣区域(AOI)管理
- [ ] 延迟补偿：Lag Compensation+回滚+Rollback Netcode

### 1.2 服务端性能
- [ ] ECS架构(Entity-Component-System)用于游戏逻辑
- [ ] 无状态游戏网关(可水平扩展)
- [ ] 内存池/对象池避免GC停顿
- [ ] 定长帧更新(固定时间步长，不受帧率影响)
- [ ] 热更新机制(逻辑热更/配置热更/不停服更新)

### 1.3 实时通信
- [ ] 房间管理：创建/加入/离开/解散+状态同步
- [ ] 匹配系统：MMR/ELO匹配+区域+延迟约束
- [ ] 语音通信：VOIP集成(编解码/降噪/3D空间音效)
- [ ] 断线重连：状态恢复+补偿机制+超时判定

---

## 二、反作弊检查

### 2.1 客户端作弊防护
| 作弊类型 | 检测方法 | 防护措施 |
|---------|---------|---------|
| 内存修改 | 服务端权威校验+签名验证 | 关键逻辑服务端执行，客户端仅展示 |
| 速度作弊 | 服务端步长校验+位置校验 | 移动速度/频率服务端校验 |
| 透视/自瞄 | 行为统计分析+录像复盘 | 服务端视野控制+Fog of War |
| 自动脚本 | 行为模式识别+CAPTCHA | 人机验证+异常行为封禁 |
| 修改协议包 | 协议加密+签名+序列号 | Protobuf+AES+HMAC+防重放 |
| 注入DLL | 反调试+完整性校验 | 客户端完整性检查+反调试 |

### 2.2 服务端权威
- [ ] 所有影响游戏结果的操作服务端验证
- [ ] 客户端发送操作请求，服务端执行并广播结果
- [ ] 关键数值(血量/伤害/掉落/金币)服务端计算
- [ ] 客户端预测+服务端纠正(预测对则无感知，错则回滚)
- [ ] 作弊检测异步处理(不影响游戏实时性)

### 2.3 作弊检测系统
- [ ] 实时统计：击杀率/命中率/移动速度/反应时间异常
- [ ] 行为分析：操作模式/输入频率/鼠标轨迹异常
- [ ] 群体检测：组队作弊/串通/异常关联
- [ ] 机器学习：异常行为模型+新作弊手法自适应检测
- [ ] 举报系统：玩家举报+录像+人工审核

### 2.4 惩罚机制
- [ ] 分级惩罚：警告→临时封禁→永久封禁→设备封禁
- [ ] 惩罚审计：处罚记录+证据链+申诉流程
- [ ] 误判保护：惩罚前人工审核(高置信度除外)+申诉渠道

## 三、服务端架构检查

### 3.1 游戏服务架构
| 架构模式 | 适用场景 | 关键技术 |
|---------|---------|---------|
| 单服务器 | 小型/独立游戏 | 单进程/单线程游戏循环 |
| 区服架构 | MMORPG/SLG | 分区/分线/跨服+网关+游戏服+DB |
| 匹配+房间 | MOBA/FPS/BR | 匹配服+房间服+全局服 |
| 微服务 | 大型平台/中台 | 服务拆分+消息总线+配置中心 |
| Serverless | 休闲/社交游戏 | 按需启停+状态外部化 |

### 3.2 状态管理
- [ ] 游戏状态内存存储(Redis/自研缓存)
- [ ] 定期快照+操作日志(崩溃恢复)
- [ ] 跨服状态同步(跨服战/排行榜/聊天)
- [ ] 玩家数据冷热分离(在线=热/离线=冷)
- [ ] 数据一致性(乐观锁/版本号/CAS)

### 3.3 容量与伸缩
- [ ] 在线人数弹性伸缩(网关无状态+游戏服有状态)
- [ ] 有状态服务伸缩：平滑迁移+连接迁移+状态迁移
- [ ] 区服合服/拆服机制
- [ ] 大版本更新：预下载+热更+灰度+回滚
- [ ] 压测：模拟在线+模拟操作+压测机器人

### 3.4 运维专项
- [ ] 停服公告+数据备份+维护窗口管理
- [ ] 热更新审批流程(测试→灰度→全量)
- [ ] 客户端版本管理(强制更新/可选更新/兼容版本)
- [ ] 滚滚服/合服操作SOP
- [ ] 故障快速恢复(分钟级恢复+自动重启+降级预案)

## 四、游戏安全与合规

### 4.1 虚拟财产安全
- [ ] 虚拟货币/道具交易安全(防复制/防注入/防篡改)
- [ ] 充值/消费流程安全(支付回调验证+幂等+限额)
- [ ] 交易安全(防交易欺诈/防盗号交易/交易日志)
- [ ] 赠送/转借安全(限额+冷却期+验证)

### 4.2 未成年人保护
- [ ] 实名认证+年龄识别
- [ ] 防沉迷系统(时长限制+收益限制+强制下线)
- [ ] 消费限额(按年龄段限制单次/单日/单月消费)
- [ ] 22:00-次日8:00禁止登录(法定要求)
- [ ] 适龄提示+内容分级

### 4.3 内容合规
- [ ] 游戏版号审批(中国大陆)
- [ ] 内容审查(暴力/色情/政治/宗教/赌博)
- [ ] 聊天内容过滤(敏感词+图片+URL)
- [ ] UGC内容审核(玩家创作内容合规检查)
- [ ] 数据合规(个保法+数据出境+未成年人数据)
