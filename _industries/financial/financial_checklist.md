# 金融行业专项检查清单

> **版本**：v1.0.0
> **适用**：银行、证券、保险、支付、基金等金融业务系统

---

## 一、PCI-DSS合规清单

### 1.1 要求1：安装并维护网络安全控制
- [ ] 防火墙/网络分段将持卡人数据环境与其他网络隔离
- [ ] 禁止从互联网直接访问持卡人数据环境
- [ ] DMZ与内网之间双向流量受限
- [ ] 所有无线接入点配置并定期审计

### 1.2 要求2：将默认配置应用于所有系统组件
- [ ] 所有系统/服务默认密码已更改
- [ ] 不必要的服务/协议/端口已禁用
- [ ] 所有安全参数配置并记录
- [ ] 加密密钥管理流程就绪

### 1.3 要求3：保护存储的持卡人数据
- [ ] PAN(主账号)加密存储(AES-256或等效)
- [ ] 明文PAN不存储(除非有业务必要并有保护措施)
- [ ] 密钥管理：生成/分发/存储/轮换/撤销全生命周期
- [ ] 数据保留策略：最小化存储周期，到期安全删除

### 1.4 要求4：加密开放网络中的持卡人数据传输
- [ ] 传输层使用TLS 1.2+（禁止SSL/TLS1.0/1.1）
- [ ] 强加密算法和密钥长度(密钥>=128bit)
- [ ] 无线网络传输加密(WPA2/WPA3)
- [ ] 终端到终端的端到端加密(E2EE)如适用

### 1.5 要求5-12：持续维护与监控
- [ ] 恶意软件防护(防病毒/EDR)部署并定期更新
- [ ] 系统和应用程序定期安全更新和补丁
- [ ] 访问控制：最小权限原则+唯一ID+MFA
- [ ] 物理访问控制对持卡人数据区域
- [ ] 安全日志和审计跟踪全量记录
- [ ] 定期安全测试(年度评估+每季度漏洞扫描)
- [ ] 信息安全政策维护和员工培训

## 二、交易安全检查

### 2.1 交易完整性
- [ ] 交易幂等性保证(防重复扣款)
- [ ] 交易原子性保证(ACID/分布式事务/TCC/Saga)
- [ ] 交易状态机定义完备(待处理→处理中→成功/失败/超时)
- [ ] 超时处理机制(自动冲正/查询确认/人工干预)
- [ ] 对账机制(日终对账/实时对账/差异自动报警)

### 2.2 资金安全
- [ ] 金额精度处理(使用BigDecimal/分存储，禁用浮点)
- [ ] 单笔限额/单日限额/单月限额校验
- [ ] 大额交易双因子认证
- [ ] 异常交易风控拦截(频率/地域/金额/时间)
- [ ] 资金划拨审批流程(金额阈值分级审批)

### 2.3 支付安全
- [ ] 支付通道加密(端到端加密+签名验证)
- [ ] 敏感信息脱敏(卡号掩码/CVV不存储/有效期最小化)
- [ ] 支付回调签名验证(HMAC-SHA256+时间戳防重放)
- [ ] 支付异常自动退款/冲正机制
- [ ] 渠道监控(成功率/延迟/异常率告警)

---

## 三、风控模型审查

### 3.1 模型安全
- [ ] 模型输入数据完整性和合法性校验
- [ ] 模型对抗攻击防御(输入扰动/数据投毒)
- [ ] 模型版本管理和回滚机制
- [ ] 模型输出合理性检查(异常值检测/阈值告警)
- [ ] 模型可解释性(监管要求时的决策解释能力)

### 3.2 模型合规
- [ ] 模型训练数据来源合规(授权/脱敏/无歧视)
- [ ] 模型公平性审查(不同人群无歧视性差异)
- [ ] 模型审计日志(输入/输出/决策/时间全记录)
- [ ] 模型监管报送(模型说明文档/评估报告/变更审批)
- [ ] 模型定期重评估(性能退化/数据漂移/概念漂移)

### 3.3 反欺诈
- [ ] 实时风控引擎(规则+模型混合决策)
- [ ] 设备指纹采集和欺诈设备识别
- [ ] 行为生物特征分析(输入模式/操作习惯)
- [ ] 关联网络分析(团伙欺诈/资金链追踪)
- [ ] 灰度发布和人工复核机制

---

## 四、监管合规附加项

### 4.1 数据合规
- [ ] 个人金融信息保护(《个保法》+人行规范)
- [ ] 数据分类分级(5级分类：公开/内部/敏感/机密/绝密)
- [ ] 数据跨境传输合规(安全评估+标准合同+认证)
- [ ] 数据留存期限合规(交易数据5年/开户资料永久)

### 4.2 业务合规
- [ ] 反洗钱(AML)：KYC+交易监控+可疑报告
- [ ] 实名认证和开户合规
- [ ] 利率和费率合规(不超过监管上限)
- [ ] 投资者适当性管理(风险等级匹配)
- [ ] 信息披露合规(产品说明书/风险提示/费用明细)
