## 一、中国内地金融监管体系

### 1.1 核心法律法规
| 法规/规范 | 发布机构 | 核心要求 | 提示词适配 |
|-----------|---------|---------|-----------|
| 《个人信息保护法》 | 全国人大 | 个人信息处理七项原则+敏感信息单独同意+数据跨境评估 | 所有涉及个人金融信息的场景添加合规审查指令 |
| 《数据安全法》 | 全国人大 | 数据分类分级+数据安全评估+数据出境安全评估 | 数据架构设计场景添加分级标注和出境评估指令 |
| 《网络安全法》 | 全国人大 | 网络安全等级保护+关键信息基础设施保护 | 架构设计场景添加等保2.0要求 |
| 等保2.0 | 公安部 | 五个等级+安全通用要求+安全扩展要求 | 部署配置场景添加等保合规检查 |
| 《反洗钱法》 | 全国人大 | 客户身份识别+大额和可疑交易报告+客户身份资料保存 | 交易系统添加AML监控规则 |
| 《金融数据安全 数据安全分级指南》 | 人行 | 数据5级分类(L1-L5)+安全保护要求 | 所有数据处理场景添加分级标注 |

|------|---------|-----------|

## 二、国际金融合规标准

### 2.1 PCI-DSS 4.0
| 要求域 | 核心内容 | 提示词适配 |
|--------|---------|-----------|
| 网络安全控制 | 网络分段+防火墙+访问控制 | 架构设计添加CDE网络分段 |
| 持卡人数据保护 | 加密存储+最小化+脱敏展示 | 代码审查添加PAN加密和脱敏检查 |
| 加密传输 | TLS1.2++强密钥+端到端加密 | 安全审计添加传输加密验证 |
| 访问控制 | 最小权限+唯一ID+MFA | 部署配置添加MFA和权限控制 |
| 监控和测试 | 日志审计+定期测试+漏洞扫描 | 监控运维添加PCI专项告警 |

### 2.2 SOX合规(上市公司)
- 关键控制点识别和文档化
- 内控有效性测试和评估
- IT一般控制(GITC)：变更管理/访问管理/运营管理
- 审计轨迹完整性和不可篡改性

### 2.3 GDPR(跨境业务)
- 数据处理合法性基础(6种)
- 数据主体权利(访问/更正/删除/可携带/限制处理)
- 数据保护影响评估(DPIA)
- 跨境数据传输机制(充分性认定/SCCs/BCRs)

### 2.4 巴塞尔协议(银行)
- 信用风险/市场风险/操作风险三大类
- 资本充足率要求(8%+缓冲)
- 压力测试和情景分析
- 流动性覆盖率(LCR)和净稳定资金比率(NSFR)

## 三、合规审查提示词集成指引

| 提示词文档 | 金融合规增强点 | 优先级 |
|-----------|--------------|--------|
| 01_需求分析 | 需求阶段添加合规前置条件识别(P0) | P0 |
| 02_架构设计 | 架构设计添加数据分级+网络分段+加密方案 | P0 |
| 03_编码规范 | 编码规范添加金额处理+加密+脱敏+审计日志规范 | P0 |
| 04_代码审查 | 代码审查添加PCI-DSS/AML/个保法专项检查 | P0 |
| 05_测试策略 | 测试策略添加交易幂等/并发/对账/安全测试 | P1 |
| 06_CI/CD | 部署添加等保合规+密钥管理+审计日志配置 | P1 |
| 07_监控运维 | 监控添加交易异常/风控告警/合规指标 | P1 |
| 08_安全审计 | 安全审计添加金融专项(PCI/SOX/AML)审计模板 | P0 |
| 09_性能优化 | 性能优化添加交易延迟SLA+对账耗时+风控耗时约束 | P1 |
