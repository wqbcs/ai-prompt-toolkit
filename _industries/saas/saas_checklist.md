# SaaS行业专项检查清单

> **版本**：v1.0.0
> **适用**：多租户SaaS平台、企业SaaS、行业SaaS、SaaS基础设施

---

## 一、多租户隔离检查

### 1.1 数据隔离策略
| 隔离级别 | 架构模式 | 安全性 | 成本 | 适用场景 |
|---------|---------|--------|------|---------|
| 物理隔离 | 独立数据库+独立部署 | 最高 | 最高 | 金融/医疗/政府 |
| 逻辑隔离-库级 | 共享部署+独立数据库 | 高 | 中 | 中大型企业客户 |
| 逻辑隔离-Schema级 | 共享数据库+独立Schema | 中高 | 中低 | 中型企业客户 |
| 逻辑隔离-行级 | 共享数据库+共享表+tenant_id行级 | 中 | 最低 | 小型/免费客户 |

### 1.2 隔离完整性检查
- [ ] 所有数据表包含tenant_id字段且为联合主键/索引第一列
- [ ] 数据访问层强制tenant_id过滤(ORM拦截器/中间件)
- [ ] 跨租户数据访问防护(全局查询必须显式指定tenant_id)
- [ ] 租户数据导出隔离(导出范围限定在租户内)
- [ ] 数据库连接池按隔离级别配置(独立库=独立连接池)

### 1.3 运行时隔离
- [ ] 请求上下文自动注入tenant_id(网关/中间件)
- [ ] 缓存键包含tenant_id前缀(避免缓存穿透/混淆)
- [ ] 文件存储按租户隔离(目录/桶级隔离)
- [ ] 搜索索引按租户隔离(索引别名/routing key)
- [ ] 后台任务按租户隔离(任务队列/调度隔离)

## 二、数据隔离深度检查

### 2.1 数据泄露防护
- [ ] API响应自动过滤非当前租户数据
- [ ] 批量操作限制在单租户范围内
- [ ] 管理后台超级管理员操作审计(跨租户访问记录)
- [ ] 数据迁移工具限定源/目标租户范围
- [ ] 日志输出脱敏(不输出其他租户数据)

### 2.2 数据加密隔离
- [ ] 每租户独立加密密钥(或密钥派生)
- [ ] 加密字段按租户密钥加密/解密
- [ ] 密钥轮换不影响历史数据访问(密钥版本管理)
- [ ] 备份数据按租户隔离(可按租户独立恢复)

### 2.3 数据合规隔离
- [ ] 数据驻留地按租户合规要求配置(区域选择)
- [ ] 数据保留策略按租户配置(不同租户不同保留期)
- [ ] 数据删除按租户独立执行(租户注销=数据彻底删除)
- [ ] GDPR"被遗忘权"按租户粒度执行

## 三、计费安全检查

### 3.1 计费模型安全
| 计费模型 | 安全风险 | 防护措施 |
|---------|---------|---------|
| 按量计费 | 资源滥用/计费篡改 | 用量上限+异常检测+审计日志 |
| 按席位计费 | 虚增席位/共享账号 | 并发登录限制+活跃度检测+定期审查 |
| 按功能计费 | 功能越权/降级绕过 | 功能开关服务端校验+权限检查 |
| 预付费 | 余额耗尽服务中断 | 余额预警+宽限期+资源保留策略 |
| 混合计费 | 计费逻辑复杂出错 | 双重计算+对账+异常告警 |

### 3.2 计费完整性
- [ ] 用量采集不可篡改(服务端采集>客户端上报)
- [ ] 用量计算精度(小数精度/舍入规则统一)
- [ ] 计费规则版本管理(历史账单可回溯)
- [ ] 账单计算可验证(用量→规则→费用可追溯)
- [ ] 退款/调整审计(审批流程+调整记录)

### 3.3 计费安全防护
- [ ] 资源创建预扣费(余额检查→预扣→创建→确认/回退)
- [ ] 并发创建防超额(分布式锁+余额实时检查)
- [ ] 欠费处理策略(预警→限制→暂停→回收，分级处理)
- [ ] 计费异常检测(用量突增/费用异常/与历史偏差>30%)
- [ ] 费用上限保护(单租户/单资源/单周期费用上限)

### 3.4 价格安全
- [ ] 价格配置权限控制(仅运营/财务可修改)
- [ ] 价格修改审计日志(修改人/时间/原价/新价/生效时间)
- [ ] 价格版本管理(新价格可预约生效/历史价格可查)
- [ ] 折扣/优惠券安全(折扣范围+叠加规则+有效期)

## 四、SaaS平台专项

### 4.1 租户生命周期
- [ ] 租户注册→开通→配置→使用→暂停→恢复→注销 全流程
- [ ] 租户开通自动化(环境初始化+数据初始化+权限配置)
- [ ] 租户注销数据彻底删除(符合GDPR/个保法)
- [ ] 租户迁移(升级/降级/跨区域)数据完整性保障

### 4.2 定制化隔离
- [ ] 租户级配置(主题/字段/流程/规则)不影响其他租户
- [ ] 自定义逻辑沙箱化执行(不影响平台稳定性)
- [ ] 插件/扩展按租户隔离(资源/权限/数据)
- [ ] 租户代码定制版本管理(独立构建/部署/回滚)

### 4.3 SLA管理
- [ ] 按租户/套餐配置差异化SLA
- [ ] SLA监控和告警(可用性/延迟/错误率)
- [ ] SLA违规自动记录和处理
- [ ] SLA报告按租户定期生成
