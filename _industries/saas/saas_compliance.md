# SaaS行业合规要求

> **版本**：v1.0.0
> **覆盖**：多租户数据合规 + 计费合规 + 国际SaaS + SOC2

## 一、多租户数据合规

### 1.1 数据保护法规映射
| 法规 | 对SaaS的要求 | 提示词适配 |
|------|------------|-----------|
| GDPR | 数据处理者义务+DPA+数据驻留+被遗忘权+数据可携带 | 多租户架构添加GDPR合规设计 |
| CCPA | 消费者隐私权+数据销售拒绝+隐私通知 | 面向加州客户添加CCPA要求 |
| 个保法 | 敏感信息单独同意+数据出境评估+最小必要 | 面向中国客户添加个保法要求 |
| 数据安全法 | 数据分类分级+安全保护+风险评估 | 数据架构添加分级标注 |

### 1.2 数据处理者义务(GDPR)
- [ ] 与数据控制者签署数据处理协议(DPA)
- [ ] 仅按控制者书面指令处理数据
- [ ] 确保数据处理人员保密义务
- [ ] 实施适当技术和组织措施保护数据
- [ ] 协助控制者履行数据主体权利请求
- [ ] 数据泄露72小时内通知控制者
- [ ] 审计配合义务(提供合规证明/接受审计)
- [ ] 子处理者需经控制者授权

### 1.3 数据驻留与跨境
| 场景 | 合规要求 | 技术实现 |
|------|---------|---------|
| EU客户 | 数据存储在EU区域 | 按租户配置数据驻留区域 |
| 中国客户 | 重要数据不出境 | 中国区域独立部署+数据本地化 |
| 跨境SaaS | 数据传输安全评估/SCCs | 跨境传输配置+加密+审计 |

## 二、计费合规

### 2.1 透明计费要求
- [ ] 定价页面公开透明(所有计费项/单价/单位)
- [ ] 用量实时可查(当前周期用量/费用预估)
- [ ] 账单明细可追溯(用量→规则→费用全链路)
- [ ] 计费规则变更提前通知(>=30天)
- [ ] 无隐藏费用/自动续费需明确同意

### 2.2 发票与税务
- [ ] 自动开具电子发票(增值税/消费税/VAT/GST)
- [ ] 税率按租户注册地自动应用
- [ ] 发票信息与注册信息一致
- [ ] 跨境SaaS税务合规(代扣代缴/VAT MOSS)

### 2.3 计费安全
- [ ] 支付渠道合规(持牌支付机构)
- [ ] 退款流程合规(原路退回/审批/时限)
- [ ] 欠费处理合规(通知→宽限→暂停→不删除数据>=30天)
- [ ] 价格变更合规(不溯及既往+现有客户保护期)

## 三、SOC2合规

### 3.1 五大信任服务标准
| 标准 | 核心要求 | 提示词适配 |
|------|---------|-----------|
| 安全(Security) | 逻辑/物理访问控制+加密+防火墙+IDS | 安全审计添加SOC2安全控制检查 |
| 可用性(Availability) | 系统可用性+BCP/DR+监控+事件响应 | 监控运维添加SLA和BCP检查 |
| 处理完整性(Processing Integrity) | 数据处理完整/准确/及时/授权 | 代码审查添加数据处理完整性检查 |
| 保密性(Confidentiality) | 机密信息保护+加密+访问控制+销毁 | 安全审计添加数据保密性检查 |
| 隐私(Privacy) | 个人信息收集/使用/保留/披露/处置 | 全链路添加个人信息保护审查 |

### 3.2 SOC2控制点示例
- CC6.1：逻辑访问控制(角色+最小权限+MFA)
- CC6.2：用户认证和授权(唯一ID+审批+定期审查)
- CC7.1：安全事件检测和响应(监控+告警+事件响应)
- CC7.2：安全事件评估和修复(根因分析+修复+验证)
- CC8.1：变更管理(审批+测试+部署+回滚)
- CC9.1：风险识别和评估(年度风险评估+新服务评估)
