# 电商行业专项检查清单

> **版本**：v1.0.0
> **适用**：电商平台、零售系统、供应链系统、促销/营销系统

---

## 一、高并发设计检查

### 1.1 流量架构
- [ ] CDN静态资源加速+边缘缓存
- [ ] 多级缓存策略(浏览器→CDN→网关→应用→分布式缓存→数据库)
- [ ] 限流分级(网关限流→服务限流→DB限流)
- [ ] 异步化设计(MQ解耦非核心链路：日志/通知/积分)
- [ ] 读写分离+分库分表(按租户/时间/地域)
- [ ] 弹性伸缩(HPA基于QPS/CPU+定时预扩+大促预热)

### 1.2 秒杀/抢购专项
- [ ] 库存预热到Redis+原子扣减(Lua脚本/EVAL)
- [ ] 请求分层拦截(前端校验→网关限流→应用校验→DB扣减)
- [ ] 防超卖(分布式锁/乐观锁/库存令牌)
- [ ] 订单创建异步化(先排队后处理)
- [ ] 降级预案(库存售罄提示→验证码降级→直接拒绝)

### 1.3 搜索性能
- [ ] 搜索引擎选型(ES/ClickHouse)和索引优化
- [ ] 热搜词缓存+搜索建议预加载
- [ ] 商品列表分页优化(游标分页替代offset)
- [ ] 图片懒加载+WebP格式+CDN回源优化

---

## 二、交易一致性检查

### 2.1 分布式事务
- [ ] 下单-扣库存-支付三步事务一致性保障
- [ ] TCC模式：Try(预留)→Confirm(确认)→Cancel(取消)
- [ ] Saga模式：正向操作+补偿操作编排
- [ ] 本地消息表+定时补偿(最终一致性)
- [ ] 事务状态机：待支付→已支付→已发货→已完成/已取消

### 2.2 库存一致性
- [ ] 库存扣减幂等性(订单ID+操作类型联合去重)
- [ ] 库存回滚机制(取消订单/超时未支付/退货)
- [ ] 多SKU库存一致性(规格组合库存同步)
- [ ] 多仓库存一致性(总库存=各仓库存之和)
- [ ] 库存预占和释放机制(下单预占/支付确认/超时释放)

### 2.3 金额一致性
- [ ] 金额使用BigDecimal/分存储，禁用浮点
- [ ] 订单金额=商品金额+运费-优惠券-积分抵扣
- [ ] 退款金额<=实付金额
- [ ] 促销叠加规则和金额校验
- [ ] 支付-退款-对账三方一致

### 2.4 数据一致性
- [ ] 对账机制：交易-支付-物流三方日终对账
- [ ] 差异自动报警和人工处理流程
- [ ] Binlog监听+数据校验+自动修复
- [ ] 延迟消息+超时处理(未支付自动取消)

---

## 三、促销安全检查

### 3.1 促销防刷
- [ ] 优惠券防刷：设备指纹+账号限领+IP限频+图验证
- [ ] 拼团防刷：虚拟人数检测+机器人识别+团长风控
- [ ] 砍价防刷：进度异常检测+同设备多账号识别
- [ ] 秒杀防刷：答题/验证码+请求排队+黑名单过滤
- [ ] 新人专享：首单检测+新设备+新手机号多因子验证

### 3.2 促销规则安全
- [ ] 促销叠加规则：互斥/叠加/最优策略明确
- [ ] 促销叠加上限：最大折扣率>=成本价+最低毛利率
- [ ] 优惠券安全：面额合理性+使用门槛+有效期+使用范围
- [ ] 满减安全：阶梯合理性+不允许负数+封顶金额
- [ ] 0元订单风险：强制最低支付0.01元或特殊审批

### 3.3 价格安全
- [ ] 价格计算链完整校验(挂牌价→促销价→优惠券→积分→实付价)
- [ ] 价格修改审计日志(修改人/时间/原价/新价)
- [ ] 价格异常监控(低于成本/异常折扣/与历史差异>30%)
- [ ] 前端展示价格与后端计算价格一致性校验
- [ ] 并发修改价格防冲突(乐观锁/版本号)
