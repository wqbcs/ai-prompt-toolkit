# 电商行业合规要求

> **版本**：v1.0.0
> **覆盖**：中国电商法规 + 消费者权益 + 跨境电商 + 数据保护

## 一、中国电商法规体系

### 1.1 核心法律
| 法规 | 核心要求 | 提示词适配 |
|------|---------|-----------|
| 《电子商务法》 | 经营者登记+信息披露+交易记录保存3年+消费者权益 | 需求分析添加电商经营者义务审查 |
| 《消费者权益保护法》 | 七天无理由退货+知情权+公平交易+个人信息保护 | 订单系统添加退货机制+信息披露 |
| 《价格法》 | 明码标价+禁止价格欺诈+禁止虚假折扣 | 价格系统添加价格合规检查 |
| 《广告法》 | 禁止虚假宣传+极限用语+特殊商品广告审查 | 商品描述添加广告合规审查 |
| 《反不正当竞争法》 | 禁止虚假交易/刷单炒信/商业贿赂 | 交易系统添加刷单识别规则 |
| 《个人信息保护法》 | 最小必要+单独同意+数据安全评估 | 所有涉及用户信息场景添加保护审查 |
| 《网络安全法》+等保2.0 | 网络安全等级保护+数据安全 | 电商平台等保三级要求 |

### 1.2 部门规章
| 规章 | 发布机构 | 核心要求 | 提示词适配 |
|------|---------|---------|-----------|
| 《网络交易监督管理办法》 | 市场监管总局 | 刷单管控+评价真实+价格规范+七日无理由 | 交易系统添加刷单检测+评价合规 |
| 《互联网广告管理办法》 | 市场监管总局 | 广告标识+弹出广告+直播带货规范 | 商品展示添加广告标识审查 |
| 《网络食品安全违法行为查处办法》 | 市场监管总局 | 食品电商特殊资质+冷链+追溯 | 食品类目添加资质和追溯检查 |

## 二、消费者权益保护技术实现

### 2.1 七天无理由退货
| 商品类型 | 是否适用 | 技术实现 |
|---------|---------|---------|
| 一般商品 | 适用 | 签收后7天内自动开放退货入口 |
| 定制商品 | 不适用 | 商品标记"不支持7天退换" |
| 鲜活易腐 | 不适用 | 商品标记+发货后不可退 |
| 数字商品 | 不适用 | 虚拟商品标记+已消费不可退 |
| 拆封后影响品质 | 不适用 | 商品标记+拆封检测 |

### 2.2 价格合规
- 划线价必须为真实成交的最低价格(7天/30天内)
- 促销价折扣计算基于原价，禁止虚构原价
- 价格变更历史保留>=3年
- 价格展示包含：原价/促销价/优惠明细/到手价

## 三、跨境电商合规

### 3.1 进出口合规
| 合规项 | 要求 | 提示词适配 |
|--------|------|-----------|
| 海关备案 | 跨境电商企业海关登记+平台备案 | 上架流程添加海关资质检查 |
| 正面清单 | 仅允许清单内商品进口(跨境电商零售进口) | 商品上架添加清单校验 |
| 限额管理 | 单次5000元+年度26000元 | 订单系统添加限额校验 |
| 税收合规 | 跨境电商综合税/行邮税 | 订单计算添加跨境税收 |
| 商品合规 | 中文标签+检验检疫+3C认证 | 商品管理添加合规标记 |

### 3.2 跨境数据
- 用户数据本地化存储(中国用户数据不出境)
- 跨境数据传输安全评估
- 支付数据符合外汇管理要求

## 四、电商安全专项合规

### 4.1 支付安全
| 要求 | 实现方式 | 对应场景 |
|------|---------|---------|
| 支付牌照 | 仅对接持牌支付机构 | 架构设计添加支付通道合规 |
| 交易安全 | HTTPS+签名+加密+防重放 | 代码审查添加支付安全检查 |
| 资金安全 | 对账+限额+风控+审计 | 监控运维添加交易对账告警 |
| 用户资金 | 存管/备付金管理合规 | 架构设计添加资金隔离 |

### 4.2 反欺诈
| 欺诈类型 | 检测方法 | 对应场景 |
|---------|---------|---------|
| 刷单炒信 | 行为模式+设备指纹+IP关联+异常交易 | 交易系统添加刷单检测 |
| 薅羊毛 | 领券频率+设备+账号+IP多因子 | 促销系统添加防薅机制 |
| 退货欺诈 | 退货频率+金额+商品+地址异常 | 售后系统添加退货风控 |
| 支付欺诈 | 盗卡检测+异常支付+IP地域 | 支付系统添加支付风控 |
