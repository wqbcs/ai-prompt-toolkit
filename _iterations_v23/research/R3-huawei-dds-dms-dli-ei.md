## 一、华为云DDS（文档数据库服务）

### 1.1 服务概述

华为云DDS（Document Database Service）是完全兼容MongoDB协议的文档数据库服务，提供集群、副本集和单节点三种部署模式。

### 1.2 核心能力

| 能力 | 描述 | 版本 |
|------|------|------|
| 集群模式 | Shard+Config+Mongos三层架构 | 4.0/4.2/4.4/5.0 |
| 副本集 | 一主两从自动故障转移 | 4.0/4.2/4.4/5.0 |
| 单节点 | 开发测试低成本方案 | 4.0/4.2/4.4/5.0 |
| 弹性伸缩 | 纵向规格变更+横向扩容Shard | 2025增强 |
| 备份恢复 | 自动备份+ PITR +跨Region备份 | 2025增强 |
| 安全合规 | SSL+VPC+KMS+审计日志 | 2025增强 |

### 1.3 开发/调优要点

- **连接池管理**：连接数限制(默认800-5000)、连接池配置最佳实践
- **索引优化**：复合索引ESR规则(Equality→Sort→Range)、覆盖查询
- **分片键选择**：避免单调递增(热点)、推荐哈希分片+范围分片混合
- **读写分离**：ReadPreference策略(Primary/Secondary/Nearest)
- **聚合管道优化**：$match前置、$project减字段、$lookup限制

### 1.4 陷阱Top5

1. 分片键选择不当导致数据倾斜
2. 大文档(>16MB)更新导致性能骤降
3. 索引过多影响写入性能
4. 连接泄漏未释放
5. $lookup嵌套过深导致超时

## 二、华为云DMS（分布式消息服务）

### 2.1 服务概述

华为云DMS（Distributed Message Service）提供Kafka/RabbitMQ/RocketMQ/AMQP四种消息队列引擎。

### 2.2 核心能力

| 引擎 | 特点 | 适用场景 |
|------|------|---------|
| Kafka | 高吞吐、持久化、分布式 | 日志采集、流处理、事件驱动 |
| RabbitMQ | 灵活路由、ACK确认、死信 | 业务解耦、异步通知、任务队列 |
| RocketMQ | 事务消息、延迟消息、顺序 | 订单处理、金融交易、精准调度 |
| AMQP | IoT轻量级、MQTT桥接 | 设备消息、移动推送、传感器数据 |

### 2.3 开发/运维要点

- **Kafka调优**：分区数(建议3-100)、批量大小(16KB-1MB)、压缩(lz4/zstd)
- **RabbitMQ调优**：预取计数(Qos prefetch)、消息持久化、死信队列
- **RocketMQ调优**：事务消息流程、延迟级别(1s-2h)、消费幂等
- **AMQP调优**：连接复用、消息大小限制、QoS等级选择
- **监控指标**：消息堆积量、消费延迟、生产/消费TPS、分区均衡

### 2.4 陷阱Top5

1. 消费者Rebalance导致重复消费
2. 消息堆积未及时告警
3. 分区数调整不可逆
4. 死信队列消息未处理
5. 事务消息超时未回查

## 三、华为云DLI（数据湖探索）

### 3.1 服务概述

华为云DLI（Data Lake Insight）是Serverless化的数据湖分析服务，支持SQL/Spark/Flink三种引擎。

### 3.2 核心能力

| 引擎 | 特点 | 适用场景 |
|------|------|---------|
| SQL引擎 | 标准SQL、跨源查询、物化视图 | 即席查询、报表分析、数据探索 |
| Spark引擎 | 批处理、MLlib、DataFrame | ETL处理、机器学习、图计算 |
| Flink引擎 | 实时流处理、窗口计算、CEP | 实时监控、风控、流式ETL |

### 3.3 开发/分析要点

- **SQL优化**：分区裁剪、列裁剪、谓词下推、Join重排序
- **Spark调优**：Executor内存/核心比(1:2-1:4)、序列化(Kryo)、广播Join
- **Flink调优**：Checkpoint间隔(1-5min)、状态后端(RocksDB)、反压监测
- **跨源查询**：OBS/IAM/DWS/GaussDB数据源联邦查询
- **数据格式**：Parquet(列存+压缩)、ORC(索引+谓词下推)、CSV(简单+无压缩)

### 3.4 陷阱Top5

1. 小文件过多导致查询性能下降
2. Shuffle分区数设置不当
3. Flink Checkpoint超时失败
4. 跨源查询权限配置错误
5. 数据倾斜导致Task OOM

## 四、华为云EI（企业智能服务）

### 4.1 服务概述

华为云EI（Enterprise Intelligence）提供OCR/语音/图像识别/自然语言处理等AI能力。

### 4.2 核心能力

| 服务 | 特点 | 适用场景 |
|------|------|---------|
| OCR | 通用/证件/票据/表格识别 | 文档数字化、发票处理、身份核验 |
| 语音 | ASR(语音转文字)+TTS(文字转语音) | 语音助手、会议记录、客服机器人 |
| 图像识别 | 标签/分类/检测/分割 | 内容审核、工业质检、医学影像 |
| NLP | 分词/实体/情感/翻译 | 舆情分析、智能客服、内容推荐 |
| 视频分析 | 结构化/目标追踪/动作识别 | 安防监控、交通分析、直播审核 |

### 4.3 开发/集成要点

- **OCR优化**：图片预处理(去噪/矫正/增强)、区域选择(ROI)、多页PDF处理
- **语音优化**：采样率(16kHz+)、VAD(语音活动检测)、热词定制
- **图像优化**：压缩传输(Base64<10MB)、批量调用、缓存结果
- **NLP优化**：领域定制模型、Prompt工程、多语言处理
- **通用优化**：API限流(QPS)、重试策略、异步调用、结果缓存

### 4.4 陷阱Top5

1. 图片过大导致API超时
2. OCR复杂表格结构识别错误
3. 语音背景噪声干扰ASR准确率
4. API调用频率超限被拒绝
5. 自定义模型训练数据不足
