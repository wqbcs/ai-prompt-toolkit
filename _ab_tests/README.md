# _ab_tests — A/B 测试引擎

## 引擎简介

`_ab_tests` 是提示词基础设施的 A/B 测试引擎，支持对提示词变体进行统计显著性对比实验。主要功能包括：

- **实验管理**：创建、配置、启停 A/B 测试实验
- **样本收集**：自动分配用户到不同变体组并收集结果
- **统计分析**：基于统计检验评估变体间差异显著性
- **推荐生成**：根据实验数据自动生成最优变体推荐

## 使用指南

### 目录结构

```
_ab_tests/
├── README.md          # 本文件
├── config.yaml        # 测试引擎配置
└── (测试核心代码)
```

### 测试流程

1. 定义测试假设与变体
2. 配置样本量与分流策略
3. 运行实验并收集数据
4. 执行统计检验
5. 生成推荐报告

### 配置说明

参见 `config.yaml`，关键配置项：

- `min_sample_size`：最小样本量
- `timeout_seconds`：实验超时时间
- `credential_encryption`：凭据加密方式

### 测试报告

测试输出遵循 `_schemas/ab_test_report.schema.json` 定义的格式。
