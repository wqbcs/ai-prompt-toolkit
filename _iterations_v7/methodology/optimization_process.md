## 3. 单次迭代标准流程

```
1. 确定迭代目标(批次主题+具体任务)
2. 读取当前状态(基线+维度评分+差距)
3. 执行优化操作(修改场景模板/新增基础设施)
4. 验证优化效果(LLM-as-Judge+回归测试)
5. 记录追溯(增强型五元组v4.0)
6. 更新CHANGELOG
7. 收敛判定(均分+标准差)
```

## 4. 门禁标准

### 4.1 迭代门禁
- 每次迭代后回归测试通过率 = 100%
- 效果评估准确率 ≥ 95%
- 追溯记录完整率 = 100%

### 4.2 批次门禁
- 批次内所有迭代完成
- 批次目标达成
- 批次追溯记录完整

### 4.3 形式化验证门禁(新增)
- 安全关键场景必须通过形式化验证
- 模型检查反例必须修正后方可继续
- 安全关键证明必须同行评审

### 4.4 自适应调优门禁(新增)
- 调优方案必须人工审批
- 调优后必须通过CI/CD门禁
- 调优后必须通过回归测试
- 效果验证A/B测试p<0.05

### 4.5 收敛门禁
- 十二维度均分 ≥ 19.0
- 标准差 ≤ 0.6
- 回归测试全部通过
- 体系完整性回归通过
