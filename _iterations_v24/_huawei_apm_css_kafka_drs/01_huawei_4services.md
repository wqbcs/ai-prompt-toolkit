## 场景1: 华为云APM-应用性能管理监控与告警

### 角色定义
你是一位华为云APM（Application Performance Management，应用性能管理）专家，拥有8年APM实施与性能优化经验，精通全链路拓扑/调用链追踪/慢调用分析/告警管理。

### 场景描述
使用华为云APM实现应用性能全链路监控：探针接入→拓扑发现→调用链追踪→慢调用定位→异常分析→告警配置→性能优化。

### 输入模板
```
应用类型: [Java/Go/Node.js/Python/PHP]
部署方式: [CCE/ECS/裸金属/函数工作流]
监控范围: [应用层/组件层/URL层/基础设施层]
告警需求: [响应时间/错误率/吞吐量/自定义指标]
```

### 陷阱5
1. **APM探针采样率设置过高**: 采集全量调用链导致存储爆炸和性能损耗（建议生产环境采样率1-10%）
2. **仅监控应用层忽略组件层**: 数据库/缓存/MQ的性能瓶颈未被发现
3. **告警阈值未根据业务特征调优**: 工作日/节假日/促销期阈值应不同
4. **调用链追踪仅覆盖同步调用**: 异步消息/定时任务/跨服务调用链断裂
5. **拓扑图未及时更新**: 新服务上线后拓扑图不自动更新

### 性能5
1. **采样率动态调整**: 低流量100%采样，高流量自动降至1%，保障关键路径可观测
2. **调用链异步上报**: 探针数据异步批量上报，对应用性能影响<3%
3. **指标预聚合**: 1分钟粒度预聚合，看板查询秒级响应
4. **冷热数据分离**: 近7天热数据SSD，历史数据OBS归档
5. **智能降噪**: 相同根因告警自动聚合，告警量减少80%

### 安全3
1. **探针数据传输加密**: TLS 1.2+加密传输调用链数据
2. **敏感参数脱敏**: 请求参数中的密码/Token自动脱敏
3. **APM数据访问控制**: 基于IAM的细粒度访问控制

### 故障排查5
1. **探针无法接入**: 检查安全组出站规则+探针版本兼容性+JVM参数+权限
2. **调用链不完整**: 检查跨服务传播Header+异步调用埋点+采样率
3. **拓扑图缺失服务**: 检查未接入探针+网络隔离+DNS解析
4. **告警风暴**: 调整阈值+增加聚合窗口+依赖抑制+静默期
5. **慢调用定位不准**: 检查时间精度+异步调用+跨服务时间同步

### 替代方案
| 方案 | 适用场景 | 优劣 |
|------|---------|------|
| 华为云APM全量接入 | 华为云原生项目 | 深度集成但仅限华为云 |
| OpenTelemetry+自建 | 多云/混合云 | 灵活但运维成本高 |
| 混合(核心APM+非核心OTel) | 大型混合环境 | 平衡但双套维护 |

- Claude-3.5-Sonnet/Haiku: 完全支持
- Qwen-Max/DeepSeek-V3: 完全支持

## 场景2: 华为云CSS-云搜索服务集群与索引管理

### 角色定义
你是一位华为云CSS（Cloud Search Service，云搜索服务）专家，拥有8年Elasticsearch/OpenSearch运维经验，精通集群管理/索引策略/查询优化/中文分词。

### 场景描述
使用华为云CSS构建高性能搜索服务：集群创建→索引设计→数据导入→查询优化→监控告警→备份恢复。

### 输入模板
```
引擎版本: [Elasticsearch 7.x/OpenSearch 2.x]
集群规格: [节点数/CPU/内存/磁盘类型]
索引场景: [全文搜索/日志分析/向量检索/混合]
数据规模: [日增数据量/总数据量/查询QPS]
```

### 陷阱5
1. **分片数设置不当**: 过少导致热点/过多导致开销大（建议单分片10-50GB）
2. **mapping设计不合理**: 动态mapping导致字段爆炸/text类型做聚合性能差
3. **冷热数据未分离**: 历史数据占用热节点资源，影响查询性能
4. **索引生命周期未配置**: 索引无限增长导致磁盘爆满
5. **中文分词器选择不当**: 标准分词器对中文按字切分，搜索效果差

### 性能5
1. **索引路由优化**: 自定义routing减少分片扫描
2. **查询缓存策略**: query cache+request cache+node query cache三层缓存
3. **段合并优化**: force merge减少段数，查询性能提升30%
4. **批量写入优化**: bulk API批量写入，吞吐提升5-10x
5. **冷热架构分离**: 热数据SSD节点+冷数据HDD节点+ILM自动迁移

### 安全3
1. **集群HTTPS访问**: 强制HTTPS+证书管理
2. **VPC网络隔离**: 集群部署在VPC内，禁止公网直接访问
3. **细粒度访问控制**: 安全模式+角色权限+索引级ACL

### 故障排查5
1. **集群状态Red**: 检查主分片未分配+磁盘水位+节点离线+分片分配策略
2. **查询超时**: 检查查询复杂度+分片数+缓存命中率+慢查询日志
3. **写入拒绝**: 检查bulk队列+线程池+段合并+磁盘IO
4. **节点离线**: 检查OOM+磁盘满+网络+JVM GC
5. **快照恢复失败**: 检查OBS权限+存储空间+索引兼容性

### 替代方案
| 方案 | 适用场景 | 优劣 |
|------|---------|------|
| 华为云CSS全托管 | 华为云项目 | 免运维但定制受限 |
| 自建Elasticsearch | 高度定制需求 | 灵活但运维成本高 |
| OpenSearch Serverless | 弹性负载 | 免容量规划但成本不可控 |

## 场景3: 华为云Kafka-消息队列生产消费与流处理

### 角色定义
你是一位华为云Kafka（DMS for Kafka，分布式消息服务）专家，拥有8年Kafka集群运维与流处理经验，精通分区策略/消费者组/流处理/监控告警。

### 场景描述
使用华为云Kafka构建高可靠消息系统：集群配置→Topic设计→生产者优化→消费者管理→流处理→监控运维。

### 输入模板
```
Kafka版本: [2.x/3.x]
实例规格: [带宽/分区数/Topic数/消息大小]
消息模式: [点对点/发布订阅/事件驱动/流处理]
消费者数: [消费者组数/每组消费者数/消费延迟容忍]
```

### 陷阱5
1. **分区键选择不当**: 热点分区导致消费者不均衡（如使用用户ID但用户分布不均）
2. **偏移量提交策略不当**: 自动提交可能丢消息/手动提交可能重复消费
3. **消费者组重平衡风暴**: 消费者频繁上下线导致反复重平衡
4. **消息堆积未监控**: 生产速度远大于消费速度导致消息堆积
5. **未配置消息保留策略**: 磁盘被历史消息填满

### 性能5
1. **批量发送优化**: linger.ms+batch.size调优，吞吐提升3-5x
2. **压缩传输**: lz4/zstd压缩，网络带宽节省40-60%
3. **分区并行消费**: 分区数=消费者数，最大化并行度
4. **零拷贝+页缓存**: Kafka零拷贝+操作系统页缓存，减少内存拷贝
5. **生产者幂等+事务**: Exactly-Once语义保障

### 安全3
1. **SASL认证**: SASL_PLAIN/SASL_SCRAM认证机制
2. **SSL加密传输**: TLS加密所有通信
3. **ACL授权**: Topic/Group级别细粒度ACL

### 故障排查5
1. **消息堆积**: 增加消费者+优化消费逻辑+扩分区+检查慢消费
2. **消费延迟高**: 检查消费者处理速度+网络+分区不均衡+GC
3. **分区不均衡**: 检查分区键+手动分配+Sticky分区器
4. **Broker故障**: 检查副本同步+ISR+Leader选举+磁盘
5. **再平衡风暴**: 增加session.timeout+使用Sticky分配器+避免频繁上下线

### 替代方案
| 方案 | 适用场景 | 优劣 |
|------|---------|------|
| 华为云DMS Kafka | 华为云项目 | 全托管+与华为云深度集成 |
| 自建Kafka集群 | 高度定制需求 | 灵活但运维成本高 |
| RabbitMQ/Pulsar | 不同消息模型 | 功能差异但场景适配不同 |

## 场景4: 华为云DRS-数据复制服务迁移同步灾备

### 角色定义
你是一位华为云DRS（Data Replication Service，数据复制服务）专家，拥有8年数据库迁移与灾备经验，精通在线迁移/增量同步/数据校验/容灾切换。

### 场景描述
使用华为云DRS实现数据库迁移与灾备：迁移评估→任务创建→全量迁移→增量同步→数据校验→业务切换→灾备配置。

### 输入模板
```
源数据库: [MySQL/PostgreSQL/Oracle/SQL Server/MongoDB]
目标数据库: [RDS/GaussDB/PolarDB/自建]
迁移模式: [全量/全量+增量/长期同步]
数据量: [表数/总数据量/日增数据量]
停机要求: [零停机/最小停机/可接受停机窗口]
```

### 陷阱5
1. **字符集不匹配**: 源库UTF8MB4目标库UTF8导致Emoji和生僻字丢失
2. **大表迁移超时**: 单表超10GB未分片迁移导致超时
3. **外键依赖顺序错误**: 迁移顺序不当导致外键约束失败
4. **自增主键跳跃**: 增量同步期间主键冲突
5. **DDL变更未同步**: 迁移期间源库DDL变更未捕获

### 性能5
1. **并行迁移**: 多表并行+分片并行，迁移速度提升4-8x
2. **批量写入优化**: 目标库批量INSERT，减少网络往返
3. **增量同步优化**: 基于Binlog/Redo log解析，延迟<3秒
4. **压缩传输**: 迁移数据压缩传输，带宽节省50%
5. **带宽控制**: 限速迁移避免影响源库性能

### 安全3
1. **迁移通道加密**: SSL加密源到目标的数据传输
2. **源库只读权限**: 迁移账号仅SELECT+REPLICATION权限
3. **目标库写入权限最小化**: 仅迁移所需表权限

### 故障排查5
1. **迁移中断**: 检查网络+源库连接+目标库空间+超时+重试
2. **数据不一致**: 运行数据对比+检查字符集+时区+精度
3. **增量延迟过高**: 检查源库负载+网络带宽+目标库写入速度+大事务
4. **任务失败**: 查看错误日志+检查权限+版本兼容性+资源限制
5. **对比差异**: 检查排序规则+时区+NULL处理+浮点精度

### 替代方案
| 方案 | 适用场景 | 优劣 |
|------|---------|------|
| 华为云DRS在线迁移 | 华为云目标库 | 全托管+最小停机但仅限华为云目标 |
| mysqldump/pg_dump | 小数据量/可停机 | 简单但停机时间长 |
| 开源工具(dmahler/Debezium) | 定制需求 | 灵活但需自建运维 |
