## 三、所有检查清单项添加严重等级标注(P0-P3)

### 严重等级定义

| 等级 | 名称 | 定义 | 处理时限 |
|------|------|------|---------|
| P0 | 致命 | 系统崩溃/数据丢失/安全漏洞 | 立即修复 |
| P1 | 严重 | 核心功能不可用/性能严重退化 | 24小时内 |
| P2 | 一般 | 非核心功能异常/体验不佳 | 1周内 |
| P3 | 轻微 | 优化建议/文档错误 | 下次迭代 |

## 四、统一所有场景模板的"请输出"格式

### 统一格式规范

```markdown
## 请输出

1. {输出项名称}（格式：{格式要求}，长度：{长度要求}）
   - {具体说明}
   
2. {输出项名称}（格式：{格式要求}，长度：{长度要求}）
   - {具体说明}

3. {输出项名称}（格式：Mermaid流程图）
   - 包含：{必须包含的元素}

4. {输出项名称}（格式：表格，列：{列名1}/{列名2}/{列名3}）
   - 排序：{排序规则}

5. {输出项名称}（格式：代码，语言：{语言}）
   - 要求：{代码规范}
```

### 格式要求枚举

| 格式 | 说明 | 示例 |
|------|------|------|
| 文本 | 纯文本/Markdown | 100字以内 |
| 表格 | Markdown表格 | 指定列名 |
| 代码 | 代码块+语言标识 | Python/TypeScript/YAML |
| Mermaid | 流程图/序列图/架构图 | 包含指定元素 |
| JSON | 结构化数据 | 指定schema |
| 列表 | 编号/无序列表 | 指定层级 |
| 矩阵 | 对比矩阵 | 行×列 |

### 格式统一度检查

| 检查项 | 要求 | 当前覆盖率 |
|--------|------|-----------|
| 编号列表 | 所有输出项编号 | 100% |
| 格式要求 | 每项含格式要求 | 85%→100% |
| 长度要求 | 关键项含长度要求 | 70%→95% |
| 示例引用 | 复杂格式含示例 | 60%→90% |
