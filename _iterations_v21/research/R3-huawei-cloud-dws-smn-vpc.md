## 一、华为云DWS（数据仓库服务）

### 1. 服务概览

| 特性 | 详情 |
|------|------|
| 全称 | 数据仓库服务 GaussDB(DWS) |
| 类型 | MPP分布式数据仓库 |
| 兼容 | PostgreSQL生态 |
| 架构 | Shared-Nothing + 列存储 + 向量化执行引擎 |
| 适用 | OLAP分析/数据湖/实时数仓/联邦查询 |

### 2. 核心能力
- **列存储+压缩**：自动列存+高效压缩比（10:1）
- **向量化执行**：批量处理提升查询性能
- **MPP并行**：水平扩展，线性提升算力
- **联邦查询**：OBS/MRS/Hive/MySQL/GaussDB跨源查询
- **实时入库**：GDS导入/INSERT/流式入库
- **快照备份**：自动快照+手动快照+跨区域复制
- **弹性扩缩**：按需增删节点，秒级生效
- **逻辑集群**：资源隔离，多业务共享集群

### 3. 典型场景
- **数据仓库建设**：ETL→ODS→DWD→DWS→ADS分层建模
- **实时分析**：流式入库+物化视图+增量刷新
- **联邦查询**：数据湖分析（OBS外表+MRS外表）
- **数据迁移**：Oracle/Teradata/MySQL→DWS迁移工具
- **调优**：执行计划分析+统计信息+分区+索引+资源池

### 4. DWS提示词场景设计
1. **DWS开发场景**：建表+分区+索引+物化视图+存储过程
2. **DWS调优场景**：慢SQL分析+执行计划+统计信息+资源池+WLM
3. **DWS迁移场景**：Oracle/Teradata→DWS迁移+兼容性+数据校验

## 二、华为云SMN（消息通知服务）

### 1. 服务概览

| 特性 | 详情 |
|------|------|
| 全称 | Simple Message Notification |
| 类型 | 发布/订阅消息通知服务 |
| 协议 | HTTP/HTTPS/Email/SMS/FunctionGraph/DMS |
| 模型 | Topic→Subscription→Publish |
| 可靠性 | At-Least-Once投递 |

### 2. 核心能力
- **Topic管理**：创建/删除/查询/更新主题
- **Subscription管理**：添加/删除/列表订阅终端
- **消息发布**：文本/JSON/模板消息
- **消息模板**：参数化模板+变量替换
- **HTTP/HTTPS推送**：Webhook回调+重试策略
- **短信通知**：模板短信+签名管理
- **邮件通知**：HTML/纯文本+附件
- **FunctionGraph触发**：消息驱动函数执行
- **DMS Kafka**：消息转Kafka队列

### 3. 典型场景
- **告警通知**：CES告警→SMN→短信/邮件/Webhook
- **事件驱动**：OBS事件→SMN→FunctionGraph处理
- **业务通知**：订单状态→SMN→多渠道推送
- **数据同步**：变更事件→SMN→下游消费

### 4. SMN提示词场景设计
1. **SMN集成场景**：Topic创建+订阅管理+消息发布+模板配置
2. **SMN告警场景**：CES告警→SMN→多渠道通知+升级策略

## 三、华为云VPC（虚拟私有云）

### 1. 服务概览

| 特性 | 详情 |
|------|------|
| 全称 | Virtual Private Cloud |
| 类型 | 隔离的私有网络环境 |
| 组件 | 子网/安全组/NAT/EIP/ELB/VPN/对等连接 |
| CIDR | 支持RFC1918地址段 |
| 区域 | 区域级+可用区级资源 |

### 2. 核心能力
- **VPC网络**：自定义网段+子网划分+可用区分布
- **安全组**：5元组规则（协议/端口/源/目的/动作）+有状态
- **网络ACL**：无状态子网级访问控制
- **NAT网关**：SNAT（出公网）+DNAT（入公网端口映射）
- **EIP**：弹性公网IP+带宽+共享带宽
- **ELB**：4层/7层负载均衡+健康检查+会话保持
- **VPN**：IPsec VPN+SSL VPN→本地数据中心互联
- **对等连接**：VPC间通信+跨区域/跨账号
- **企业路由器ER**：复杂网络拓扑+路由表+传播
- **流量镜像**：镜像VPC流量→安全分析

### 3. 典型场景
- **Web应用**：ELB+ECS+RDS+安全组三层架构
- **混合云**：VPN+ER→本地IDC+云上VPC互联
- **微服务**：CCE+ELB+NAT+安全组网络隔离
- **多租户**：多VPC+对等连接+共享服务VPC

### 4. VPC提示词场景设计
1. **VPC网络配置场景**：VPC+子网+安全组+NAT+ELB架构设计
2. **VPC安全场景**：安全组规则+网络ACL+流量镜像+安全审计

## 五、关键发现

1. DWS基于PostgreSQL生态，兼容性好，迁移工具链完善
2. SMN是华为云事件驱动架构的核心，连接CES/OBS/FunctionGraph
3. VPC安全组是网络隔离核心，需精确配置5元组规则
4. FunctionGraph冷启动优化是Serverless关键挑战
5. 华为云三服务可组成完整的事件驱动+数据仓库+网络隔离方案
