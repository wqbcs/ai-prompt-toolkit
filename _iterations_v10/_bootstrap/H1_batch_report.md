## 1. 自举协议定义

### 1.1 自举层次模型

| 层级 | 名称 | 描述 | 实现方式 |
|------|------|------|----------|
| L0 | 外部构建 | 用外部规则创建提示词 | v9方法论驱动 |
| L1 | 自审查 | 提示词审查提示词自身 | 04审查04, 08审计08 |
| L2 | 自改进 | 提示词改进提示词自身 | Meta-Prompt+安全边界 |
| L3 | 自验证 | 提示词验证提示词正确性 | 形式化自证明+双轨验证 |
| L4 | 自生成 | 提示词生成提示词 | DNA遗传+模板合成 |

### 1.2 自审查协议(Bootstrap Audit Protocol)

```
输入：提示词P, 审查提示词P_audit
流程：
  1. P_audit以P为输入执行审查
  2. 生成审查报告R_self
  3. 外部人工审查P生成R_external
  4. 一致性验证：|score(R_self) - score(R_external)| ≤ δ
  5. 若一致则P通过自审查，否则标记需改进
输出：自审查结果 + 一致性分数
```

### 1.3 自引用完整性验证

- **内部一致性**：P审查P自身 → 结果与外部审查一致(差异≤5%)
- **交叉一致性**：P_a审查P_b ≈ P_b审查P_a(交换律近似，差异≤8%)
- **传递一致性**：P_a审查P_b ∧ P_b审查P_c → P_a审查P_c(传递律近似)
- **不动点验证**：自改进收敛后，P ≈ Improve(P)(差异<ε)

## 3. 双轨验证机制

### 3.1 验证流程

```
自举结果 → 内部自审查(提示词审查自身) → 外部验证(人工+基准+独立评估) → 一致性判定
    ↓              ↓                          ↓                    ↓
  生成中        评分R_self                评分R_external        |R_self-R_external|≤δ?
```

### 3.2 外部锚点(3个)

1. **人工审查锚点**：专家评审组独立评分
2. **基准测试锚点**：标准测试集自动评分
3. **独立评估锚点**：LLM-as-Judge独立评估

### 3.3 一致性阈值

| 一致性级别 | 阈值 | 判定 | 处理 |
|-----------|------|------|------|
| 完全一致 | ≤1% | ✓✓ | 直接通过 |
| 基本一致 | ≤5% | ✓ | 通过+记录 |
| 轻度偏差 | ≤10% | △ | 需复核 |
| 显著偏差 | >10% | ✗ | 拒绝+调查 |

