# 贡献者协议与行为准则

> 版本：v14.0.0 | 日期：2026-05-29

---

## 1. 贡献者许可协议(CLA)

### 1.1 CLA类型
本项目采用**Apache CLA 2.0**（与Apache软件基金会标准CLA一致）。

### 1.2 CLA核心条款
1. **贡献授权**：贡献者授予项目永久、全球、非独占、免费、可再许可的许可
2. **专利授权**：贡献者授予专利许可，涵盖其贡献中可被专利覆盖的部分
3. **原创声明**：贡献者声明贡献为原创或已获授权
4. **通知义务**：贡献者同意通知项目任何其知的专利侵权
5. **签名要求**：每次PR需签署CLA（首次签署后自动记住）

### 1.3 CLA签署流程
```
1. 贡献者提交PR
2. CLA-Assistant自动检查签署状态
3. 未签署→自动评论+签署链接
4. 贡献者点击链接→GitHub OAuth→签署
5. CLA-Assistant验证→PR检查通过
```

### 1.4 企业CLA
- 企业贡献者由企业签署**Corporate CLA**
- 企业CLA指定授权代表
- 覆盖企业所有员工贡献

## 2. 行为准则(Code of Conduct)

### 2.1 采用标准
本项目采用**Contributor Covenant v2.1**（国际最广泛采用的开源行为准则）。

### 2.2 核心承诺
为营造开放和友好的环境，我们作为贡献者和维护者承诺：无论年龄、体型、残疾、种族、性别认同和表达、经验水平、教育程度、社会经济地位、国籍、外貌、种族、宗教或性取向，都将在我们的项目和社区中提供无骚扰的体验。

### 2.3 行为标准
**积极行为**：
- 使用友好和包容的语言
- 尊重不同观点和经验
- 优雅地接受建设性批评
- 关注对社区最有利的事
- 对其他社区成员展现同理心

**不可接受行为**：
- 使用性化语言或图像，以及不受欢迎的性关注或性骚扰
- 捣乱、侮辱/贬损评论和人身或政治攻击
- 公开或私下骚扰
- 未经明确许可，发布他人的私人信息（如物理或电子地址）
- 在专业环境中可能被合理认为不适当的其他行为

### 2.4 执行责任
- **行为准则委员会**：3名维护者组成
- **报告渠道**：conduct@prompt-engine.dev（私密）
- **响应时间**：48小时内确认，1周内调查
- **制裁等级**：警告→临时禁止→永久禁止

## 3. 项目治理

### 3.1 角色与职责
| 角色 | 人数 | 职责 | 选举方式 |
|------|------|------|---------|
| BDFL | 1 | 最终决策+愿景 | 创始人 |
| 核心维护者 | 3-5 | 技术决策+发布审批 | 贡献度+社区投票 |
| 维护者 | 5-10 | PR审批+Issue管理 | 核心维护者任命 |
| 贡献者 | 不限 | 代码+文档+测试 | 自动(PR合并) |
| 社区成员 | 不限 | 讨论+反馈+推广 | 自动 |

### 3.2 决策流程
```
技术决策(RFC流程):
1. 提议者提交RFC(Request for Comments)
2. 社区讨论期(2周)
3. 核心维护者评审
4. 投票(Lazy Consensus: 72h无反对=通过)
5. 实施与验证

重大决策(BDFL保留权):
- 版本发布
- 许可证变更
- 行为准则执行
- 架构重大变更
```

### 3.3 贡献流程
```
1. Fork → 创建特性分支
2. 开发+测试(lint+type-check+unit+integration)
3. 提交PR(模板+CLA签署+DCO签名)
4. CI自动检查(构建+测试+安全扫描+评估)
5. 2名维护者Review(Lgtm)
6. 合并→自动发布(semantic-release)
```
