## 1. 法律AI Prompt Engineering

### 1.1 核心挑战
- **术语精确性**：法律术语不可模糊，一字之差可能改变法律效力
- **合规红线**：不可生成法律建议替代律师，需明确免责声明
- **版本追溯**：法律法规版本更替，必须引用特定版本
- **不确定性表达**：法律结论常为"可能"/"倾向于"而非"确定"

### 1.2 最佳实践
| 实践 | 描述 | 实现方式 |
|------|------|---------|
| 术语锁定 | 法律术语严格引用法条原文 | `TERM_LOCK[条文号]: 术语=原文` |
| 免责声明 | 每次输出前强制附加 | `MANDATORY: 本输出不构成法律意见` |
| 版本标注 | 引用法条时标注生效版本 | `LAW_REF[法条名 v2026.03修订]` |
| 不确定性标记 | 结论标注置信度 | `CONFIDENCE: 高/中/低` |
| 批判性分析 | 必须提供正反双方论点 | `REQUIRE: 正方论点+反方论点+裁判倾向` |

### 1.3 5大场景
1. **合同审查**：条款风险识别+修改建议+合规性检查
2. **法条检索**：语义检索+关联法条+适用性分析
3. **案件分析**：事实梳理+法律适用+裁判预测
4. **合规报告**：合规差距+整改建议+时间线
5. **法律文书起草**：格式规范+条款模板+风险提示

### 1.4 合规清单(15项)
1. 输出不构成法律意见声明

5. 利益冲突检查
6. 时效性提醒
7. 管辖权确认

## 2. 医疗AI Prompt Engineering

### 2.1 核心挑战
- **安全红线**：AI不可替代医生诊断，需明确免责
- **循证要求**：所有建议必须有文献/指南支持
- **隐私合规**：HIPAA/个人信息保护法
- **不确定性**：医学结论需标注证据等级

### 2.2 最佳实践
| 实践 | 描述 | 实现方式 |
|------|------|---------|
| 证据等级标注 | A/B/C/D级证据 | `EVIDENCE_LEVEL: A(随机对照)/B(队列)/C(病例)/D(专家意见)` |
| 诊断免责 | 不替代医生诊断 | `MANDATORY: 本输出仅供医学参考，不替代专业诊断` |
| 药物交互检查 | 多药并用时检查交互 | `REQUIRE: drug_interaction_check(med_list)` |
| 指南引用 | 引用最新临床指南 | `GUIDELINE_REF[指南名 v版本号]` |
| 患者安全 | 高风险操作警示 | `ALERT: 高风险操作，需二次确认` |

### 2.3 5大场景
1. **症状分诊**：症状采集+可能性排序+就诊建议
2. **病历摘要**：结构化摘要+关键指标+趋势分析
3. **药物审查**：交互检查+剂量验证+禁忌排查
4. **指南查询**：指南检索+适用性判断+建议生成
5. **影像辅助**：影像描述+异常标注+鉴别诊断

6. 儿童用药警示

## 3. 教育AI Prompt Engineering

### 3.1 核心挑战
- **认知适配**：不同年龄段/水平需不同表达方式
- **价值观引导**：教育内容需符合社会主流价值观
- **隐私保护**：未成年人数据保护(COPPA/个人信息保护法)
- **评估公平**：避免算法偏见影响评分

### 3.2 最佳实践
| 实践 | 描述 | 实现方式 |
|------|------|---------|
| 认知分级 | 按年级/水平适配内容 | `COGNITIVE_LEVEL: K12/本科/研究生/职业` |
| 价值观审查 | 内容通过价值观检查 | `VALUE_CHECK: 符合社会主义核心价值观` |
| 防抄袭 | 不直接给答案，引导思考 | `STRATEGY: 苏格拉底式提问法` |
| 多模态教学 | 文字+图+音+视频 | `MODALITY: text+image+audio+video` |
| 进度追踪 | 学习路径+掌握度 | `PROGRESS: 路径图+掌握度%+下一步` |

### 3.3 5大场景
1. **课程设计**：教学大纲+课时安排+评估方案
2. **智能答疑**：苏格拉底式引导+错误诊断+知识链接
3. **作业批改**：结构化评语+错误分类+改进建议
4. **学习路径**：知识图谱+薄弱点+个性化推荐
5. **教学评估**：学习效果+教学反思+改进方案

### 3.4 合规清单(12项)
1. 未成年人数据保护
2. 内容适龄标注
3. 价值观合规审查
4. 防作弊机制
5. 评分公平性
6. 无障碍访问
7. 数据最小化采集
8. 家长知情同意
9. 学习数据安全
10. 算理员审计
11. 教育公平

## 4. 科研AI Prompt Engineering

### 4.1 核心挑战
- **学术严谨性**：引用必须真实，不可幻觉引用
- **可复现性**：实验方法必须足够详细可复现
- **数据完整性**：数据处理透明，不可选择性报告
- **伦理合规**：涉及人类/动物需IRB审批

### 4.2 最佳实践
| 实践 | 描述 | 实现方式 |
|------|------|---------|
| 引用验证 | 所有引用必须可验证 | `CITATION_CHECK: 每条引用需有DOI/URL` |
| 方法详述 | 实验方法可复现 | `METHOD_DETAIL: 参数+环境+步骤+代码` |
| 数据透明 | 数据处理全链透明 | `DATA_PIPELINE: 原始→清洗→分析→结果` |
| 伦理标注 | 人类/动物研究标注 | `ETHICS: IRB审批号/豁免类型` |
| 局限声明 | 必须声明研究局限 | `REQUIRE: limitations_section` |

### 4.3 5大场景
1. **文献综述**：系统检索+分类+趋势+空白识别
2. **实验设计**：假设→变量→方法→统计→功效分析
3. **数据分析**：方法选择+假设检验+效应量+可视化
4. **论文写作**：结构化写作+引用管理+格式合规
5. **同行评审**：方法论评审+结果验证+改进建议

### 4.4 合规清单(10项)
1. 引用真实性验证
2. 数据可复现性
3. 利益冲突声明
4. 伦理审批标注
5. 数据可用性声明
6. 作者贡献声明
7. 开源许可合规
8. 预注册报告
9. 选择性报告防范
10. 跨学科可理解性

| 模式 | 法律 | 医疗 | 教育 | 科研 |
