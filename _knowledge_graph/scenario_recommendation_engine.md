## 一、推荐算法

### 1.1 多因子推荐模型

```
Score(scenario) = 
  w1 * workflow_proximity(current, scenario) +    # 工作流邻近度(0-1)
  w2 * dependency_strength(current, scenario) +    # 依赖强度(0-1)
  w3 * task_similarity(task_context, scenario) +   # 任务相似度(0-1)
  w4 * industry_relevance(industry, scenario) +    # 行业相关性(0-1)
  w5 * historical_frequency(current, scenario)     # 历史频率(0-1)

权重: w1=0.35, w2=0.25, w3=0.20, w4=0.10, w5=0.10
```
