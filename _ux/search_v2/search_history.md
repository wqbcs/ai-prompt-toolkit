# 搜索历史管理

> **版本**: v1.0.0 | **日期**: 2026-07-12

---

## 一、搜索历史存储

### 1.1 存储方式
- 使用 `localStorage` 存储
- 最大存储条数: 20条
- 存储键: `ai-prompt-search-history`
- 过期时间: 30天

### 1.2 数据结构

```json
{
  "version": "1.0",
  "entries": [
    {
      "id": "sh-001",
      "query": "分布式链路追踪断链排查",
      "timestamp": "2026-07-12T10:30:00+08:00",
      "result_count": 3,
      "filters": {
        "category": "observability",
        "applicable_models": ["gpt-4o"]
      }
    }
  ]
}
```

### 1.3 管理操作

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 查看历史 | 点击搜索框 | 显示最近20条搜索 |
| 复用搜索 | 点击历史条目 | 使用历史查询重新搜索 |
| 删除单条 | 悬停→删除按钮 | 删除指定搜索历史 |
| 清空全部 | 清空按钮 | 清空所有搜索历史 |

## 二、搜索建议

### 2.1 建议来源

| 来源 | 优先级 | 说明 |
|------|--------|------|
| 搜索历史 | 高 | 最近搜索过的相关内容 |
| 热门搜索 | 中 | 全站搜索频次最高的查询 |
| 标签推荐 | 低 | 基于当前输入匹配的标签 |

```
搜索框输入 "链路" →

  └─────────────────────────────────────┘
```
