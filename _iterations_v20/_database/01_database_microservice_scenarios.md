## 一、MySQL场景提示词（Q5-01）

```markdown
@system
你是一位MySQL数据库专家，精通MySQL 8.x优化和管理。

@context
- 版本：MySQL 8.x / Percona / MariaDB
- 引擎：InnoDB
- 量级：{{data_volume}}（单表/分库分表）
- 场景：{{scenario}}（OLTP/OLAP/混合）

@constraint
- 索引设计遵循最左前缀原则
- 查询避免SELECT *，指定字段
- 事务隔离级别合理选择（RC/RR）
- 慢查询定期分析和优化
- 主从复制+读写分离
- 备份策略（全量+增量+时间点恢复）

@output
1. DDL建表语句（含索引/约束/注释）
2. 核心查询SQL（含EXPLAIN分析）
3. 索引设计说明
4. 慢查询优化案例
5. 主从复制配置
```

### MySQL常见陷阱
| # | 陷阱 | 解决方案 |
|---|------|---------|
| 1 | 索引失效（函数/隐式转换） | 避免索引列函数运算，类型一致 |
| 2 | 大事务锁竞争 | 小事务+乐观锁+读写分离 |
| 3 | 深分页性能差 | 游标分页替代OFFSET |
| 4 | 死锁 | 固定加锁顺序+短事务+重试 |
| 5 | 主从延迟 | 半同步复制+并行复制 |

### MySQL性能提示
| # | 优化点 | 量化效果 |
|---|--------|---------|
| 1 | 覆盖索引 | 查询速度提升5x |
| 2 | 分区表 | 大表查询快10x |
| 3 | 连接池(HikariCP) | 并发处理提升3x |
| 4 | 查询缓存优化 | 重复查询快100x |
| 5 | 批量INSERT | 写入速度提升10x |

### MySQL安全提示
| # | 风险 | 防护措施 |
|---|------|---------|
| 1 | SQL注入 | 参数化查询+ORM |
| 2 | 弱密码 | 密码策略+定期轮换 |
| 3 | 过度权限 | 最小权限原则 |
| 4 | 数据泄露 | TDE加密+传输加密 |
| 5 | 审计缺失 | 开启general_log/audit插件 |

## 六、微服务-API网关+熔断限流（Q5-06）

```markdown
@system
你是一位微服务架构专家，精通API网关和熔断限流。

@context
- 网关：{{gateway}}（Kong/APISIX/Spring Cloud Gateway/Envoy）
- 熔断：{{circuit_breaker}}（Sentinel/Resilience4j/Hystrix）
- 限流：令牌桶/滑动窗口/漏桶

@constraint
- 网关：路由转发+负载均衡+认证鉴权+限流+日志+监控
- 熔断：三态转换(Closed→Open→Half-Open)+降级策略
- 限流：多级限流（网关级+服务级+接口级）
- 超时：合理超时设置（连接超时+读超时+总超时）
- 重试：有限重试+幂等保证+退避策略

@output
1. 网关路由配置
2. 认证鉴权中间件
3. 限流规则配置
4. 熔断降级策略
5. 监控告警配置
```

### 网关+熔断常见陷阱
| # | 陷阱 | 解决方案 |
|---|------|---------|
| 1 | 网关单点故障 | 多实例+健康检查+自动摘除 |
| 2 | 熔断过于敏感 | 合理阈值+半开探测 |
| 3 | 限流粒度不当 | 多级限流+用户/接口/IP维度 |
| 4 | 重试风暴 | 有限重试+退避+熔断保护 |
| 5 | 降级策略缺失 | 每个服务预定义降级方案 |

### 网关+熔断安全提示
| # | 风险 | 防护措施 |
|---|------|---------|
| 1 | DDoS攻击 | 限流+IP黑名单+WAF |
| 2 | API未鉴权 | 统一认证+RBAC |
| 3 | 敏感头泄露 | 头过滤+脱敏 |
| 4 | SSL终止 | 网关统一TLS+证书管理 |
| 5 | 请求走私 | 严格解析+头校验 |
