## 场景匹配算法

### 三维评分

```typescript
interface ScenarioMatcher {
  calculateRelevance(context: ProjectContext, scenario: Scenario): number
  calculateApplicability(context: ProjectContext, scenario: Scenario): number
  calculateFreshness(context: ProjectContext, scenario: Scenario): number
  calculateFinalScore(scores: ThreeDScores): number
}

interface ThreeDScores {
  relevance: number
  applicability: number
  freshness: number
}
```

| 维度 | 权重 | 计算方法 |
|------|------|---------|
| 相关性 | 0.40 | 语言/框架/领域匹配度 |
| 适用性 | 0.35 | 任务类型匹配+约束兼容度 |
| 新鲜度 | 0.25 | 未使用场景优先+最新更新 |

### 匹配流程

```
输入项目上下文
    │
    ├── Step 1: 语言过滤 → 缩小到匹配语言的场景
    ├── Step 2: 任务匹配 → 按任务类型排序
    ├── Step 3: 约束检查 → 过滤不兼容场景
    ├── Step 4: 三维评分 → relevance+applicability+freshness
    └── Step 5: Top-N推荐 → 返回前5个推荐
```
