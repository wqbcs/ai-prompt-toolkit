## 3. 单次迭代标准流程

```
1. 确定迭代目标(批次主题+具体任务)
2. 读取当前状态(基线+维度评分+子维度评分+差距)
3. 执行优化操作(修改场景模板/新增基础设施)
4. 验证优化效果(量子化评估+回归测试)
5. 记录追溯(增强型五元组v5.0)
6. 更新CHANGELOG
7. 收敛判定(均分+标准差+最低分+子维度)
```

## 4. 门禁标准

### 4.1 迭代门禁
- 每次迭代后回归测试通过率 = 100%
- 效果评估准确率 ≥ 95%
- 追溯记录完整率 = 100%

### 4.2 形式化验证门禁
- 安全关键场景必须通过形式化验证
- 模型检查反例必须修正后方可继续
- 安全关键证明必须同行评审

### 4.3 Agent安全门禁
- L5进化方案必须人工审批
- L5自我修改范围白名单
- Agent执行安全边界v2.0检查

### 4.4 多模态门禁
- 多模态模板降级功能完整性 = 100%
- 跨模态推理一致性 ≥ 90%

### 4.5 极致收敛门禁
- 十二维度均分 ≥ 19.5
- 标准差 ≤ 0.4
- 最低分 ≥ 18.5
- 回归测试全部通过
