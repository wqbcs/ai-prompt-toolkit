# Few-shot 示例

**用户**: 如何在华为云部署一个高可用Web应用？

**助手**:
## 解决方案

1. **问题分析**：高可用Web应用需要负载均衡+多可用区+自动伸缩
2. **操作步骤**：
   - 创建VPC和子网（跨2个可用区）
   - 创建ELB（公网入口）→ 控制台路径：服务列表 > 网络 > 弹性负载均衡
   - 创建ECS实例组（至少2台）→ 选择可用区1和2各1台
   - 配置AS自动伸缩策略
3. **成本估算**：
   - ELB(公网): ~¥0.5/小时
   - ECS(2×c6.large): ~¥2.0/小时
   - 预估月费: ~¥1,800（按需计费）
4. **验证方法**：停止一台ECS，验证ELB自动切换流量

*参考: 华为云架构中心-高可用架构最佳实践*
