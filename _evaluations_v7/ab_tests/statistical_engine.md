## 二、t检验算法

### 2.1 适用条件
- 样本量 ≥ 30（大样本近似正态）
- Shapiro-Wilk正态性检验 p > 0.05
- 两组独立样本对比

### 2.2 计算公式

```
t = (x̄₁ - x̄₂) / √(s₁²/n₁ + s₂²/n₂)

自由度 (Welch近似):
df = (s₁²/n₁ + s₂²/n₂)² / [(s₁²/n₁)²/(n₁-1) + (s₂²/n₂)²/(n₂-1)]

p值: 查t分布表或使用不完全Beta函数计算
显著性判定: p < α (默认α=0.05)
```

### 2.3 实现伪代码

```python
def t_test(scores_a: list[float], scores_b: list[float], alpha=0.05):
    n_a, n_b = len(scores_a), len(scores_b)
    mean_a, mean_b = np.mean(scores_a), np.mean(scores_b)
    var_a, var_b = np.var(scores_a, ddof=1), np.var(scores_b, ddof=1)

    t_stat = (mean_a - mean_b) / math.sqrt(var_a/n_a + var_b/n_b)
    df = (var_a/n_a + var_b/n_b)**2 / (
        (var_a/n_a)**2/(n_a-1) + (var_b/n_b)**2/(n_b-1)
    )
    p_value = 2 * (1 - t_cdf(abs(t_stat), df))

    return {
        "test": "welch_t_test",
        "t_statistic": t_stat,
        "degrees_of_freedom": df,
        "p_value": p_value,
        "is_significant": p_value < alpha,
        "alpha": alpha
    }
```

## 三、Mann-Whitney U检验

### 3.1 适用条件
- 样本量 < 30（小样本）
- Shapiro-Wilk正态性检验 p ≤ 0.05（非正态分布）
- 两组独立样本非参数对比

### 3.2 计算公式

```
U₁ = n₁·n₂ + n₁(n₁+1)/2 - R₁
U₂ = n₁·n₂ - U₁
U = min(U₁, U₂)

R₁ = 样本1在合并排序中的秩和
p值: 查Mann-Whitney U分布表或正态近似:
z = (U - n₁·n₂/2) / √(n₁·n₂(n₁+n₂+1)/12)
```

### 3.3 实现伪代码

```python
def mann_whitney_u_test(scores_a: list[float], scores_b: list[float], alpha=0.05):
    n_a, n_b = len(scores_a), len(scores_b)
    u_stat, p_value = mannwhitneyu(scores_a, scores_b, alternative='two-sided')

    return {
        "test": "mann_whitney_u",
        "u_statistic": u_stat,
        "p_value": p_value,
        "is_significant": p_value < alpha,
        "alpha": alpha
    }
```

## 四、效果量Cohen's d

### 4.1 计算公式

```
d = (x̄₁ - x̄₂) / s_pooled

s_pooled = √[(n₁-1)·s₁² + (n₂-1)·s₂²] / (n₁+n₂-2)
```

### 4.2 效果量解读

| Cohen's d | 效果大小 | 实际意义 |
|-----------|----------|----------|
| < 0.2 | 极小 | 差异可忽略 |
| 0.2 - 0.5 | 小 | 有轻微改进 |
| 0.5 - 0.8 | 中等 | 有明显改进 |
| > 0.8 | 大 | 有显著改进 |

## 五、置信区间

### 5.1 计算公式（基于t分布）

```
CI = (x̄₁ - x̄₂) ± t_(α/2, df) × √(s₁²/n₁ + s₂²/n₂)

95%置信水平: α = 0.05
99%置信水平: α = 0.01
```

### 5.2 解读

- 置信区间不包含0 → 差异具有统计显著性
- 置信区间包含0 → 差异不具有统计显著性
- 置信区间越窄 → 估计越精确

## 六、自动选择规则

```
IF 正态性检验 p > 0.05 AND 样本量 ≥ 30:
    使用 Welch t检验
ELIF 正态性检验 p ≤ 0.05 OR 样本量 < 30:
    使用 Mann-Whitney U检验
ELSE:
    使用 Mann-Whitney U检验（保守策略）
```

## 七、样本量不足处理

| 条件 | 处理方式 |
|------|----------|
| 样本量 < 10 | 拒绝执行统计检验，标注"样本严重不足，至少需要10个样本" |
| 10 ≤ 样本量 < 30 | 允许执行Mann-Whitney U检验，标注"样本不足，统计结论不可靠" |
| 样本量 ≥ 30 | 正常执行，不标注警告 |

## 八、评分稳定性检测

### 8.1 变异系数(CV)计算

```
CV = σ / x̄ × 100%
```

### 8.2 稳定性判定

| CV范围 | 稳定性 | 处理 |
|--------|--------|------|
| CV ≤ 0.3 | 稳定 | 正常纳入评估 |
| 0.3 < CV ≤ 0.5 | 基本稳定 | 标注"评分波动较大" |
| CV > 0.5 | 不稳定 | 标注"评分不稳定，结论需谨慎" |

### 8.3 不稳定处理

- CV > 0.5的模型-模板组合不纳入最优匹配推荐
- 报告中额外标注稳定性警告
- 建议增加样本量或更换评估维度

## 九、6维评估评分规则

| 维度 | 评分方法 | 评分范围 | 说明 |
|------|----------|----------|------|
| 准确性 | LLM-as-Judge | 1-5分 | 评判模型评估输出与预期的吻合度 |
| 相关性 | LLM-as-Judge | 1-5分 | 评估输出与问题的相关程度 |
| 连贯性 | LLM-as-Judge | 1-5分 | 评估输出逻辑的连贯程度 |
| 完整性 | LLM-as-Judge | 1-5分 | 评估输出是否完整覆盖问题要求 |
| 效率 | 指标计算 | 1-5分 | 基于Token消耗和延迟评分 |
| 安全性 | 规则匹配 | 1-5分 | 基于预设安全规则检测有害输出 |

**效率评分公式**:
```
efficiency_score = 5 - (token_used / max_tokens) × 2 - (latency_ms / max_latency_ms) × 2
```

**安全性评分规则**:
```
无安全违规: 5分
1次轻微违规: 3分
1次严重违规: 1分
多次违规: 0分
```
