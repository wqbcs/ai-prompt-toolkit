## 3. 知识域详细定义

### K1: 提示词需求

1. **需求获取**：从业务目标推导提示词需求，意图澄清技术
2. **意图建模**：形式化用户意图(任务意图/约束意图/风格意图)
3. **约束识别**：安全约束+合规约束+性能约束+质量约束
4. **验收标准**：可度量的输出质量标准+行为合规标准
5. **需求追溯**：需求→设计→实现→测试的双向追溯

### K2: 提示词设计

1. **结构设计**：指令+上下文+示例+约束+输出格式的5层结构
2. **原则应用**：28条设计原则的选择与应用策略
3. **模式选择**：零样本/少样本/思维链/自一致/元提示/React等模式
4. **反模式规避**：28种反模式的识别、预防与修复
5. **工作流设计**：单步/多步/条件分支/并行/循环工作流
6. **安全设计**：注入防御+边界约束+输出验证的安全设计模式

### K3: 提示词构造

1. **编码规范**：提示词编码风格+命名约定+注释规范
2. **模板实例化**：参数化模板+变量绑定+条件片段
3. **示例设计**：正例+反例+边界例的设计原则
4. **格式规范**：JSON/YAML/Markdown输出格式规范
5. **压缩构造**：L0-L3四级压缩的语义保持构造

### K4: 提示词测试

1. **单元测试**：单个提示词的功能正确性测试
2. **集成测试**：多提示词协作的端到端测试
3. **回归测试**：变更后的行为一致性测试
4. **对抗测试**：注入攻击+边界输入+异常场景测试
5. **应力测试**：模型切换+并发+版本冲突的应力测试

### K5: 提示词运维

1. **部署管理**：版本化部署+灰度发布+回滚策略
2. **运行监控**：质量监控+延迟监控+成本监控+异常告警
3. **故障诊断**：日志分析+根因定位+修复验证
4. **持续优化**：反馈闭环+A/B测试+自动调优
5. **版本管理**：语义化版本+废弃策略+兼容性管理

### K6: 提示词质量

1. **质量模型**：22维度×4子维度的质量模型
2. **评估框架**：人工+LLM-as-Judge+自动化+元评估
3. **度量指标**：精确度/召回率/一致性/鲁棒性/效率
4. **持续改进**：门禁+闭环+守护+收敛的改进机制

### K7: 模型适配

1. **多模型适配**：7大模型(GPT/Claude/Gemini/Qwen/DeepSeek/Ernie/Kimi)适配
2. **能力抽象**：10项能力抽象接口(推理/工具/结构化/多语言/长上下文等)
3. **弹性指令**：4级弹性(强制/推荐/建议/可选)
4. **迁移策略**：模型切换迁移指南+预适配策略

### K8: 行业适配

1. **行业术语**：10行业术语表(金融/医疗/电商/SaaS/游戏/汽车/能源/制造/政府/媒体)
2. **合规覆盖**：每行业3类合规文件(检查清单+术语表+合规要求)
3. **场景特化**：55场景的行业特化版本
4. **领域迁移**：跨域共性7模式+通用模板框架

### K9: 跨域迁移

1. **共性模式**：7个跨域共性模式(术语锁定/合规清单/安全红线/不确定表达/多模式输出/批判性思维/版本追溯)
2. **术语锁定**：领域术语不可替代性验证
3. **安全红线**：领域安全不可违反约束
4. **不确定表达**：概率性结论的标准表达规范

### K10: 提示词工程管理

1. **项目管理**：提示词项目的WBS+进度+风险+质量四维管理
2. **团队协作**：角色定义+工作流+评审机制+知识共享
3. **成本控制**：Token成本+API成本+人力成本的预算与优化
4. **风险管理**：技术风险+合规风险+安全风险的识别与应对

### K11: 提示词工程过程

1. **开发过程**：需求→设计→构造→测试→部署的标准过程
2. **迭代流程**：64次迭代×10轮的螺旋式迭代方法论
3. **门禁体系**：17项门禁的自动执行与阻断
4. **变更管理**：满分守护+自动回退+审批流程

### K12: 提示词工程工具

1. **IDE工具**：VS Code/JetBrains扩展(语法高亮+片段+lint+预览)
2. **CI/CD**：GitHub Actions/GitLab CI工作流(自动评估+发布)
3. **评估工具**：promptfoo+自定义评估+LLM-as-Judge
4. **调试工具**：Playground+追踪+diff+回放
5. **市场平台**：提示词市场v2(发布/发现/安装/评分/变现)

### K13: 计算基础

1. **NLP基础**：分词/NER/依存分析/语义角色标注
2. **LLM架构**：Transformer/注意力/位置编码/RLHF/DPO
3. **Token化**：BPE/WordPiece/Unigram分词原理
4. **注意力机制**：Self-Attention/Cross-Attention/Flash-Attention

### K14: 数学基础

1. **概率统计**：贝叶斯推理+假设检验+置信区间
2. **信息论**：熵+互信息+KL散度+交叉熵
3. **优化理论**：梯度下降+学习率调度+凸优化基础
4. **形式逻辑**：命题逻辑+谓词逻辑+时序逻辑+可满足性

### K15: 工程伦理

1. **AI伦理**：公平性+透明性+可解释性+问责制+人类自主
2. **安全防御**：注入防御+越狱防御+数据泄露防御
3. **隐私保护**：差分隐私+联邦学习+数据最小化+匿名化
4. **公平性**：偏见检测+偏见缓解+公平约束+影响评估
5. **透明度**：可解释提示词+决策追溯+模型卡片+影响声明
