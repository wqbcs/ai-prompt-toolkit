| 认证 | 全称 | 级别 | 前置 | 有效期 |

| CPE-L3 | Certified Prompt Engineer - Expert | 专家 | CPE-L2+1年经验 | 2年 |

## 2. 考试题库(每级3道示例)

### CPE-L1 示例题

**Q1[选择]**：提示词的5层结构包括以下哪些要素？
- A) 指令、上下文、示例、约束、输出格式 ✓
- B) 角色、任务、风格、长度、语言
- C) 输入、处理、输出、反馈、迭代
- D) 需求、设计、编码、测试、部署

**Q2[场景]**：以下提示词存在什么设计缺陷？请识别并修复。
```
你是一个AI助手。请帮我写一篇关于AI安全的文章。
```
参考答案：违反P1单一职责(任务不明确)+P3约束前置(无约束)+P4示例驱动(无示例)+A2约束缺失。修复：添加明确主题、长度、风格约束和输出格式。

**Q3[实操]**：使用Playground编写一个代码审查提示词，要求：结构化5层、含2个示例、约束输出为JSON，并通过LLM-as-Judge评估得分≥8.0。

### CPE-L2 示例题

**Q1[场景]**：识别以下工作流中的3种反模式并提出修复方案。
```
[工作流描述含：A4过度指令+A6静态提示词+A15引用悬空]
```

**Q2[设计]**：为"API文档生成"场景设计完整工作流，含：提示词设计(遵循≥5条原则)+模型适配层+门禁配置+评估方案。

**Q3[实操]**：实现GPT-4和Qwen的适配层，包含：能力抽象+弹性指令配置+降级策略，通过门禁验证。

### CPE-L3 示例题

**Q1[设计]**：设计一个"法律咨询Agent"多Agent协作系统，要求：≥3个Agent+工具调用+形式化不变量(输出不含确定性法律意见)+ReAct模式。

**Q2[实操]**：实现一个自进化提示词系统，含：元提示词+用户反馈收集+自动优化循环+漂移检测+回退机制。

**Q3[分析]**：将"金融风控"提示词跨域迁移到"医疗诊断"领域，输出：术语映射表+安全红线差异+不确定表达调整+合规覆盖对比。

### CPE-L4 示例题

**Q1[架构]**：设计一个企业级提示词体系架构，覆盖：5层架构(基础层/适配层/行业层/工作流层/应用层)+接口定义+演进策略+安全架构+运维架构。

**Q2[实操]**：为"制造业"实现完整行业适配方案，含：ISO 26262合规映射+工业术语表(≥50术语)+3个场景提示词+安全审计。

**Q3[报告]**：撰写一份组织提示词工程变革方案(≥3000字)，含：现状评估+团队能力建设+流程改造+培训计划+伦理影响评估+ROI预估。

### CPE-L5 示例题

**Q1[论文]**：撰写研究论文(≥5000字)，主题从以下选择：
- 提示词可计算性理论初探
- 基于信息论的提示词压缩极限
- 提示词工程的语义保真度形式化定义
- 跨模态提示词的认知科学基础

**Q2[提案]**：提交PEBOK知识域扩展提案，含：新知识域动机+与现有15域关系+子主题定义+评审计划。

**Q3[课程]**：设计L3级新模块"多模态提示词工程"，含：4学时大纲+教案+实验设计+微认证评估方案。

## 3. 续证机制

| 项目 | 规则 |
|------|------|
| 有效期 | 2年(与AI技术迭代周期对齐) |
| 续证方式 | 重考(60%权重)或继续教育学分(40%权重) |
| 年度学分 | ≥16学分/年 |
| 学分来源 | 学术会议(3)+期刊论文(5)+课程(2)+社区贡献(1)+实战项目(4)+标准贡献(5) |
| 逾期处理 | 超3月需重考，超1年降1级 |

## 5. 考试管理

```yaml
exam_administration:
  platform: "在线监考系统"
  proctoring:
    - AI行为检测(切换窗口/复制粘贴/异常输入)

    - 答案加密传输

    - 延长时间(残疾+30%)

  results:
    - 即时出分(L1-L4)
    - 7日内出分(L5论文)
    - 成绩单+能力雷达图+改进建议
```
