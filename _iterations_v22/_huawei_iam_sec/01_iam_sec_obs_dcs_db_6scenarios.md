## 场景1：华为云IAM身份认证

### 场景模板

```
角色：华为云IAM安全工程师
任务：设计IAM身份认证提示词方案

输入：
- 认证场景：{scenario}(用户管理/跨账号授权/CI/CD凭证/联邦认证)
- 账号类型：{account_type}(企业/个人/合作伙伴)
- 安全等级：{security_level}(基础/增强/最高)

请设计：
1. IAM用户与用户组管理提示词（创建/授权/MFA/密码策略）
2. 权限策略设计提示词（RBAC+自定义策略+权限边界+最小权限）
3. 联邦认证配置提示词（SAML2.0/OIDC/企业IdP集成）
4. 临时凭证管理提示词（STS+会话策略+自动轮转）
5. 安全基线检查提示词（MFA覆盖率+弱密码+过度授权+审计）

请输出IAM方案JSON（策略语法符合华为云IAM规范）。
```

### 陷阱5

| # | 陷阱 | 严重等级 | 修复方法 |
|---|------|---------|---------|
| 1 | 策略授予*:*权限 | P0 | 最小权限+资源限定+条件约束 |
| 2 | AK/SK硬编码 | P0 | 临时凭证+环境变量+密钥管理 |
| 3 | MFA未强制启用 | P1 | 强制MFA+条件策略(MFARequired) |
| 4 | 临时凭证永不过期 | P0 | 最大有效期15分钟+自动轮转 |
| 5 | 联邦认证映射规则错误 | P1 | 用户组映射+会话策略+测试验证 |

### 性能基准
- Token消耗：3K-8K | 延迟：2-5s | 成本：$0.02-0.05/次

### 最小可执行示例

```
输入：为CI/CD流水线设计IAM临时凭证方案
提示词：请设计华为云CI/CD IAM方案：
1. 创建专用IAM用户+用户组
2. 自定义策略：仅允许ECS部署+OBS上传+RDS只读
3. 临时AK/SK生成（有效期15分钟）
4. 凭证自动轮转+使用审计

预期输出：
{
  "iamPolicy": {
    "Statement": [
      {"Effect": "Allow", "Action": ["ecs:servers:create","ecs:servers:update"], "Resource": ["ecs:cn-north-4:*:server/*"]},
      {"Effect": "Allow", "Action": ["obs:object:Put"], "Resource": ["obs:cn-north-4:*:bucket/artifacts/*"]},
      {"Effect": "Allow", "Action": ["rds:instance:list"], "Resource": ["rds:cn-north-4:*:instance/*"]}
    ]
  },
  "credentialRotation": {"maxDuration": "15m", "autoRotate": true}
}
```

### 常见错误Top5

| # | 错误 | 修复方法 |
|---|------|---------|
| 1 | 用root账号做日常操作 | 创建IAM子账号+最小权限 |
| 2 | 策略Resource用通配符 | 精确到具体资源ARN |
| 3 | 忘记配置Condition | 加IP限制+时间限制+MFA条件 |
| 4 | 跨账号委托未设信任策略 | 配置委托信任+限定条件 |
| 5 | 密码策略过于简单 | 最少12位+复杂度+90天轮换 |
