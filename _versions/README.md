# _versions — 版本管理引擎

## 引擎简介

`_versions` 是提示词基础设施的版本管理引擎，提供提示词模板的全生命周期版本控制。主要功能包括：

- **版本追踪**：基于语义化版本号（SemVer）追踪模板变更历史
- **差异对比**：对比任意两个版本间的新增、修改、删除内容
- **锁定机制**：在特定状态（review/canary）下锁定版本，防止误修改
- **删除保护**：默认禁止删除，确保历史可追溯

## 使用指南

### 目录结构

```
_versions/
├── README.md          # 本文件
├── config.yaml        # 版本引擎配置
└── (版本核心代码)
```

### 版本管理流程

1. 创建模板并分配初始版本号
2. 修改模板时自动递增版本号
3. 提交版本差异报告
4. 在 review/canary 状态锁定版本
5. 发布后归档版本快照

### 配置说明

参见 `config.yaml`，关键配置项：

- `version_format`：版本号格式
- `allow_deletion`：是否允许删除
- `lock_on_status`：锁定版本的状态列表

### 版本差异报告

版本对比输出遵循 `_schemas/version_diff_report.schema.json` 定义的格式。
