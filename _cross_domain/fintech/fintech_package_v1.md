# 金融科技(FinTech)跨域提示词包 v1.0

> 领域：金融科技 | 版本：v1.0 | 日期：2026-05-29

---

## 1. 领域概述

金融科技将AI应用于DeFi(去中心化金融)、监管科技(RegTech)、智能投顾、风控反欺诈等场景，需严格遵守金融监管+数据隐私+反洗钱合规。

## 2. 5个场景

### 场景1：智能风控评估
- 输入：交易特征+用户画像+历史行为
- 输出：风险评分(0-100)+风险等级+决策建议+合规检查
- 安全红线：绝不可给出确定性投资建议；必须含风险提示

### 场景2：反洗钱(AML)分析
- 输入：交易流水+客户KYC+可疑模式
- 输出：可疑度评分+洗钱模式识别+SAR报告建议
- 合规：FATF 40项建议+各国AML法规

### 场景3：监管科技(RegTech)合规检查
- 输入：业务流程+产品特性+监管要求
- 输出：合规差距+整改建议+监管报告
- 合规：Basel III/IV+MiFID II+ Dodd-Frank

### 场景4：DeFi智能合约审计
- 输入：Solidity代码+合约逻辑
- 输出：漏洞列表+风险评估+修复建议
- 安全：重入攻击+闪电贷+预言机操纵

### 场景5：信用评分模型解释
- 输入：用户特征+信用历史
- 输出：评分因素+权重解释+公平性检查+改进建议
- 合规：ECOA公平信贷+GDPR解释权

## 4. 安全红线

- 绝不可给出确定性投资/信贷决策
- 风险评分必须含置信区间
- AML分析结果必须经人工复核
- DeFi审计不可替代正式安全审计
- 信用评分必须含公平性检查
