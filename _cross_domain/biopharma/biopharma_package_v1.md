# 生物医药(BioPharma)跨域提示词包 v1.0

> 领域：生物医药 | 版本：v1.0 | 日期：2026-05-29

---

## 1. 领域概述

生物医药将AI应用于药物发现、临床试验、药物警戒、基因组分析等场景，需严格遵守GCP/GMP/GVP+FDA/EMA/NMPA监管要求。

## 2. 5个场景

### 场景1：药物发现辅助
- 输入：靶点信息+化合物库+ADMET约束
- 输出：候选化合物排序+结合能预测+毒性预警+实验设计建议
- 安全：输出必须标注"不可替代湿实验验证"

### 场景2：临床试验方案设计
- 输入：适应症+患者人群+终点指标+既往研究
- 输出：方案草案+入排标准+统计设计+GCP合规检查
- 合规：ICH-GCP E6(R2)+21 CFR Part 11

### 场景3：药物警戒信号检测
- 输入：不良事件报告+药物使用数据+文献信号
- 输出：信号评分+因果关系评估+报告建议
- 合规：ICH-E2B/GVP Module

### 场景4：基因组变异解读
- 输入：VCF文件+患者表型+基因数据库
- 输出：变异分类(ACMG 5级)+致病性评估+治疗建议
- 合规：ACMG/AMP解读标准

### 场景5：医学文献系统综述
- 输入：研究问题+检索策略+纳入排除标准
- 输出：文献筛选+质量评估+证据合成+GRADE分级
- 方法：PRISMA+GRADE

## 3. 术语表

| 术语 | 定义 | 不可替代 |
|------|------|---------|
| GCP | 药物临床试验质量管理规范 | 是 |
| GMP | 药品生产质量管理规范 | 是 |
| GVP | 药物警戒质量管理规范 | 是 |
| ADMET | 吸收/分布/代谢/排泄/毒性 | 是 |
| ICH | 国际人用药品注册技术要求协调会 | 是 |
| ACMG | 美国医学遗传学学会 | 是 |
| VCF | 变异调用格式(Variant Call Format) | 否 |
| IND | 研究用新药申请(Investigational New Drug) | 是 |
| NDA | 新药申请(New Drug Application) | 是 |
| AE | 不良事件(Adverse Event) | 是 |
| SAE | 严重不良事件(Serious Adverse Event) | 是 |
| SUSAR | 可疑非预期严重不良反应 | 是 |
| PRISMA | 系统综述和Meta分析首选报告项目 | 是 |
| GRADE | 推荐等级的评估/制定与评价 | 是 |

## 4. 安全红线

- 绝不可给出确定性诊断或治疗建议
- 药物发现输出必须标注"需湿实验验证"
- 临床试验方案必须经IRB/IEC审查
- 药物警戒信号必须经医学评审
- 基因组解读必须标注ACMG分类依据
