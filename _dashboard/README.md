# _dashboard — 监控仪表盘引擎

## 引擎简介

`_dashboard` 是提示词基础设施的监控仪表盘引擎，提供实时运维洞察与异常检测。主要功能包括：

- **指标聚合**：从编译、测试、安全、版本各引擎收集运行指标
- **异常检测**：基于统计阈值（Sigma 倍数）自动识别异常波动
- **趋势分析**：移动平均窗口平滑指标趋势，辅助决策
- **可视化展示**：统一仪表盘展示各引擎健康状态

## 使用指南

### 目录结构

```
_dashboard/
├── README.md          # 本文件
├── config.yaml        # 仪表盘配置
└── (仪表盘核心代码)
```

### 监控流程

1. 从各引擎采集运行数据
2. 应用异常检测阈值筛选异常点
3. 计算移动平均趋势线
4. 聚合为仪表盘视图
5. 触发告警（如需要）

### 配置说明

参见 `config.yaml`，关键配置项：

- `anomaly_threshold_sigma`：异常检测 Sigma 阈值
- `min_sample_for_trend`：趋势分析最小样本数
- `moving_average_window`：移动平均窗口大小

### 指标来源

| 引擎 | 关键指标 |
|------|---------|
| `_compiler` | 编译成功率、编译耗时、缓存命中率 |
| `_ab_tests` | 实验完成率、推荐采纳率 |
| `_security` | 扫描通过率、高危阻断次数 |
| `_versions` | 版本发布频率、锁定时长 |
