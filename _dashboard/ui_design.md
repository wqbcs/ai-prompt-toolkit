# 仪表盘 UI 设计

## 概述

仪表盘 UI 是 `_dashboard` 引擎的可视化呈现层，提供总览、趋势、排行、告警四大区域布局，支持实时数据刷新与交互式数据探索。设计目标：一屏掌控系统健康状态，两次点击定位具体问题。

---

## 一、仪表盘布局

### 1.1 整体布局

```
┌──────────────────────────────────────────────────────────────┐
│  顶部导航栏（系统名称 + 全局筛选 + 刷新状态 + 用户操作）      │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐       │
│  │  编译成功率   │  │  安全通过率   │  │  版本发布数   │       │
│  │   95.2% ↑    │  │   98.1% →    │  │   12 ↓       │       │
│  └──────────────┘  └──────────────┘  └──────────────┘       │
│                                                              │
│  ┌──────────────────────────────────────────────────────┐   │
│  │              趋势区域（效果趋势折线图）                │   │
│  │  ── 实际值   ── MA7   ○ 异常点   ▮ 告警区间         │   │
│  └──────────────────────────────────────────────────────┘   │
│                                                              │
│  ┌────────────────────────┐  ┌────────────────────────┐     │
│  │   排行榜（Top 10）     │  │   告警列表（最近 20）   │     │
│  │   1. e1_deh  92.5     │  │   🔴 compile_success   │     │
│  │   2. e2_bms  89.1     │  │   🟡 scan_pass_rate    │     │
│  │   3. e3_as   85.3     │  │   🟢 lock_duration     │     │
│  └────────────────────────┘  └────────────────────────┘     │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 1.2 四大区域

| 区域 | 位置 | 核心内容 | 信息密度 |
|------|------|---------|---------|
| **总览区** | 顶部 | KPI 卡片（3~5 个核心指标） | 低（一眼可见） |
| **趋势区** | 中部 | 效果趋势折线图（叠加 MA7 + 异常标注） | 中（时间维度） |
| **排行区** | 左下 | 模板排行榜（综合评分 + 使用频次 + 效果评分） | 中（对比维度） |
| **告警区** | 右下 | 最近告警列表（按时间倒序，颜色区分严重级别） | 高（详情维度） |

## 二、总览区 — KPI 卡片

### 2.1 卡片设计

每个 KPI 卡片包含：

```
┌─────────────────────┐
│ 编译成功率           │  ← 指标名称
│ 95.2%               │  ← 当前值（大字号）
│ ↑ 2.1% vs 7d ago   │  ← 变化趋势（与7天前对比）
│ ████████████░░░     │  ← 迷你进度条（相对目标值）
└─────────────────────┘
```

### 2.2 默认 KPI 卡片

| 顺序 | 指标 | 目标值 | 告警阈值 | 趋势对比 |
|------|------|--------|---------|---------|
| 1 | 编译成功率 | 98% | < 90% | vs 7d |
| 2 | 安全通过率 | 99% | < 95% | vs 7d |
| 3 | 版本发布数（本周） | - | = 0 持续 2 周 | vs 7d |
| 4 | 推荐采纳率 | 80% | < 60% | vs 7d |
| 5 | 异常告警数（24h） | 0 | > 5 | vs 24h |

### 2.3 卡片状态

| 状态 | 条件 | 视觉表现 |
|------|------|---------|
| 正常 | 当前值 ≥ 目标值 | 绿色边框 |
| 警告 | 当前值 < 目标值但 > 告警阈值 | 黄色边框 + 闪烁 |
| 异常 | 当前值 ≤ 告警阈值 | 红色边框 + 持续高亮 |

## 三、趋势区 — 效果趋势图

### 3.1 图表元素

| 元素 | 说明 | 交互 |
|------|------|------|
| 实际值折线 | 原始指标数据点连线 | 悬停显示具体值 |
| MA7 趋势线 | 7 日移动平均线 | 悬停显示 MA 值 |
| 异常点标注 | 红色圆点标记异常值 | 点击查看异常详情 |
| 告警区间 | 红色半透明带标记告警时段 | 点击展开告警列表 |
| 置信区间 | MA7 ± 1σ 的浅色带 | 无交互 |

### 3.2 时间范围选择

| 选项 | 范围 | 数据粒度 |
|------|------|---------|
| 24h | 最近 24 小时 | 1 分钟 |
| 7d | 最近 7 天 | 1 小时 |
| 30d | 最近 30 天 | 1 天 |
| 90d | 最近 90 天 | 1 天 |
| Custom | 自定义范围 | 自动选择粒度 |

### 3.3 多指标叠加

- 支持同一图表叠加最多 3 个指标（左 Y 轴 1 个 + 右 Y 轴 2 个）
- 叠加指标需单位兼容（百分比类可叠加，绝对值类不可与百分比叠加）
- 叠加模式下各指标使用不同颜色区分

## 四、排行区 — 模板排行榜

### 4.1 表格列

| 列名 | 宽度 | 排序 | 说明 |
|------|------|------|------|
| 排名 | 40px | - | 序号，Top 3 使用奖牌图标 |
| 模板名称 | 200px | - | 可点击跳转至模板详情 |
| 综合评分 | 80px | 默认倒序 | 数值 + 迷你条形图 |
| 使用频次 | 80px | 可排序 | 调用次数 |
| 效果评分 | 80px | 可排序 | 百分比 |
| 趋势 | 60px | - | ↑/→/↓ 箭头 + 变化值 |

### 4.2 排行榜操作

- 点击列头排序
- 点击模板名称跳转至模板趋势详情页
- 悬停综合评分显示评分构成明细（使用频次分 × 效果评分分）

## 五、告警区 — 告警列表

### 5.1 列表项设计

```
┌─────────────────────────────────────────────────────┐
│ 🔴 CRITICAL  compile_success_rate                   │
│ 观测值 72.5%  期望范围 89.0%~101.4%  偏离 7.32σ    │
│ 2026-07-12 10:30  来源: _compiler  模板: e1_deh     │
└─────────────────────────────────────────────────────┘
```

### 5.2 告警颜色编码

| 严重级别 | 图标 | 颜色 | 说明 |
|---------|------|------|------|
| critical | 🔴 | #DC2626 | 严重异常，需立即处理 |
| warn | 🟡 | #F59E0B | 轻微异常，需关注 |
| info | 🟢 | #10B981 | 信息通知，已自动恢复 |

### 5.3 告警操作

- 点击告警项展开详情（关联上下文、历史同类告警）
- "已处理"按钮标记告警为已解决
- "抑制"按钮临时抑制同类告警（默认 30 分钟）

## 六、数据刷新策略

### 6.1 刷新模式

| 模式 | 触发方式 | 刷新范围 | 适用场景 |
|------|---------|---------|---------|
| 自动轮询 | 定时器（默认 60s） | 全量指标 | 日常监控 |
| 手动刷新 | 用户点击刷新按钮 | 全量指标 | 疑似数据延迟 |
| 事件驱动 | 版本发布/告警触发 | 相关指标 | 实时响应 |

### 6.2 刷新状态指示

| 状态 | 图标 | 说明 |
|------|------|------|
| 刷新中 | ↻ 旋转 | 正在拉取最新数据 |
| 已同步 | ✓ 绿色 | 数据为最新（显示最后同步时间） |
| 延迟 | ⚠ 黄色 | 超过 2 倍刷新间隔未更新 |
| 失败 | ✗ 红色 | 数据拉取失败（显示失败原因） |

### 6.3 性能优化

- 增量刷新：仅拉取上次刷新后有变化的数据
- 智能降频：页面不可见时自动降低刷新频率至 5 分钟
- 数据缓存：前端缓存最近 3 次刷新结果，支持离线查看
- 请求合并：多个指标的刷新请求合并为单次 API 调用

## 七、交互组件

### 7.1 筛选器

| 筛选项 | 类型 | 选项 | 默认值 |
|--------|------|------|--------|
| 引擎来源 | 多选 | _compiler / _ab_tests / _security / _versions | 全选 |
| 时间范围 | 单选 | 24h / 7d / 30d / 90d / Custom | 7d |
| 指标类型 | 多选 | 所有可用指标 | 核心指标 |
| 告警级别 | 多选 | critical / warn / info | critical + warn |
| 模板 | 单选 | 所有模板 / 具体模板 | 全部 |

筛选器位于顶部导航栏下方，展开/收起切换，收起时仅显示当前生效的筛选标签。

### 7.2 导出功能

| 导出类型 | 格式 | 内容范围 | 触发方式 |
|---------|------|---------|---------|
| 趋势数据 | CSV | 当前筛选条件下的所有指标数据 | 导出按钮 |
| 告警报告 | PDF | 当前筛选条件下的告警详情 | 导出按钮 |
| 排行榜 | CSV | 完整排行数据（含评分明细） | 排行区工具栏 |
| 截图 | PNG | 当前仪表盘完整视图 | 快捷键 Ctrl+Shift+S |

### 7.3 钻取导航

```
总览卡片 → 点击 → 单指标趋势详情页
    └→ 趋势图异常点 → 点击 → 异常事件详情
        └→ 关联模板 → 点击 → 模板详情页
            └→ 版本历史 → 点击 → 版本差异页

排行榜项 → 点击 → 模板趋势详情页
    └→ 评分明细 → 悬停 → 评分构成浮层

告警项 → 点击 → 告警详情展开
    └→ 关联模板 → 点击 → 模板详情页
        └→ 相关版本 → 点击 → 版本差异页
```

### 7.4 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `R` | 手动刷新 |
| `F` | 展开/收起筛选器 |
| `1-4` | 切换四大区域焦点 |
| `Esc` | 关闭详情面板/弹窗 |
| `Ctrl+Shift+S` | 截图导出 |
| `←/→` | 时间范围前后切换 |

## 八、响应式设计

### 8.1 断点定义

| 断点 | 宽度 | 布局调整 |
|------|------|---------|
| Desktop | ≥ 1280px | 标准四区域布局 |
| Tablet | 768~1279px | 趋势区全宽，排行/告警上下堆叠 |
| Mobile | < 768px | 所有区域纵向堆叠，KPI 卡片 2 列 |

### 8.2 移动端优化

- KPI 卡片精简显示（仅保留当前值和趋势箭头）
- 趋势图支持双指缩放
- 告警列表改为摘要模式，点击展开详情
- 排行榜仅显示 Top 5，支持滑动查看更多
