它是什么

AI Prompt Toolkit（prompt-cli）是确定性 LLM 提示词静态门禁——prompt 的 ESLint。271 条规则覆盖注入攻击、编码混淆、不可见字符、结构缺陷、合规声明（EU AI Act / GDPR / 国内监管，映射 OWASP LLM Top10）、平台生态面（鸿蒙 / 华为云）。

怎么用

pip install ai-prompt-toolkit
prompt-cli lint prompt.md          # 单文件门禁（exit 0/1/2 三态契约）
prompt-cli baseline                # 一条命令自证双基线
prompt-cli scan --format sarif .   # CI 集成（SARIF 2.1.0 标准）

边界（诚实声明）

静态门禁辖区 = 注入标记 / 编码混淆 / 不可见字符 / 结构 / 合规声明；语义层攻击（创意越狱 / 间接注入 / 对抗性改写）是机制上限，应组合运行时防火墙使用——与 promptfoo / Lakera 系是互补关系，不混坐标系比较。
